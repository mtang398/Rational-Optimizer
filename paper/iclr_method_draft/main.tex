\begin{abstract}
Modern LLM development is constrained by how many pretraining tokens and hours
are needed before a model is useful enough to enter the downstream loop of
evaluation, post-training, and iteration.  We make the nonlinear Transformer
sublayer optimizer-visible.  Rational Latent Basis (RLB) replaces a fixed
response with grouped, RMS-normalized, real-pole-free P5/Q4 rational responses
and exposes derivative gains, response gains, coefficient activity, and
matrix-pair balance summaries.  MatrixPolicy consumes these summaries to update
only the adjacent input and output matrices, while rational coefficients and all
other Transformer parameters remain on AdamW.  On five pretraining corpora with
a fixed 12-layer, width-768 decoder, MatrixPolicy reaches matched
validation-loss targets with fewer tokens and lower measured arrival time than
SiLU controls.  It saves 19.5--22.8\% target-arrival tokens versus SiLU with
AdamW and 29.2--34.0\% versus SiLU with Muon at 100M tokens, and 22.3--26.4\%
and 6.7--9.8\%, respectively, at 300M tokens.  [todo: Insert the larger-scale
training result here.]

\section{Introduction}
\label{sec:introduction}

For 2027-era LLMs, the practical question has shifted from final model size
alone to capability purchased per token, per optimizer step, and per hour of
training.  A pretraining run is not an isolated curve-fitting exercise: it gates
architecture search, data-mixture revision, post-training, safety evaluation,
and release cadence.  Recent open model reports therefore foreground training
data, token budgets, architecture choices, stability, and hardware cost
alongside benchmark quality
\citep{grattafiori2024llama3,qwen2025qwen25,deepseekai2024deepseekv3}.
Recent scaling and training-protocol studies make the same point from a more
controlled angle: loss depends on data mixture, repetition, optimizer choice,
and the full training configuration, so small design changes should be judged by
how quickly they reach useful loss, not only by the endpoint after a fixed budget
\citep{li2025farseer,liu2026infolaw,volkova2026optimizerlaws,semenov2025benchmarking,wen2026fantastic}.
We therefore use target arrival as the main readout: when two runs eventually
approach similar endpoint losses, the one that reaches the same validation loss
earlier has changed the cost of pretraining.

The nonlinear Transformer sublayer is a plausible place to improve target
arrival, but only if it is treated as a matrix interaction rather than as an
isolated scalar curve.  Early Transformer implementations used pointwise
responses such as ReLU or GELU
\citep{vaswani2017attention,hendrycks2016gelu}.  Modern decoder blocks instead
often use GLU-derived gated sublayers, including SwiGLU in PaLM and LLaMA-style
models
\citep{dauphin2017language,shazeer2020glu,chowdhery2022palm,touvron2023llama}.
This made nonlinear sublayers stronger, but it also made many fixed-curve swaps
less structurally decisive: learned projections choose latent coordinates, a
response transforms them, and another matrix recombines the features.  The scalar
curve matters, but the surrounding matrices decide what the curve sees and how
its features return to the residual stream.

Learned rational responses are a natural response family for this interaction.
Rational neural networks have approximation-theoretic advantages for smooth
functions, and recent theory extends the separation to modern fixed activations,
including gated and Transformer-style nonlinearities
\citep{boulle2020rational,tang2026rationalexpressivity}.  Prior Transformer
work with rational activations shows that replacing a fixed curve by a trainable
rational curve can help \citep{fang2023transformers}.  The missing piece is the
optimizer interface.  If the rational curve is trained as just another tensor,
the optimizer does not know which adjacent matrix selects rational coordinates,
which matrix recombines rational features, or which reciprocal rescalings leave
the represented sublayer map nearly unchanged.

Rational Latent Basis (RLB) exposes exactly these quantities.  It maps residual
states into grouped latent coordinates, normalizes each group by its RMS radius,
and applies a trainable real-pole-free P5/Q4 rational response.  This
parameterization produces response gains, derivative gains, coefficient-activity
signals, relative matrix-pressure summaries, and a positive matrix-pair balance
coordinate.  MatrixPolicy is the optimizer rule paired with that interface: it
updates only the RLB input and output matrices by role, while rational
coefficients, attention weights, embeddings, normalization parameters, and all
other Transformer tensors remain on AdamW.

The completed fixed-scale study uses the same 12-layer, width-768 causal
Transformer across DCLM, FineWeb-Edu, FineWeb, Dolma-sample, and C4.  At the
100M-token budget, MatrixPolicy reaches shared validation-loss targets earlier
than matched SiLU with AdamW and SiLU with Muon baselines.  At the 300M-token
budget, where longer runs compress endpoint gaps, the target-arrival advantage
remains visible in both tokens and measured time.  [todo: Insert the larger-scale
training result here.]  The contribution is an activation design that exposes
optimizer-visible matrix roles, a localized role-aware optimizer for the exposed
matrix pair, and matched evidence that this interface reduces target-arrival
tokens and wall-clock time across five pretraining corpora.

\section{Related Work}
\label{sec:related}

Transformer nonlinear sublayers have evolved from fixed pointwise responses to
learned gated interactions.  GELU and Swish/SiLU modify the scalar curve applied
inside the original Transformer-style sublayer
\citep{vaswani2017attention,hendrycks2016gelu,ramachandran2017swish}.  GLU
introduced a multiplicative gate for language modeling
\citep{dauphin2017language}, and GLU variants such as SwiGLU improved Transformer
sublayers in compute-matched settings \citep{shazeer2020glu}.  Large decoder
models then adopted SwiGLU together with pre-normalized Transformer components
\citep{chowdhery2022palm,touvron2023llama}.  RLB keeps the nonlinear sublayer
location but changes the object exposed to optimization: the response remains a
learned scalar function, while normalized groups and adjacent matrix roles become
observable optimizer signals.

Rational activations replace fixed curves by quotients of low-degree polynomials.
Pad\'e Activation Units learned flexible rational responses end to end
\citep{molina2020pade}, rational neural networks established approximation
efficiency results for smooth-function classes \citep{boulle2020rational}, and
RAFT evaluated rational activation functions inside Transformer pretraining and
fine-tuning \citep{fang2023transformers}.  More recent theory argues for
expressivity advantages of trainable low-degree rational activations over a broad
set of modern fixed activations, including gated and Transformer-style
nonlinearities \citep{tang2026rationalexpressivity}.  RLB uses this line of work
as the activation family, but the paper's empirical question is different: a
global rational curve is paired with an optimizer-visible matrix interface, and
RLB-only controls separate the curve family from MatrixPolicy.

Optimization for language-model pretraining is again an active target.  Adam and
AdamW remain central baselines \citep{kingma2015iclr-adam,loshchilov2019decoupled}.
State-efficient and diagonal adaptive methods such as Adafactor and CAME reduce
optimizer memory or alter adaptive-state estimates
\citep{shazeer2018adafactor,luo2023came}; Lion, Schedule-Free methods, and
cautious optimizers alter momentum, sign, or schedule behavior
\citep{chen2023lion,defazio2024road,liang2026cautious}; Sophia, GaLore, and
Adam-mini change curvature, low-rank, or per-block learning-rate structure
\citep{liu2024sophia,zhao2024galore,zhang2025adammini}.  Matrix-aware methods
are especially relevant here: Shampoo uses tensor preconditioners
\citep{gupta2018shampoo}, SOAP stabilizes Shampoo-style preconditioning by
running Adam in the preconditioner eigenbasis \citep{vyas2025soap}, and Muon uses
orthogonalized matrix updates for LLM training \citep{liu2025muon}.  Recent
optimizer comparisons emphasize fair tuning, model-scale dependence, and the
fact that matrix-structured optimizers can change token or compute efficiency
without uniformly dominating across all settings
\citep{zhao2025deconstructing,wen2026fantastic}.  MatrixPolicy follows the
matrix-aware direction, but the role information does not come from tensor shape
alone.  RLB supplies derivative/response gains, relative input/output pressure,
coefficient activity, and pair-balance signals, and MatrixPolicy applies them
only to the input/output matrix pair of the nonlinear sublayer.

\section{Method}
\label{sec:method}

RLB and MatrixPolicy are designed as a single interface.  RLB defines the
nonlinear sublayer and the detached summaries it exposes; MatrixPolicy consumes
those summaries to update the two adjacent matrices.  Rational coefficients and
ordinary Transformer parameters remain on the AdamW path in the evaluated
configuration.

Throughout the method we use
\begin{align}
    \clip(x,a,b)&=\min\{\max\{x,a\},b\}, \\
    \smooth(a,b,x)&=3\omega^2-2\omega^3,
    \qquad
    \omega=\clip\left(\frac{x-a}{b-a},0,1\right).
\end{align}

\subsection{Rational Latent Basis}
\label{sec:method-rlb}

For layer $l\in\{1,\ldots,L\}$, let $x_l\in\mathbb{R}^{d}$ be the input to the
nonlinear sublayer.  RLB uses an input matrix $A_l\in\mathbb{R}^{H\times d}$ and
an output matrix $B_l\in\mathbb{R}^{d\times H}$ with latent width $H=Gm$.  Let
$A_{l,g}\in\mathbb{R}^{m\times d}$ denote the row block of $A_l$, and let
$B_{l,g}\in\mathbb{R}^{d\times m}$ denote the matching column block of $B_l$.
Each group has a trainable P5/Q4 rational response
\begin{align}
    P_{l,g}(u)&=\sum_{i=0}^{5}a_{l,g,i}u^i,
    \label{eq:global-rational-p}\\
    Q_{l,g}(u)&=
    1+|b_{l,g,1}|\,|u|+|b_{l,g,2}|\,u^2
     +|b_{l,g,3}|\,|u|^3+|b_{l,g,4}|\,u^4,
    \label{eq:global-rational-q}\\
    R_{l,g}(u)&=P_{l,g}(u)/Q_{l,g}(u).
    \label{eq:global-rational}
\end{align}
The RLB forward map is the single block expression
\begin{equation}
    y_l
    =
    \sum_{g=1}^{G}
    B_{l,g}
    \left[
    \rho_{l,g}(x_l)\,
    R_{l,g}\!\left(
    \frac{A_{l,g}x_l}{\rho_{l,g}(x_l)}
    \right)
    \right],
    \qquad
    \rho_{l,g}(x_l)=
    \sqrt{m^{-1}\lVert A_{l,g}x_l\rVert_2^2+\epsilon_{\rm rms}} .
    \label{eq:rlb-forward}
\end{equation}
The scalar functions $P_{l,g}$, $Q_{l,g}$, and $R_{l,g}$ are applied
coordinatewise when their input is a vector.  Since $Q_{l,g}(u)\ge1$ for all
real $u$, the implemented response has no real pole.  The response is piecewise
rational because of the absolute-value terms; derivative statistics use the
autodiff convention $\sign(0)=0$ and equations involving $R'_{l,g}$ are
interpreted almost everywhere.  Numerator and denominator coefficients are
initialized by a SiLU fit on $[-5,5]$ and are then trained by AdamW.  The evaluated
model uses only these group-global P5/Q4 rational responses.

The forward map in \eqref{eq:rlb-forward} separates the normalized coordinate at which the
rational response is evaluated from the group radius returned to the residual
stream.  For fixed curves $R_l=\{R_{l,g}\}_{g=1}^{G}$, write this block map as
$f_l(x;A_l,B_l,R_l)$.  If $\epsilon_{\rm rms}=0$ and every group radius is
nonzero, then for any $\lambda\in\mathbb{R}_{>0}^{G}$ and
$D_l(\lambda)=\diag(\lambda_1I_m,\ldots,\lambda_GI_m)$,
\begin{align}
    f_l(x;A_l,B_l,R_l)
    =
    f_l(x;D_l(\lambda)A_l,B_lD_l(\lambda)^{-1},R_l).
    \label{eq:positive-rescale}
\end{align}
This positive matrix-pair rescaling is exact only in the unfloored map.  With the
stabilizing RMS floor and optimizer state, the same direction becomes a bounded
balance coordinate for MatrixPolicy rather than an exact invariance of the full
training dynamics.

\subsection{MatrixPolicy}
\label{sec:method-update}

MatrixPolicy acts only on the RLB matrix pair $(A_l,B_l)$.  The RLB calculus
exposes the signals used below: live response/derivative gains for output/input
roles, relative matrix-gradient pressure, coefficient activity, and a positive
pair-balance coordinate.  After backpropagation at step $t$, MatrixPolicy forms
bounded group/role multipliers, applies the AdamW/Muon matrix branch to the
scaled gradients, and then applies the scheduled positive pair-rescaling move.
Gradient statistics are computed before parameter updates; the pair-rescaling
ratio is computed after the AdamW/Muon branch.
For any tensor $V$, define
\begin{align}
    \rms(V)=\sqrt{\operatorname{mean}(V^2)},
    \qquad
    \rms_{\epsilon}(V)=\sqrt{\operatorname{mean}(V^2)+\epsilon}.
    \label{eq:rms-definition}
\end{align}
The constants $\epsilon_p>0$ and $\epsilon_g>0$ denote fixed additive floors in
squared-RMS units.  The same $\epsilon_p$ is reused as the implementation floor
for matrix-ratio logs in \eqref{eq:current-ratio}.  The resulting pressure and
activity scores are bounded update-control signals.  Let
$A_{l,g}\in\mathbb{R}^{m\times d}$ be the row block of $A_l$, and let
$B_{l,g}\in\mathbb{R}^{d\times m}$ be the column block of $B_l$.  The relative
matrix-gradient scales are
\begin{align}
    p^{\rm in}_{l,g}
    =
    \frac{\rms_{\epsilon_p}(\nabla A_{l,g})}
    {\rms_{\epsilon_p}(A_{l,g})},
    \qquad
    p^{\rm out}_{l,g}
    =
    \frac{\rms_{\epsilon_p}(\nabla B_{l,g})}
    {\rms_{\epsilon_p}(B_{l,g})} .
    \label{eq:matrix-pressure}
\end{align}
The coefficient-gradient energy scale for the global response is
\begin{align}
    p^{R}_{l,g}
    =
    \left[
    \frac{1}{2}
    \left(
    \operatorname{mean}((\nabla a_{l,g,\cdot})^2)
    +
    \operatorname{mean}((\nabla b_{l,g,\cdot})^2)
    \right)
    +\epsilon_p
    \right]^{1/2}.
    \label{eq:rational-activity-raw}
\end{align}
The same numerical floor is used in $p^R_{l,g}$, although this quantity is raw
coefficient-gradient energy rather than a relative matrix pressure.
MatrixPolicy maintains exponential moving averages
$q^{\rm in}_{l,g}$, $q^{\rm out}_{l,g}$, and $q^R_{l,g}$ of these quantities with
decay $0.95$, and forms
\begin{align}
    \pi_{l,g}
    =
    \log q^{\rm in}_{l,g}-\log q^{\rm out}_{l,g},
    \qquad
    \alpha_{l,g}
    =
    \log q^{R}_{l,g}
    -\frac{1}{2}\left(\log q^{\rm in}_{l,g}+\log q^{\rm out}_{l,g}\right).
    \label{eq:pressure-activity}
\end{align}
Each matrix pressure is an unsigned relative RMS-gradient scale, so
$\pi_{l,g}$ is signed only because it compares input and output magnitudes.
MatrixPolicy uses $\pi_{l,g}$ as a bounded redistribution and pair-balance
signal.  The score $\alpha_{l,g}$ compares coefficient-gradient activity with
adjacent matrix pressure and is used only inside bounded redistribution and
gating rules.

The activation also provides batch-estimated curve gains.  From a recent sample
of normalized coordinates $u_{l,g}$ cached by the RLB forward path, MatrixPolicy
uses floored summaries
\begin{align}
    \hat d^{\rm live}_{l,g}
    =
    \sqrt{\operatorname{mean}\!\left(R'_{l,g}(u_{l,g})^2\right)+\epsilon_g},
    \qquad
    \hat o^{\rm live}_{l,g}
    =
    \sqrt{\operatorname{mean}\!\left(R_{l,g}(u_{l,g})^2\right)+\epsilon_g}.
    \label{eq:live-gains}
\end{align}
The mean is over cached scalar normalized coordinates for group $(l,g)$ across
batch, sequence positions, and the $m$ group coordinates.  The derivative gain is
the input-role proxy; the response gain is the recombination-role proxy.  The
latter excludes the group radius $r_{l,g}$, so neither gain is a full feature
scale or block-Jacobian preconditioner.

Let $t$ be the optimizer step, $T$ the planned number of training steps, and
$\xi_t=t/T$.  A smooth gate
\begin{align}
    \phi_t=\smooth(0.02,0.30,\xi_t)
    \label{eq:group-phase}
\end{align}
turns on the group-gradient policy.  For positive group values $v_j$, define
$\geom_{j=1}^{G}(v_j)=\exp\!\left(G^{-1}\sum_{j=1}^{G}\log v_j\right)$.
The multiplier for group $g$ and role $\sigma\in\{\mathrm{in},\mathrm{out}\}$ is
\begin{align}
    c_{l,g,\sigma}
    =
    c^{\rm gain}_{l,g,\sigma}
    c^{\rm pressure}_{l,g,\sigma}
    c^{\rm activity}_{l,g}.
    \label{eq:group-multiplier}
\end{align}
For the input role, the gain term uses $\hat d^{\rm live}_{l,g}$; for the output
role, it uses $\hat o^{\rm live}_{l,g}$:
\begin{align}
    c^{\rm gain}_{l,g,\mathrm{in}}
    =
    \left(\frac{\geom_{j=1}^{G} \hat d^{\rm live}_{l,j}}{\hat d^{\rm live}_{l,g}}\right)^{0.20\phi_t},
    \qquad
    c^{\rm gain}_{l,g,\mathrm{out}}
    =
    \left(\frac{\geom_{j=1}^{G} \hat o^{\rm live}_{l,j}}{\hat o^{\rm live}_{l,g}}\right)^{0.20\phi_t}.
    \label{eq:gain-policy}
\end{align}
With $\tilde{\pi}_{l,g}=\clip(\pi_{l,g},-1.50,1.50)$, the relative-gradient term
sets role-dependent group multipliers before the later role-wise recentering:
\begin{align}
    c^{\rm pressure}_{l,g,\mathrm{in}}
    =
    \exp(-0.10\phi_t\tilde{\pi}_{l,g}),
    \qquad
    c^{\rm pressure}_{l,g,\mathrm{out}}
    =
    \exp(+0.10\phi_t\tilde{\pi}_{l,g}).
    \label{eq:pressure-policy}
\end{align}
Coefficient-gradient activity downweights groups whose rational coefficients are
moving more strongly than the adjacent matrices before role-wise recentering:
\begin{align}
    c^{\rm activity}_{l,g}
    =
    \exp\left[
    -0.20\phi_t
    \relu\left(\frac{\alpha_{l,g}-0.05}{0.45}\right)
    \right].
    \label{eq:activity-policy}
\end{align}
The final multiplier is recentered and clipped,
\begin{align}
    c_{l,g,\sigma}\leftarrow
    \frac{c_{l,g,\sigma}}{\geom_{j=1}^{G} c_{l,j,\sigma}},
    \qquad
    c_{l,g,\sigma}\leftarrow\clip(c_{l,g,\sigma},0.75,1.35),
    \label{eq:group-center-clip}
\end{align}
so the policy redistributes update scale across groups, separately for each
matrix role, without changing the role-wise mean log multiplier before
clipping.

The scaled matrix gradients are
\begin{align}
    \widetilde\nabla A_{l,g}=c_{l,g,\mathrm{in}}\nabla A_{l,g},
    \qquad
    \widetilde\nabla B_{l,g}=c_{l,g,\mathrm{out}}\nabla B_{l,g}.
    \label{eq:scaled-gradients}
\end{align}
Let $\widetilde\nabla M_{l,\mathrm{in}}$ be the row-block concatenation of
$\{\widetilde\nabla A_{l,g}\}_{g=1}^{G}$, and let
$\widetilde\nabla M_{l,\mathrm{out}}$ be the column-block concatenation of
$\{\widetilde\nabla B_{l,g}\}_{g=1}^{G}$.
After this scaling, the RLB matrices are updated by a role/depth AdamW branch and
a transient Muon branch.  Define $\delta_l=(l-1)/(L-1)$ for $L>1$ and
$\delta_l=1/2$ otherwise.  The role factors are
\begin{align}
    \varrho_{\mathrm{in}}(l)
    =
    \clip(1-0.50(\delta_l-0.5),0.55,1.40),
    \qquad
    \varrho_{\mathrm{out}}(l)
    =
    \clip(1+1.00(\delta_l-0.5),0.55,1.40),
    \label{eq:role-factors}
\end{align}
and the AdamW matrix multiplier for role $\sigma$ is
\begin{align}
    s^{\rm Adam}_{l,\sigma}
    =
    \clip\left(
    3.0\max\{0.10,1+1.20(\varrho_\sigma(l)-1)\},
    0.40,4.0
    \right).
    \label{eq:adam-role-scale}
\end{align}
The Muon branch is concentrated early in training and is reduced when relative
scale imbalance or coefficient-gradient scale is high.  Define
\begin{align}
    \Psi_{l,t}
    =
    \clip\left(\frac{1}{G}\sum_{g=1}^{G}|\pi_{l,g}|,0,1.50\right),
    \qquad
    \Omega_{l,t}
    =
    \relu\left(\frac{G^{-1}\sum_{g=1}^{G}\alpha_{l,g}-0.05}{0.45}\right),
    \label{eq:pressure-activity-aggregates}
\end{align}
\begin{align}
    \psi_{l,t}
    =
    \clip\left(\exp[-0.30\Psi_{l,t}-0.65\Omega_{l,t}],0.10,1.15\right).
    \label{eq:stat-penalty}
\end{align}
The branch gate is
\begin{align}
    \mu_{l,\sigma,t}
    =
    \clip\left(
    0.75\,
    \smooth(0.02,0.12,\xi_t)
    [1-\smooth(0.20,0.36,\xi_t)]
    \varrho_\sigma(l)\psi_{l,t},
    0,0.75
    \right).
    \label{eq:muon-fraction}
\end{align}
For $M_{l,\mathrm{in}}=A_l$ and $M_{l,\mathrm{out}}=B_l$, let $\eta_t$ be the
base learning rate.  MatrixPolicy applies an AdamW matrix step followed by any
active Muon substep.  The gate $\mu_{l,\sigma,t}$ scales the two learning rates;
it is not a convex mixing coefficient for a single update direction:
\begin{equation}
\begin{gathered}
    \widetilde M_{l,\sigma}^{\,t+1}
    =
    \operatorname{AdamW}_{\eta_t s^{\rm Adam}_{l,\sigma}(1-\mu_{l,\sigma,t})}
    (M_{l,\sigma}^{t};\widetilde\nabla M_{l,\sigma}^{t}),\\
    M_{l,\sigma}^{t+1}
    =
    \operatorname{Muon}_{\eta_t\mu_{l,\sigma,t}}
    (\widetilde M_{l,\sigma}^{\,t+1};\widetilde\nabla M_{l,\sigma}^{t}),
\end{gathered}
    \label{eq:matrix-branch-step}
\end{equation}
The update in \eqref{eq:matrix-branch-step} is operational notation: AdamW and
Muon carry separate optimizer states, their configured weight-decay and momentum
terms are handled by the respective optimizer implementations, and both substeps
use the gradient from training step $t$.  Here $\operatorname{Muon}$ denotes the
\texttt{torch.optim.Muon} update on two-dimensional RLB matrix parameters:
momentum $0.95$, five Newton--Schulz orthogonalization steps, and the match-RMS
learning-rate adjustment of the Muon optimizer \citep{liu2025muon}.  When all
Muon fractions have decayed to zero, this branch is inactive.

The last operation is a bounded positive rescaling of the two matrix blocks
around each rational curve.  It is evaluated after the AdamW/Muon matrix branch
every five optimizer steps.  Let
$\mathcal{U}=\{u_k\}_{k=1}^{129}$ be a uniform probe grid over $[-5,5]$, and
define
$\rms_{\mathcal{U}}(\varphi)=\sqrt{|\mathcal{U}|^{-1}\sum_{u_k\in\mathcal{U}}\varphi(u_k)^2}$.
Fixed-grid probe gains describe curve shape for pair balancing; live gains in
\eqref{eq:live-gains} describe the current batch distribution for
group-gradient redistribution.  The probe gains are
\begin{align}
    \hat d^{\rm probe}_{l,g}
    =
    \sqrt{|\mathcal U|^{-1}\sum_{u_k\in\mathcal U}R'_{l,g}(u_k)^2+\epsilon_g},
    \qquad
    \hat o^{\rm probe}_{l,g}
    =
    \sqrt{|\mathcal U|^{-1}\sum_{u_k\in\mathcal U}R_{l,g}(u_k)^2+\epsilon_g},
    \label{eq:probe-gains}
\end{align}
and the current matrix log ratio is computed from the post-branch matrix blocks
with floored matrix RMS values,
\begin{align}
    \gamma_{l,g}=\log\rms_{\epsilon_p}(A_{l,g})-\log\rms_{\epsilon_p}(B_{l,g}).
    \label{eq:current-ratio}
\end{align}
Because the floor is inside both logarithms, $\gamma_{l,g}$ is a stable
implementation proxy for a matrix-RMS ratio.  The target ratio combines
curve-gain and relative-gradient terms,
\begin{align}
    \tau_{l,g}
    =
    \frac{1}{2}
    \left(
    \log \hat d^{\rm probe}_{l,g}
    -
    \log \hat o^{\rm probe}_{l,g}
    \right)
    +0.25\,\bar{\pi}_{l,g},
    \qquad
    \bar{\pi}_{l,g}=\clip(\pi_{l,g},-1.25,1.25).
    \label{eq:rescale-target}
\end{align}
The first term balances fixed-grid derivative and response gains in log space,
with the factor $1/2$ mapping the gain contrast to the matrix-pair log-ratio
coordinate; the second term adds a smaller pressure bias from the clipped
RMS-imbalance proxy.  Coefficient-gradient scale modulates the rescaling strength
through
\begin{align}
    \chi^{\rm rs}_{l,g}
    =
    \exp(0.10\,\bar{\alpha}_{l,g}),
    \qquad
    \bar{\alpha}_{l,g}=\clip(\alpha_{l,g},-1.25,1.25).
    \label{eq:rescale-activity}
\end{align}
High group coefficient activity damps the group-gradient path, while high
layer-average coefficient activity damps the Muon branch; in the bounded
rescaling step it instead moves the pair slightly faster toward the
representative ratio, with the log-step clip limiting the effect.
With schedule
\begin{align}
    s_{l,t}
    =
    0.50\,\smooth(0.03,0.35,\xi_t)
    \clip(1+0.15(\delta_l-0.5),0.75,1.25),
    \label{eq:rescale-schedule}
\end{align}
the active-step log move is
\begin{align}
    \ell_{l,g,t}
    =
    \clip\left(
    \frac{1}{2}[\tau_{l,g}-\gamma_{l,g}]s_{l,t}\chi^{\rm rs}_{l,g},
    -0.030,0.030
    \right).
    \label{eq:rescale-log-step}
\end{align}
The matrix blocks are then updated as
\begin{align}
    A_{l,g}\leftarrow e^{\ell_{l,g,t}}A_{l,g},
    \qquad
    B_{l,g}\leftarrow e^{-\ell_{l,g,t}}B_{l,g}.
    \label{eq:rescale-update}
\end{align}
The implementation applies the corresponding group scale to optimizer-state
buffers as well, using squared scales for square-average state entries.

FineWeb-Edu, FineWeb, Dolma-sample, and C4 runs use the text field specified in
the manifests, with validation slices drawn from held-out token offsets of the
same corpus stream.

\section{Rational Latent Basis Calculus}
\label{app:rlb-calculus}

The algebra supporting \eqref{eq:rlb-forward} starts with a rational response
whose denominator cannot vanish on the real line.  For one layer and one group,
suppress $(l,g)$ and write
\begin{align}
    \phi_1(u)=|u|,
    \quad
    \phi_2(u)=u^2,
    \quad
    \phi_3(u)=|u|^3,
    \quad
    \phi_4(u)=u^4,
    \notag\\
    P(u)=\sum_{i=0}^{5}a_i u^i,
    \qquad
    Q(u)=1+\sum_{j=1}^{4}|b_j|\phi_j(u).
\end{align}
Since $\phi_j(u)\ge 0$ for all real $u$, $Q(u)\ge 1$ and $R(u)=P(u)/Q(u)$ has
no real pole.  The same parameterization keeps the curve derivatives visible to
the optimizer.  For all $u\ne0$, the input derivative is
\begin{align}
    R'(u)
    =
    \frac{P'(u)Q(u)-P(u)Q'(u)}{Q(u)^2},
    \label{eq:appendix-r-prime}
\end{align}
where
\begin{align}
    P'(u)=\sum_{i=1}^{5} i a_i u^{i-1},
    \qquad
    Q'(u)=|b_1|\sign(u)+2|b_2|u+3|b_3|u|u|+4|b_4|u^3.
\end{align}
Derivative-gain statistics use the autodiff convention $\sign(0)=0$ at the
absolute-value kink.  The coefficient features are explicit:
\begin{align}
    \frac{\partial R(u)}{\partial a_i}=\frac{u^i}{Q(u)},
    \qquad
    \frac{\partial R(u)}{\partial b_j}
    =
    -\frac{P(u)}{Q(u)^2}\sign(b_j)\phi_j(u),
    \label{eq:appendix-coeff-features}
\end{align}
where $\sign(0)=0$ is also used at $b_j=0$.  The response factor $R(u)$, the
input derivative $R'(u)$, and the coefficient features in
\eqref{eq:appendix-coeff-features} are all observable from the group-global
curve.  No local-atom parameters are present in this variant.

The RMS-normalized group map turns these curve quantities into matrix-role
signals.  For a group vector $z\in\mathbb{R}^{m}$, define
\begin{align}
    r(z)=\sqrt{m^{-1}\lVert z\rVert_2^2+\epsilon_{\rm rms}},
    \qquad
    u(z)=z/r(z),
    \qquad
    h(z)=r(z)R(u(z)),
\end{align}
where $R$ is applied coordinatewise.  The radius derivative is
\begin{align}
    \mathrm{d}r
    =
    \frac{z^\top \mathrm{d}z}{m r}
    =
    \frac{u^\top\mathrm{d}z}{m},
\end{align}
and the normalized-coordinate derivative is
\begin{align}
    \mathrm{d}u
    =
    \frac{1}{r}\left(I-\frac{uu^\top}{m}\right)\mathrm{d}z.
    \label{eq:appendix-du}
\end{align}
The factor $I-uu^\top/m$ is exact in \eqref{eq:appendix-du}; it becomes the
orthogonal tangent projector to the RMS sphere only in the unfloored case where
$\epsilon_{\rm rms}=0$ and $z\ne0$.  The group Jacobian is
\begin{align}
    J_h(z)
    :=
    \frac{\partial h}{\partial z}
    =
    R(u)\frac{u^\top}{m}
    +
    \diag(R'(u))\left(I-\frac{uu^\top}{m}\right).
    \label{eq:appendix-group-jacobian}
\end{align}
The response vector $R(u)$ controls the curve factor inside the realized feature
$h=rR(u)$, while $R'(u)$ appears in the normalized-coordinate component of the
input Jacobian.  The MatrixPolicy summaries $\hat o$ and $\hat d$ are therefore
partial role signals: $\hat o$ omits the group radius $r$, and $\hat d$ omits the
radial term $R(u)u^\top/m$, the output block $B_{l,g}$, and the upstream
gradient.  These equations expose a compact set of role signals for the adjacent
matrices without requiring a full block-Jacobian preconditioner.

The same normalization also exposes a positive matrix-pair coordinate.  Set
$\epsilon_{\rm rms}=0$ and take $z\ne0$ and $\lambda>0$.  Then
\begin{align}
    r(\lambda z)=\lambda r(z),
    \qquad
    u(\lambda z)=u(z),
    \qquad
    h(\lambda z)=\lambda h(z).
\end{align}
Scaling $A_{l,g}$ by $\lambda$ and the matching column block $B_{l,g}$ by
$\lambda^{-1}$ therefore leaves the group contribution unchanged.  Applying
this independently to all groups gives \eqref{eq:positive-rescale}.

With $\epsilon_{\rm rms}>0$, define the floored maps
\begin{align}
    r_\epsilon(z)=\sqrt{m^{-1}\lVert z\rVert_2^2+\epsilon_{\rm rms}},
    \qquad
    u_\epsilon(z)=z/r_\epsilon(z),
    \qquad
    h_\epsilon(z)=r_\epsilon(z)R(u_\epsilon(z)).
\end{align}
For $\rho^2=m^{-1}\lVert z\rVert_2^2$,
\begin{align}
    u_\epsilon(\lambda z)
    =
    \kappa(\lambda,z)u_\epsilon(z),
    \qquad
    \kappa(\lambda,z)
    =
    \frac{\lambda\sqrt{\rho^2+\epsilon_{\rm rms}}}
    {\sqrt{\lambda^2\rho^2+\epsilon_{\rm rms}}}.
    \label{eq:appendix-kappa}
\end{align}
Let $L_R$ be a Lipschitz constant of the scalar curve over an interval containing
all coordinates of $u_\epsilon(z)$ and
$\kappa(\lambda,z)u_\epsilon(z)$.  After compensating the output matrix by
$\lambda^{-1}$, the group-feature error obeys
\begin{align}
    \left\|\lambda^{-1}h_\epsilon(\lambda z)-h_\epsilon(z)\right\|_2
    &\le
    \left|\frac{r_\epsilon(\lambda z)}{\lambda}-r_\epsilon(z)\right|
    \left\|R(u_\epsilon(z))\right\|_2 \\
    &\quad+
    \frac{r_\epsilon(\lambda z)}{\lambda}
    L_R |\kappa(\lambda,z)-1|\left\|u_\epsilon(z)\right\|_2 .
    \label{eq:appendix-floor-bound}
\end{align}
Both terms vanish when $\epsilon_{\rm rms}=0$.  When
$\rho^2\gg \epsilon_{\rm rms}$ and the global response and derivative are bounded
on the compact interval above, the bound is small.  Near the floor, the positive
pair-rescaling identity no longer gives a useful invariance.  MatrixPolicy
therefore uses this direction only through a clipped log step with floored matrix
RMS values and matching optimizer-state rescaling.



\section{MatrixPolicy Update Geometry}
\label{app:matrixpolicy-step}

MatrixPolicy uses the calculus above in the order imposed by one optimizer step.
Backpropagation first produces gradients with respect to the pre-update
parameters.  Pressure and activity statistics are then computed from these
gradients, $A_l^t$, $B_l^t$, and the rational coefficients before any parameter
is changed.  With EMA decay $\beta=0.95$, the matrix and coefficient statistics
have the form
\begin{align}
    q^{\rm in,t}_{l,g}
    &=
    \beta q^{\rm in,t-1}_{l,g}+(1-\beta)p^{\rm in,t}_{l,g}, \\
    q^{\rm out,t}_{l,g}
    &=
    \beta q^{\rm out,t-1}_{l,g}+(1-\beta)p^{\rm out,t}_{l,g}, \\
    q^{R,t}_{l,g}
    &=
    \beta q^{R,t-1}_{l,g}+(1-\beta)p^{R,t}_{l,g}.
\end{align}
Live curve gains are read from the RLB forward cache sampled by the optimizer's
configured statistics path and enter the group-gradient multipliers in
\eqref{eq:group-multiplier}.  The Muon fraction in \eqref{eq:muon-fraction} and
the balancing quantities in equations~\ref{eq:rescale-target}--\ref{eq:rescale-activity}
use pre-update pressure/activity EMAs.  Non-matrix Transformer parameters and
rational coefficients follow AdamW.  The RLB matrix blocks use the scaled
gradients in \eqref{eq:scaled-gradients} for the sequential AdamW and Muon matrix
branches in \eqref{eq:matrix-branch-step}.  On scheduled rescaling steps, the
positive matrix-pair move in \eqref{eq:rescale-update} is applied after the
matrix branch, and first- and second-moment-like optimizer-state buffers are
scaled in the matching direction.

The need for separate input and output matrix rules follows from the gradient
factorization around the RLB group.  For one training example, let
$\bar y_l=\nabla_{y_l}\mathcal{L}$ be the upstream gradient, and let
$J_{l,g}=\partial h_{l,g}/\partial z_{l,g}$ be the group Jacobian in
\eqref{eq:appendix-group-jacobian}.  The adjacent matrix gradients factor as
\begin{align}
    \nabla_{B_{l,g}}\mathcal{L}
    &=
    \bar y_l h_{l,g}^\top, \\
    \nabla_{A_{l,g}}\mathcal{L}
    &=
    \left(J_{l,g}^\top B_{l,g}^\top\bar y_l\right)x_l^\top .
    \label{eq:appendix-matrix-gradients}
\end{align}
The output matrix is coupled directly to the realized feature $h_{l,g}$, whereas
the input matrix is coupled to the tangent and radial components of the RLB
Jacobian before the upstream gradient reaches $x_l$.  Minibatch and sequence
gradients sum these factors over positions and examples.  Response RMS summaries
therefore align with the output role, and derivative RMS summaries align with the
input role.  They remain proxies because the full output feature contains
$r_{l,g}$, and the full input gradient depends on $B_{l,g}$, the upstream
gradient, and the radial term in \eqref{eq:appendix-group-jacobian}.

The pressure signal is a stable magnitude proxy for motion along the
input/output balance direction.  In the idealized unfloored rescaling direction,
an infinitesimal increase of the input representative and reciprocal decrease of
the output representative has the loss derivative
\begin{align}
    \Delta_g
    =
    \left\langle\nabla_{A_{l,g}}\mathcal{L},A_{l,g}\right\rangle_F
    -
    \left\langle\nabla_{B_{l,g}}\mathcal{L},B_{l,g}\right\rangle_F .
    \label{eq:appendix-signed-pressure}
\end{align}
MatrixPolicy does not estimate $\Delta_g$ directly.  Instead it uses RMS relative
gradient scales.  For nonzero unfloored $W$, if $W^+=W-\eta \mathcal{G}$ and
$\eta$ is small, then
\begin{align}
    \log \rms(W^+)-\log\rms(W)
    =
    -\eta\frac{\langle \mathcal{G},W\rangle_F}{\lVert W\rVert_F^2}+O(\eta^2),
\end{align}
and Cauchy--Schwarz implies
\begin{align}
    \left|\frac{\langle \mathcal{G},W\rangle_F}{\lVert W\rVert_F^2}\right|
    \le
    \frac{\lVert \mathcal{G}\rVert_F}{\lVert W\rVert_F}
    =
    \frac{\rms(\mathcal{G})}{\rms(W)} .
    \label{eq:appendix-pressure-bound}
\end{align}
The implemented quantities $p^{\rm in}$ and $p^{\rm out}$ are floored versions
of the upper-bound scale on the right-hand side.  They are unsigned magnitudes.
Thus $\pi_{l,g}=\log q^{\rm in}_{l,g}-\log q^{\rm out}_{l,g}$ is an
RMS-imbalance proxy: its sign identifies which role currently has the larger
relative update scale, and its clipped magnitude supplies the pressure term used
by \eqref{eq:pressure-policy} and \eqref{eq:rescale-target}.

The gain and pressure rules in equations~\ref{eq:gain-policy}--\ref{eq:pressure-policy}
are log-space redistribution rules: high derivative gain reduces the input-role
multiplier for that group, high response gain reduces the output-role multiplier,
and a positive $\pi_{l,g}$ reduces the input-role multiplier while increasing the
output-role multiplier.  Coefficient activity in \eqref{eq:activity-policy}
damps groups whose rational curve is changing faster than the adjacent matrix
pair.  These corrections would change the layer-wide step scale unless they were
centered.  Before clipping,
\begin{align}
    \widehat c_{l,g,\sigma}
    =
    \frac{c_{l,g,\sigma}}{\geom_{j=1}^{G} c_{l,j,\sigma}},
    \qquad
    \frac{1}{G}\sum_{g=1}^{G}\log \widehat c_{l,g,\sigma}=0 .
    \label{eq:appendix-centered-policy}
\end{align}
The policy redistributes update scale across groups while preserving the
role-wise mean log multiplier before clipping.  The subsequent clip in
\eqref{eq:group-center-clip} bounds noisy group statistics and can break exact
centering.

The pair-rescale target follows from equalizing the two role scales in the
positive log coordinate.  For the unfloored nonzero-matrix calculation, write
\begin{align}
    \gamma_{l,g}=\log\rms(A_{l,g})-\log\rms(B_{l,g}).
\end{align}
An active rescaling step applies
$A_{l,g}\leftarrow e^{\ell_{l,g,t}}A_{l,g}$ and
$B_{l,g}\leftarrow e^{-\ell_{l,g,t}}B_{l,g}$, hence
\begin{align}
    \gamma_{l,g}^{+}=\gamma_{l,g}+2\ell_{l,g,t}.
    \label{eq:appendix-gamma-update}
\end{align}
If clipping is ignored and
$\lambda_{l,g,t}=s_{l,t}\chi^{\rm rs}_{l,g}$ uses the schedule and activity
factor from equations~\ref{eq:rescale-activity}--\ref{eq:rescale-schedule}, then
\eqref{eq:rescale-log-step} gives
\begin{align}
    \gamma_{l,g}^{+}
    =
    (1-\lambda_{l,g,t})\gamma_{l,g}
    +
    \lambda_{l,g,t}\tau_{l,g}.
    \label{eq:appendix-rescale-contraction}
\end{align}
This is an exact contraction only in the nonzero-matrix, unfloored-RMS,
$\epsilon_{\rm rms}=0$, unclipped idealization.  The implementation uses the
floored proxy in \eqref{eq:current-ratio}; near the floor, the log-ratio
interpretation and the contraction model are approximate.

Under reciprocal rescaling, the input-side role scale varies as
$\hat d^{\rm probe}e^{-\gamma}$ and the output-side role scale varies as
$\hat o^{\rm probe}e^{\gamma}$, up to the group-independent constants already
absorbed by RMS normalization and centering.  Equalizing these two log scales
gives
$\gamma^\star=\frac{1}{2}(\log\hat d^{\rm probe}-\log\hat o^{\rm probe})$.
MatrixPolicy adds a smaller clipped RMS-pressure bias:
\begin{align}
    \tau_{l,g}
    =
    \frac{1}{2}
    \left(
    \log \hat d^{\rm probe}_{l,g}
    -
    \log \hat o^{\rm probe}_{l,g}
    \right)
    +0.25\,\bar{\pi}_{l,g},
    \qquad
    \bar{\pi}_{l,g}=\clip(\pi_{l,g},-1.25,1.25)
\end{align}
using fixed-grid probe gains from \eqref{eq:probe-gains}.  Probe gains make the
balance target depend on the current curve shape rather than the current sampled
feature distribution, while the $\bar\pi$ term lets recent matrix-pressure
imbalance shift the target within a bounded range.

The final pair-rescale operation follows the approximate representative geometry
above.  The AdamW/Muon branch in \eqref{eq:matrix-branch-step} updates the
