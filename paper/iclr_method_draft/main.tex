\begin{abstract}
Transformer MLP sublayers are usually optimized as ordinary matrix blocks, even
though their input matrix, scalar nonlinearity, and output matrix play different
roles.  We study Rational Latent Basis (RLB), a Transformer sublayer that makes
these roles explicit by inserting grouped rational curves between the two
matrices, and MatrixPolicy, an optimizer that uses the resulting matrix roles and
cheap curve statistics during pretraining.  The paper-facing RLB variant is the
global-rational/no-local-atom version: each group uses one trainable P5/Q4
rational curve initialized from SiLU, with no local atom path and no atom
parameter group.  MatrixPolicy applies a manifest-enabled group-gradient policy,
a role/depth matrix update with a short early matrix-normalized branch, and a
bounded positive rescaling of each input/output matrix pair, while all non-matrix
parameters are updated by AdamW.  We separate exact properties of the RLB
parameterization from heuristic optimizer choices so that the empirical claims
can be audited against matched activation and optimizer controls.
\end{abstract}

\section{Method}
\label{sec:method}

This section defines the method used for the E1 and E2 paper-facing runs.  The
activation part is a global-rational RLB sublayer, and the optimizer part is
MatrixPolicy.  The claim is not that the rational activation alone is sufficient:
the matched RLB controls use the same global-rational/no-local-atom sublayer with
standard or published optimizers, while the MatrixPolicy row changes only how the
RLB matrix roles are optimized.

\subsection{Global-Rational RLB}
\label{sec:method-rlb}

Consider Transformer layer $l\in\{1,\ldots,L\}$ with sublayer input
$x_l\in\mathbb{R}^{d}$.  RLB replaces the usual Transformer MLP sublayer by a
single projected representation of width $H=Gm$, divided into $G$ groups of width
$m$.  The input matrix $A_l\in\mathbb{R}^{H\times d}$ produces
\begin{align}
    z_l=A_lx_l,\qquad
    z_l=\operatorname{concat}_{g=1}^{G}z_{l,g},\qquad
    z_{l,g}\in\mathbb{R}^{m}.
    \label{eq:rlb-projection}
\end{align}
Each group is normalized by its root-mean-square radius
\begin{align}
    r_{l,g}
    =
    \sqrt{m^{-1}\lVert z_{l,g}\rVert_2^2+\epsilon_{\rm rms}},
    \qquad
    u_{l,g}=z_{l,g}/r_{l,g},
    \label{eq:rlb-normalization}
\end{align}
where $\epsilon_{\rm rms}>0$ is a numerical floor.  A scalar rational curve
$R_{l,g}$ is then applied coordinatewise to $u_{l,g}$ and multiplied back by the
same radius:
\begin{align}
    h_{l,g}=r_{l,g}R_{l,g}(u_{l,g}),\qquad
    h_l=\operatorname{concat}_{g=1}^{G}h_{l,g},\qquad
    y_l=B_lh_l ,
    \label{eq:rlb-output}
\end{align}
with output matrix $B_l\in\mathbb{R}^{d\times H}$.  The tensor $y_l$ is inserted
at the same block location as the standard MLP-sublayer output.

The main RLB variant uses one global rational curve per layer and group,
\begin{align}
    R_{l,g}(u)=\frac{P_{l,g}(u)}{Q_{l,g}(u)},\qquad
    P_{l,g}(u)=\sum_{i=0}^{5}a_{l,g,i}u^i,
    \label{eq:global-rational-p}
\end{align}
where
\begin{align}
    Q_{l,g}(u)
    =
    1+|b_{l,g,1}|\,|u|+|b_{l,g,2}|\,u^2
     +|b_{l,g,3}|\,|u|^3+|b_{l,g,4}|\,u^4 .
    \label{eq:global-rational-q}
\end{align}
The coefficients are initialized by a least-squares SiLU fit on a fixed probe
interval and are trained with the model.  Equation~\eqref{eq:global-rational-q}
is pole-safe on real inputs because every nonconstant denominator term is
nonnegative, so $Q_{l,g}(u)\ge 1$ for all real $u$.  The denominator is piecewise
smooth because of the absolute values, which is the intended tradeoff for
avoiding real poles during pretraining.

The phrase \emph{global rational} means that the learned nonlinear response is
only the P5/Q4 curve in \eqref{eq:global-rational-p} and
\eqref{eq:global-rational-q}.  The paper-facing configuration has no local
Cauchy atoms, no atom centers, no atom coefficients, and no atom parameter
group.  MatrixPolicy rows and non-MatrixPolicy RLB optimizer controls use this
same activation source.

The RLB matrix pair has a limited positive rescaling identity.  Let
$D_l(a)=\operatorname{diag}(a_1I_m,\ldots,a_GI_m)$ for
$a\in\mathbb{R}_{>0}^{G}$, let $R_l=\{R_{l,g}\}_{g=1}^{G}$, and write
$f_l(x;A_l,B_l,R_l)$ for the map in \eqref{eq:rlb-projection} through
\eqref{eq:rlb-output}.  If $\epsilon_{\rm rms}=0$ and all group radii are
nonzero, then
\begin{align}
    f_l(x;A_l,B_l,R_l)
    =
    f_l(x;D_l(a)A_l,B_lD_l(a)^{-1},R_l).
    \label{eq:positive-rescale}
\end{align}
This identity is not a claim that the full training objective is invariant:
weight decay, optimizer moments, finite-precision arithmetic, and the RMS floor
all matter in the implemented system.  We use it only as a local explanation for
why a bounded post-step rescaling of $A_l$ and $B_l$ can control matrix scale
without changing the represented block map in the homogeneous idealization.

\subsection{MatrixPolicy}
\label{sec:method-matrixpolicy}

MatrixPolicy applies only to the RLB matrix set
$\{A_l,B_l\}_{l=1}^{L}$.  Non-matrix parameters, including embeddings, attention
weights, normalization parameters, and the rational numerator and denominator
coefficients, are updated by the AdamW child optimizer
\citep{kingma2015iclr-adam,loshchilov2019decoupled}.  A separate rational
coefficient optimizer exists in the code but is inactive in the main method.

MatrixPolicy uses two kinds of statistics.  The first kind is gradient pressure.
For any tensor $V$, define the floored RMS
\begin{align}
    \rms_{\epsilon}(V)=\sqrt{\operatorname{mean}(V^2)+\epsilon}.
\end{align}
All RMS quantities used below inside logarithms, denominators, or probe-gain
ratios are implemented with the corresponding small positive floor; we write
plain $\rms$ only when the exact floor value is not a design parameter.  For
group $g$, let $A_{l,g}\in\mathbb{R}^{m\times d}$ be the row block of
$A_l$ and let $B_{l,g}\in\mathbb{R}^{d\times m}$ be the column block of $B_l$.
With floor $\epsilon_p>0$, the implemented relative matrix-gradient pressures
are
\begin{align}
    p^{\rm in}_{l,g}
    =
    \frac{\rms_{\epsilon_p}(\nabla A_{l,g})}
    {\max\{\rms_{\epsilon_p}(A_{l,g}),\epsilon_p\}},
    \qquad
    p^{\rm out}_{l,g}
    =
    \frac{\rms_{\epsilon_p}(\nabla B_{l,g})}
    {\max\{\rms_{\epsilon_p}(B_{l,g}),\epsilon_p\}} .
    \label{eq:matrix-pressure}
\end{align}
For the global-rational variant, the rational activity statistic is
\begin{align}
    p^{R}_{l,g}
    =
    \left[
    \frac{1}{2}\left(
    \operatorname{mean}((\nabla a_{l,g,\cdot})^2)
    +
    \operatorname{mean}((\nabla b_{l,g,\cdot})^2)
    \right)
    +\epsilon_p
    \right]^{1/2}.
    \label{eq:rational-activity-raw}
\end{align}
Let $q^{\rm in}_{l,g}$, $q^{\rm out}_{l,g}$, and $q^{R}_{l,g}$ be exponential
moving averages of \eqref{eq:matrix-pressure} and
\eqref{eq:rational-activity-raw} with decay $0.95$, floored before logarithms.
MatrixPolicy forms
\begin{align}
    \pi_{l,g}
    =
    \log q^{\rm in}_{l,g}-\log q^{\rm out}_{l,g},
    \qquad
    \alpha_{l,g}
    =
    \log q^{R}_{l,g}
    -\frac{1}{2}\left(\log q^{\rm in}_{l,g}+\log q^{\rm out}_{l,g}\right).
    \label{eq:pressure-activity}
\end{align}
The pressure $\pi_{l,g}$ measures relative update pressure between the input and
output matrix roles.  The activity $\alpha_{l,g}$ measures whether rational
coefficients are receiving large gradients relative to the adjacent matrix
pressures.

The second kind of statistic is curve gain.  During the activation forward path,
RLB caches statistics from a recent sample of normalized coordinates
$u_{l,g}$, refreshed every configured statistic interval from at most 512
samples.  MatrixPolicy uses the most recent cache:
\begin{align}
    d^{\rm live}_{l,g}=\rms(R'_{l,g}(u_{l,g})),
    \qquad
    o^{\rm live}_{l,g}=\rms(R_{l,g}(u_{l,g})).
    \label{eq:live-gains}
\end{align}
These quantities are deliberately not full block Jacobians.  Derivative gain is
a cheap proxy for the input-domain matrix $A_l$, and output gain is a cheap proxy
for the recombination matrix $B_l$.

Let $t$ be the optimizer step, $T$ the planned number of steps, and
$\xi_t=t/T$.  The paper-facing manifests enable the group-gradient policy with
strengths that are zero by parser default and nonzero in the submitted rows.  Its
phase is
\begin{align}
    \phi_t=\smooth(0.02,0.30,\xi_t),
    \label{eq:group-phase}
\end{align}
where $\smooth(a,b,\xi)$ is the cubic smoothstep gate from $0$ to $1$ over
$[a,b]$.  For positive group values $v_j$, let
$\geom_j v_j=\exp(G^{-1}\sum_{j=1}^{G}\log v_j)$.  For matrix role
$r\in\{\mathrm{in},\mathrm{out}\}$, the group multiplier is
\begin{align}
    c_{l,g,r}
    =
    c^{\rm gain}_{l,g,r}
    c^{\rm pressure}_{l,g,r}
    c^{\rm activity}_{l,g}.
    \label{eq:group-multiplier}
\end{align}
For the input role, gain uses $d^{\rm live}_{l,g}$; for the output role, it uses
$o^{\rm live}_{l,g}$:
\begin{align}
    c^{\rm gain}_{l,g,\mathrm{in}}
    =
    \left(\frac{\geom_j d^{\rm live}_{l,j}}{d^{\rm live}_{l,g}}\right)^{0.20\phi_t},
    \qquad
    c^{\rm gain}_{l,g,\mathrm{out}}
    =
    \left(\frac{\geom_j o^{\rm live}_{l,j}}{o^{\rm live}_{l,g}}\right)^{0.20\phi_t}.
    \label{eq:gain-policy}
\end{align}
With clipped pressure $\tilde{\pi}_{l,g}=\clip(\pi_{l,g},-1.50,1.50)$,
\begin{align}
    c^{\rm pressure}_{l,g,\mathrm{in}}
    =
    \exp(-0.10\phi_t\tilde{\pi}_{l,g}),
    \qquad
    c^{\rm pressure}_{l,g,\mathrm{out}}
    =
    \exp(+0.10\phi_t\tilde{\pi}_{l,g}).
    \label{eq:pressure-policy}
\end{align}
The rational-activity term damps both matrix roles when rational coefficients
are unusually active:
\begin{align}
    c^{\rm activity}_{l,g}
    =
    \exp\left[
    -0.20\phi_t
    \relu\left(\frac{\alpha_{l,g}-0.05}{0.45}\right)
    \right].
    \label{eq:activity-policy}
\end{align}
The multiplier is then recentered and clipped:
\begin{align}
    c_{l,g,r}\leftarrow
    \frac{c_{l,g,r}}{\geom_j c_{l,j,r}},
    \qquad
    c_{l,g,r}\leftarrow\clip(c_{l,g,r},0.75,1.35).
    \label{eq:group-center-clip}
\end{align}
Centering makes the mean log multiplier zero before clipping, so the group rule
redistributes matrix update budget instead of silently changing the global
learning rate.

After group-gradient scaling, each RLB matrix is updated by a role/depth AdamW
branch and a short early matrix-normalized branch.  Define normalized depth
$\delta_l=(l-1)/(L-1)$ when $L>1$, with $\delta_l=1/2$ otherwise.  The role
factors are
\begin{align}
    \rho_{\mathrm{in}}(l)
    =
    \clip(1-0.50(\delta_l-0.5),0.55,1.40),
    \qquad
    \rho_{\mathrm{out}}(l)
    =
    \clip(1+1.00(\delta_l-0.5),0.55,1.40).
    \label{eq:role-factors}
\end{align}
The AdamW learning-rate multiplier for role $r$ is
\begin{align}
    s^{\rm Adam}_{l,r}
    =
    \clip\left(
    3.0\max\{0.10,1+1.20(\rho_r(l)-1)\},
    0.40,4.0
    \right).
    \label{eq:adam-role-scale}
\end{align}
The early matrix-normalized fraction is reduced when pressure imbalance or
rational activity is large.  Define
\begin{align}
    \Psi_{l,t}
    =
    \frac{1}{G}\sum_{g=1}^{G}
    \left|\clip(\pi_{l,g},-1.50,1.50)\right|,
    \qquad
    \Omega_{l,t}
    =
    \frac{1}{G}\sum_{g=1}^{G}
    \relu\left(\frac{\alpha_{l,g}-0.05}{0.45}\right),
    \label{eq:pressure-activity-aggregates}
\end{align}
and
\begin{align}
    \psi_{l,t}
    =
    \clip\left(\exp[-0.30\Psi_{l,t}-0.65\Omega_{l,t}],0.10,1.15\right).
    \label{eq:stat-penalty}
\end{align}
The branch fraction is
\begin{align}
    \mu_{l,r,t}
    =
    \clip\left(
    0.75
    \smooth(0.02,0.12,\xi_t)
    [1-\smooth(0.20,0.36,\xi_t)]
    \rho_r(l)\psi_{l,t},
    0,0.75
    \right).
    \label{eq:muon-fraction}
\end{align}
For matrix $M_{l,r}$, where $M_{l,\mathrm{in}}=A_l$ and
$M_{l,\mathrm{out}}=B_l$, the implementation composes two stateful child
updates:
\begin{equation}
\begin{gathered}
    \widetilde M_{l,r}^{\,t+1}
    =
    \operatorname{AdamW}_{\eta_t s^{\rm Adam}_{l,r}(1-\mu_{l,r,t})}
    (M_{l,r}^{t};\nabla M_{l,r}^{t}),\\
    M_{l,r}^{t+1}
    =
    \matnorm_{\eta_t\mu_{l,r,t}}
    (\widetilde M_{l,r}^{\,t+1};\nabla M_{l,r}^{t}).
\end{gathered}
    \label{eq:matrix-child-step}
\end{equation}
Here $\eta_t$ is the base learning rate, and $\matnorm$ denotes the
matrix-normalized branch with momentum and Newton-Schulz normalization.  The
formula describes operational order, not an additive closed-form optimizer.
After $\mu_{l,r,t}$ is permanently zero for all matrix groups, the implementation
skips the zero-learning-rate matrix-normalized child step; this is a runtime-only
optimization.

Finally, the wrapper applies a bounded positive rescaling to each group of the
matrix pair.  On a fixed probe grid $u\in[-5,5]$, define
\begin{align}
    d^{\rm probe}_{l,g}=\rms(R'_{l,g}(u)),
    \qquad
    o^{\rm probe}_{l,g}=\rms(R_{l,g}(u)).
    \label{eq:probe-gains}
\end{align}
Let the current log matrix ratio be
\begin{align}
    \gamma_{l,g}
    =
    \log\rms(A_{l,g})-\log\rms(B_{l,g}).
    \label{eq:current-ratio}
\end{align}
The target log ratio is the heuristic
\begin{align}
    \tau_{l,g}
    =
    \frac{1}{2}
    \left(
    \log d^{\rm probe}_{l,g}
    -
    \log o^{\rm probe}_{l,g}
    \right)
    +0.25\,\bar{\pi}_{l,g},
    \qquad
    \bar{\pi}_{l,g}=\clip(\pi_{l,g},-1.25,1.25).
    \label{eq:rescale-target}
\end{align}
Rational activity modulates the strength:
\begin{align}
    a^{\rm rs}_{l,g}
    =
    \exp\left(
    \clip(0.10\,\bar{\alpha}_{l,g},\log 0.75,\log 1.25)
    \right),
    \qquad
    \bar{\alpha}_{l,g}=\clip(\alpha_{l,g},-1.25,1.25).
    \label{eq:rescale-activity}
\end{align}
With
\begin{align}
    s_{l,t}
    =
    0.50\,\smooth(0.03,0.35,\xi_t)
    \clip(1+0.15(\delta_l-0.5),0.75,1.25),
    \label{eq:rescale-schedule}
\end{align}
the log move is
\begin{align}
    \ell_{l,g,t}
    =
    \clip\left(
    \frac{1}{2}[\tau_{l,g}-\gamma_{l,g}]
    s_{l,t}a^{\rm rs}_{l,g},
    -0.030,0.030
    \right),
    \label{eq:rescale-log-step}
\end{align}
and the matrices are updated by
\begin{align}
    A_{l,g}\leftarrow e^{\ell_{l,g,t}}A_{l,g},
    \qquad
    B_{l,g}\leftarrow e^{-\ell_{l,g,t}}B_{l,g}.
    \label{eq:rescale-update}
\end{align}
When compatible optimizer moment tensors exist, their states are scaled
covariantly.  In the homogeneous idealization of \eqref{eq:positive-rescale},
\eqref{eq:rescale-update} changes only the representative of the same block map.
With the RMS floor, the move is approximate, which is why it is clipped and run
only as a bounded post-step correction.  The pressure term in
\eqref{eq:rescale-target} is a relative-update heuristic, not an exact
quotient-space gradient.

\subsection{Reproducibility Boundary}
\label{sec:method-boundary}

The active paper-facing configuration is manifest-first.  The MatrixPolicy rows
use \texttt{rlb\_fused\_global\_rational} with grouped P5/Q4 rational curves,
SiLU initialization, and no local atoms.  The backbone and rational coefficients
use AdamW.  The RLB input and output matrices use the MatrixPolicy child
optimizer, with group-gradient policy enabled by the manifest flags
\texttt{--rational-matrix-policy-group-gain-strength 0.20},
\texttt{--rational-matrix-policy-group-pressure-strength 0.10},
\texttt{--rational-matrix-policy-group-activity-damping 0.20},
\texttt{--rational-matrix-policy-group-start 0.02},
\texttt{--rational-matrix-policy-group-end 0.30},
\texttt{--rational-matrix-policy-group-min-scale 0.75}, and
\texttt{--rational-matrix-policy-group-max-scale 1.35}.  The parser defaults
for the three strengths are zero, and the default group end/clip values differ,
so reproducing the paper rows requires the manifest settings.

The active numerical surface is as follows.  Matrix AdamW uses the multiplier in
\eqref{eq:adam-role-scale}.  The matrix-normalized branch uses maximum fraction
$0.75$, momentum $0.95$, five Newton-Schulz steps, and the schedule in
\eqref{eq:muon-fraction}; its final and minimum fractions are both zero.  The
group-gradient policy uses pressure clip $1.50$, activity target $0.05$,
activity width $0.45$, activation window $0.02$ to $0.30$ of training progress,
and multiplier clip $[0.75,1.35]$.  The bounded positive rescaling runs every
five optimizer steps, uses 129 probe points on $[-5,5]$, target weight $1.0$,
strength $0.50$, activation window $0.03$ to $0.35$, pressure coefficient
$0.25$, pressure clip $1.25$, activity coefficient $0.10$, activity-gain clamp
$[0.75,1.25]$, and maximum absolute log step $0.030$.

The following branches are inactive in the main method: the separate rational
coefficient optimizer, coefficient Gram preconditioning, transport/quotient
projection, transport matrix gain preconditioning, and transport pressure
preconditioning.  They remain research hooks in the codebase, but they are not
part of the reported E1/E2 method unless a manifest explicitly enables them.

\section{Exact Mathematical Checks}
\label{app:math-checks}

\paragraph{Pole-safe denominator.}
For one group, the denominator
\begin{align}
    Q(u)=1+|b_1|\,|u|+|b_2|u^2+|b_3|\,|u|^3+|b_4|u^4
\end{align}
satisfies $Q(u)\ge 1$ for every real $u$, independently of the raw signs of
$b_i$.  Thus $P(u)/Q(u)$ has no real pole.  The absolute values make the curve
piecewise smooth; this is a numerical design choice, not a theorem about global
optimization.

\paragraph{Positive rescaling identity.}
Set $\epsilon_{\rm rms}=0$ and consider a nonzero group.  For any $a>0$,
\begin{align}
    r(az)=\sqrt{m^{-1}\lVert az\rVert_2^2}=a r(z),
    \qquad
    u(az)=\frac{az}{r(az)}=\frac{z}{r(z)}=u(z).
\end{align}
Therefore
\begin{align}
    h(az)=r(az)R(u(az))=a r(z)R(u(z))=a h(z).
\end{align}
Scaling the matching output columns by $a^{-1}$ leaves the group contribution to
$B_lh_l$ unchanged.  Applying this argument independently to all groups proves
\eqref{eq:positive-rescale}.  The identity requires positive scaling; negative
scaling would flip the normalized coordinate and is not generally a symmetry of
a learned rational curve.

\paragraph{Effect of the RMS floor.}
With $\epsilon_{\rm rms}>0$, scaling a group gives
\begin{align}
    u_{\epsilon}(az)
    =
    \frac{az}
    {\sqrt{a^2m^{-1}\lVert z\rVert_2^2+\epsilon_{\rm rms}}}
    =
    \kappa(a,z)u_{\epsilon}(z),
\end{align}
where
\begin{align}
    \kappa(a,z)
    =
    \frac{a\sqrt{m^{-1}\lVert z\rVert_2^2+\epsilon_{\rm rms}}}
    {\sqrt{a^2m^{-1}\lVert z\rVert_2^2+\epsilon_{\rm rms}}}.
\end{align}
When $m^{-1}\lVert z\rVert_2^2\gg\epsilon_{\rm rms}$,
$\kappa(a,z)\approx 1$ and the homogeneous identity is a good local model.  Near
the floor, $\kappa(a,z)$ can differ from $1$, so the implemented rescaling is not
exactly function-preserving.  This is the reason for the small log-step clip in
\eqref{eq:rescale-log-step}; the paper does not claim exact invariance for the
stabilized implementation.

\section{Why These Signals Are Plausible but Not Proofs}
\label{app:rationale}

The output matrix has a direct first-order effect
\begin{align}
    \delta y_{l,g}=\delta B_{l,g}h_{l,g}.
\end{align}
Because $h_{l,g}=r_{l,g}R_{l,g}(u_{l,g})$, the RMS of $R_{l,g}(u_{l,g})$ is a
cheap proxy for how strongly the group feeds the recombination matrix.  This
motivates the output gain $o_{l,g}$.  The input matrix changes the pre-normalized
coordinate.  In the homogeneous-radius case, the differential of
$h(z)=r(z)R(z/r(z))$ contains
\begin{align}
    \mathrm{d}h
    =
    \mathrm{d}r\,R(u)
    +
    r\,\operatorname{diag}(R'(u))\,\mathrm{d}u,
\end{align}
along with terms from the RMS normalization.  MatrixPolicy does not estimate the
full Transformer-block Jacobian.  It uses the scalar derivative RMS
$d_{l,g}$ as a stable, low-cost input-side sensitivity proxy and recenters the
resulting inverse-gain multiplier across groups.

The pressure statistic is also heuristic.  In the exact homogeneous model, the
infinitesimal transform $A_{l,g}\mapsto e^sA_{l,g}$ and
$B_{l,g}\mapsto e^{-s}B_{l,g}$ leaves the block map unchanged, so an unregularized
loss would have zero derivative along that direction:
\begin{align}
    \langle\nabla_{A_{l,g}}\mathcal{L},A_{l,g}\rangle_F
    -
    \langle\nabla_{B_{l,g}}\mathcal{L},B_{l,g}\rangle_F
    =
    0.
\end{align}
The implementation intentionally does not use this signed inner product.  It
uses the RMS ratio in \eqref{eq:matrix-pressure}, which is less sensitive to
cancellation and closer to the scale of an optimizer update.  Therefore
$\pi_{l,g}$ should be read as relative update pressure, not as an exact quotient
gradient or a natural-gradient estimate.

The early matrix-normalized branch is motivated by training dynamics rather than
an invariance theorem.  Early in training, the RLB matrices decide which
normalized coordinates the rational curves see and how those features return to
the residual stream.  A temporary matrix-normalized direction update can change
these domains quickly.  Later, after the rational curves, attention layers, and
output recombinations have co-adapted, keeping that branch active adds runtime
and can obscure the role/depth AdamW policy.  MatrixPolicy therefore schedules
the branch early and decays it to zero through \eqref{eq:muon-fraction}.

Removing local atoms is both an a priori and an a posteriori choice for this
paper.  A priori, the global-rational variant is the cleaner object for an
optimizer study: each group has one rational curve, one input matrix block, and
one output matrix block, with no extra atom tensor that could introduce a
separate optimizer failure mode.  A posteriori, all MatrixPolicy and
non-MatrixPolicy RLB optimizer controls in the paper-facing E1/E2 tables use the
same global-rational/no-local-atom activation source, so performance differences
are attributed to optimizer behavior rather than to a local atom path.

\section{Runtime and Failure Accounting}
\label{app:accounting}

Runtime tables should report clean training-process time from completed JSONL
summary records.  Queue wait, dependency wait, token-cache construction,
extension compilation, launcher overhead, and discarded pre-restart partial
attempts are not optimizer runtime.  If a completed artifact cannot reconstruct
trusted per-row training time after preemption, the row must be rerun or marked
as unrepaired rather than silently averaged into the runtime table.

Failures are not excluded from the scientific record.  If an
optimizer/activation pair diverges or early-stops under the stated protocol, it
is reported as diverged or early-stopped under the same stopping rule.  The
accounting rule only separates training behavior from systems artifacts such as
preempted allocations or known-bad timing nodes.
