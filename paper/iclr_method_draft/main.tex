\section{Rational Matrix Policy Optimization}
\label{sec:method}

Rational Latent Basis (RLB) parameterizes each Transformer MLP sublayer as
grouped rational features with explicit input and output matrix factors.  The
term latent refers to the learned projected coordinates $z_l$, not to local atom
centers.  This exposes groupwise sensitivities, relative update pressures, and a
positive scale gauge that a standard optimizer does not distinguish.
MatrixPolicy is the corresponding matrix-specific optimizer rule.  Our main
configuration uses the fused global-rational RLB variant: a single-branch RLB
sublayer with grouped trainable degree-5 numerator and degree-4 denominator
rational curves, no local atom branch, and no atom parameter group.

\subsection{Global-Rational RLB Sublayer}
\label{sec:method-activation}

For a Transformer layer $l$, let $x_l\in\mathbb{R}^d$ be the MLP input.  RLB
replaces the usual gated/value activation by a single rational branch
\begin{align}
    z_l=A_lx_l,\qquad z_{l,g}\in\mathbb{R}^m,\qquad H=Gm,
\end{align}
where $A_l\in\mathbb{R}^{H\times d}$ and the hidden coordinates are partitioned
into $G$ groups.  Each group is evaluated in normalized coordinates,
\begin{align}
    r_{l,g}=\sqrt{m^{-1}\lVert z_{l,g}\rVert_2^2+\epsilon_{\rm rms}},
    \qquad u_{l,g}=z_{l,g}/r_{l,g},
\end{align}
then mapped coordinatewise by a learned rational curve and rescaled by the same
radius:
\begin{align}
    h_{l,g}=r_{l,g}R_{l,g}(u_{l,g}),\qquad
    y_l=B_l\operatorname{concat}_{g=1}^{G} h_{l,g}.
\end{align}
Here $B_l\in\mathbb{R}^{d\times H}$ recombines the rational features.  The
global-rational curve is
\begin{align}
    R_{l,g}(u)=\frac{P_{l,g}(u)}{Q_{l,g}(u)},\qquad
    P_{l,g}(u)=\sum_{i=0}^{5} a_{l,g,i}u^i,
    \label{eq:rlb-numerator}
\end{align}
with the pole-safe denominator
\begin{align}
    Q_{l,g}(u)=1+|b_{l,g,1}|\,|u|+|b_{l,g,2}|u^2
      +|b_{l,g,3}|\,|u|^3+|b_{l,g,4}|u^4 .
    \label{eq:rlb-denominator}
\end{align}
All denominator terms are nonnegative on the real line, so $Q_{l,g}(u)\ge 1$ and
there are no real poles.  The coefficients are initialized from a SiLU fit on a
fixed probe interval and then trained.  Because \eqref{eq:rlb-denominator}
contains absolute-value terms, the curve is pole-safe and piecewise smooth rather
than a globally smooth rational polynomial quotient.  Global here means that the
nonlinear correction is the groupwise rational curve itself, with no local atom
basis around fixed centers; coefficients remain layer- and group-specific.

\subsection{Why This Parameterization Matters}
\label{sec:method-structure}

RLB separates three roles that a standard optimizer would otherwise treat nearly
uniformly.  The input matrix $A_l$ chooses the rational domains; the rational
coefficients set the response and derivative profile in those domains; the output
matrix $B_l$ recombines rational features into the residual stream.  Write
$f_l(x;A_l,B_l,R_l)$ for the RLB block map defined above, where $R_l$ collects
all group rational curves in layer $l$.  The group RMS normalization also creates
a positive scale gauge between $A_l$ and $B_l$.  In the homogeneous idealization
$\epsilon_{\rm rms}=0$, for nonzero group radii, any positive group scales
$a_g>0$, and block matrix $D_l(a)=\operatorname{diag}(a_1I_m,\ldots,a_GI_m)$,
\begin{align}
    f_l(x;A_l,B_l,R_l)=f_l(x;D_l(a)A_l,B_lD_l(a)^{-1},R_l).
    \label{eq:gauge-invariance}
\end{align}
Thus many matrix representatives encode the same block function.  The training rule
uses a stabilizing RMS floor, so \eqref{eq:gauge-invariance} is not an exact
training-time invariance.  We use it as a design principle: the
optimizer should control motion in the represented function while preventing
uncontrolled drift in the matrix representative.  Appendix~\ref{app:gauge-proof}
proves the homogeneous identity and states the floor-induced discrepancy.

In the main configuration, MatrixPolicy is applied only to the RLB matrices
$\{A_l,B_l\}_{l=1}^{L}$.  All non-matrix parameters, including attention,
embeddings, layer norms, and the rational numerator/denominator coefficients, are
updated by the AdamW-backed non-matrix optimizer.  This partition is important:
the method does not rely on a separate coefficient optimizer, and it does not
introduce any local-atom coefficient group.

\subsection{MatrixPolicy}
\label{sec:method-optimizer}

MatrixPolicy combines three operations: on-policy group scaling, a role/depth
matrix update, and a post-step gauge rebalance.  Let
$r\in\{\mathrm{in},\mathrm{out}\}$ denote the matrix role, with
$M_{l,\mathrm{in}}=A_l$ and $M_{l,\mathrm{out}}=B_l$.  We write
$A_{l,g}\in\mathbb{R}^{m\times d}$ for the input row block of group $g$ and
$B_{l,g}\in\mathbb{R}^{d\times m}$ for the matching output column block.
Before the optimizer step, MatrixPolicy records relative update pressures for
each rational group,
\begin{align}
    p_{\mathrm{in},g}=\frac{\rms(\nabla A_{l,g})}{\rms(A_{l,g})},\qquad
    p_{\mathrm{out},g}=\frac{\rms(\nabla B_{l,g})}{\rms(B_{l,g})},\qquad
    p_{\mathrm{rat},g}=\rms(\nabla\theta_{R,l,g}),
\end{align}
where $\theta_{R,l,g}$ denotes the raw numerator coefficients and denominator
parameters before the absolute-value map in \eqref{eq:rlb-denominator}.  Let
$q_{\mathrm{in},g}$, $q_{\mathrm{out},g}$, and $q_{\mathrm{rat},g}$ be EMAs of
these quantities, with all RMS values and EMAs floored by a small positive
constant before logarithms.  MatrixPolicy uses
\begin{align}
    \pi_g=\log q_{\mathrm{in},g}-\log q_{\mathrm{out},g},\qquad
    \alpha_g=\log q_{\mathrm{rat},g}
       -\frac{1}{2}(\log q_{\mathrm{in},g}+\log q_{\mathrm{out},g}),
    \label{eq:pressure-activity}
\end{align}
as pressure and rational-activity signals.  Let $T$ be the training-step budget,
$\xi_t=t/T$, and let $\sigma_{a,b}(\xi)$ be the smoothstep gate from $0$ to $1$
over $[a,b]$.  We write
$\tilde\pi_g=\clip(\pi_g,-p_{\max}^{\mathrm{grp}},p_{\max}^{\mathrm{grp}})$ and
$\phi_t=\sigma_{0.02,0.30}(\xi_t)$ for the clipped pressure and group-policy
schedule.  The geometric mean over groups is
$\geom_g(c)=\exp(G^{-1}\sum_{g=1}^G\log c_g)$.

The group-gradient multiplier is centered and clipped:
\begin{align}
\begin{aligned}
    c_{g,r}&=c^{\mathrm{gain}}_{g,r}c^{\mathrm{pressure}}_{g,r}
       c^{\mathrm{activity}}_{g},\\
    c_{g,r}&\leftarrow c_{g,r}/\geom_g(c_{g,r}),\\
    c_{g,r}&\leftarrow \clip(c_{g,r},c_{\min},c_{\max}).
\end{aligned}
\label{eq:group-scale}
\end{align}
For the input matrix, the gain term uses the rational derivative RMS $d_g$; for
the output matrix, it uses the rational output RMS $o_g$ measured on normalized
coordinates,
\begin{align}
    d_g=\rms(R'_{l,g}(u_{l,g})),\qquad
    o_g=\rms(R_{l,g}(u_{l,g})),
\end{align}
with the RMS taken over sampled normalized coordinates and stabilized by the same
small positive floors used in training.  The gain factors are
\begin{align}
    c^{\mathrm{gain}}_{g,\mathrm{in}}
       =\left(\frac{\geom(d)}{d_g}\right)^{\lambda_g\phi_t},\qquad
    c^{\mathrm{gain}}_{g,\mathrm{out}}
       =\left(\frac{\geom(o)}{o_g}\right)^{\lambda_g\phi_t}.
\end{align}
The pressure term moves the two matrix roles in opposite directions,
\begin{align}
    c^{\mathrm{pressure}}_{g,\mathrm{in}}=\exp(-\lambda_p\phi_t\tilde\pi_g),\qquad
    c^{\mathrm{pressure}}_{g,\mathrm{out}}=\exp(+\lambda_p\phi_t\tilde\pi_g),
\end{align}
and the rational-activity term damps matrix updates when coefficient gradients
are large relative to matrix gradients.  Here $\alpha_0$ is the activity target
and $w_\alpha>0$ is the activity transition width:
\begin{align}
    c^{\mathrm{activity}}_g
    =\exp\left[-\lambda_a\phi_t\relu\left(\frac{\alpha_g-\alpha_0}{w_\alpha}\right)\right].
\end{align}
Geometric centering keeps the average log multiplier at zero before the final
clip; the clip bounds the influence of noisy per-group statistics.  In the main
configuration, $(\lambda_g,\lambda_p,\lambda_a)=(0.20,0.10,0.20)$,
$(\alpha_0,w_\alpha)=(0.05,0.45)$, $p_{\max}^{\mathrm{grp}}=1.50$, and
$(c_{\min},c_{\max})=(0.75,1.35)$.

After group scaling, each RLB matrix receives a role/depth AdamW step and,
when active, a matrix-normalized step.  The AdamW matrix scale is
\begin{align}
    a_{l,r}=\clip\{3.0\,a_{\mathrm{role}}(l,r),0.40,4.0\}.
\end{align}
The role factor depends on normalized depth $d_l=(l-1)/(L-1)$:
\begin{align}
    \rho_{\mathrm{in}}(l)=\clip(1-0.50(d_l-0.5),0.55,1.40),\qquad
    \rho_{\mathrm{out}}(l)=\clip(1+1.00(d_l-0.5),0.55,1.40),
\end{align}
with $a_{\mathrm{role}}(l,r)=\max(0.10,1+1.20(\rho_r(l)-1))$.  The
matrix-normalized branch is active only early.  Let $\eta_t$ be the shared base
learning-rate schedule and define
\begin{align}
    \mu_{l,r,t}=\clip\Big(
      0.75\,\sigma_{0.02,0.12}(\xi_t)
      \big[1-\sigma_{0.20,0.36}(\xi_t)\big]
      \rho_r(l)\,s_{\mathrm{stat}}(l,r,t),0,0.75\Big),
\end{align}
where $s_{\mathrm{stat}}(l,r,t)$ is a bounded pressure/activity factor defined
in Appendix~\ref{app:details}.  Operationally, MatrixPolicy composes two
stateful optimizer steps with temporary learning-rate multipliers:
\begin{align}
    M'_{l,r} &= \operatorname{AdamW}_{\eta_t a_{l,r}(1-\mu_{l,r,t})}
       (M^t_{l,r};\nabla M^t_{l,r}),\\
    M^{t+1}_{l,r} &= \operatorname{MatNorm}_{\eta_t\mu_{l,r,t}}
       (M'_{l,r};\nabla M^t_{l,r}).
      \label{eq:matrix-update}
\end{align}
Here $\operatorname{MatNorm}$ denotes the early Muon-style matrix-normalized
branch used for RLB matrices: it maintains its own matrix-gradient momentum and
normalizes the resulting matrix update direction before applying the temporary
learning-rate multiplier.  This notation describes the step composition and
learning-rate multipliers, not a claim that the two stateful updates are an exact
additive closed form.  After $\mu_{l,r,t}$ permanently decays to zero, the
zero-learning-rate matrix-normalized branch is omitted.  This reduces runtime
without changing the nonzero updates.

The final operation is a clipped positive-gauge rebalance.  Define the current
log-ratio
\begin{align}
    \gamma_g=\log\rms(A_{l,g})-\log\rms(B_{l,g}).
\end{align}
Using derivative gain $d_g$, output gain $o_g$, and the separately clipped gauge
pressure
$\bar\pi_g=\clip(\pi_g,-p_{\max}^{\mathrm{bal}},p_{\max}^{\mathrm{bal}})$,
MatrixPolicy defines the gauge target
\begin{align}
    \tau_g=w_\tau\frac{1}{2}(\log d_g-\log o_g)+\beta_p\bar\pi_g,
\end{align}
where $w_\tau$ weights the gain-ratio target and equals $1$ in the main
configuration.  Its activity factor is
\begin{align}
    a^{\mathrm{activity}}_g=
    \exp\{\clip(\beta_a\bar\alpha_g,
    \log a_{\min},\log a_{\max})\},
\end{align}
where
$\bar\alpha_g=\clip(\alpha_g,-p_{\max}^{\mathrm{bal}},p_{\max}^{\mathrm{bal}})$,
$\beta_a$ is the activity-gain coefficient, and
$0<a_{\min}\le a_{\max}$.  Activity can either damp or amplify the scheduled
gauge move within this fixed range.  MatrixPolicy applies
\begin{align}
    \ell_g=\clip\left(s_{l,t}a^{\mathrm{activity}}_g\frac{\tau_g-\gamma_g}{2},
      -\ell_{\max},\ell_{\max}\right)
\end{align}
where $s_{l,t}$ is the scheduled gauge strength and $\ell_{\max}$ is the maximum
absolute log-scale move.  It then rescales the matrices as
\begin{align}
    A_{l,g}\leftarrow e^{\ell_g}A_{l,g},\qquad
    B_{l,g}\leftarrow e^{-\ell_g}B_{l,g}.
    \label{eq:gauge-step}
\end{align}
In the homogeneous limit, \eqref{eq:gauge-step} changes only the representative.
With the RMS floor, exact function preservation is lost near the floor; the
applied log move remains bounded by $|\ell_g|\le\ell_{\max}$.

\textbf{Algorithm 1: MatrixPolicy step.}
Given gradients $\nabla\mathcal{L}(\theta^t)$ and base learning rate $\eta_t$:
\begin{enumerate}
    \item Update EMAs of RLB group pressure and rational-coefficient activity.
    \item Apply the centered, clipped group multipliers in \eqref{eq:group-scale}
    to $A_l$ and $B_l$ gradients.
    \item Step non-matrix parameters, including rational coefficients, with the
    AdamW-backed non-matrix optimizer.
    \item Step each RLB matrix with \eqref{eq:matrix-update}.
    \item Apply the bounded positive-gauge rebalance in \eqref{eq:gauge-step}.
\end{enumerate}

\appendix
\section{Design Rationale and Mathematical Details}
\label{app:design}

This appendix separates exact facts from design heuristics.  The exact facts are
that the main denominator has no real poles and that RLB has an exact
positive gauge in the homogeneous-radius limit.  The design heuristics are the
use of derivative/output gains as cheap function-space proxies, the use of
relative gradient pressures as on-policy imbalance signals, and the use of a
short early matrix-normalized branch for RLB matrices.  We do not claim a
convergence theorem, a natural-gradient derivation, or exact gauge preservation
under the stabilized RMS floor.

\subsection{Pole-Safe Global Rational Curves}
\label{app:denominator}

For each group, the global-rational activation uses the denominator
\begin{align}
    Q(u)=1+|b_1||u|+|b_2|u^2+|b_3||u|^3+|b_4|u^4 .
\end{align}
Every term is nonnegative for real $u$, hence $Q(u)\ge 1$.  This is the main
reason for this denominator form: it preserves rational expressivity without
introducing real poles.  The price is that the denominator is only piecewise
smooth because of the absolute-value terms.  This is acceptable for the intended
use: the curve is initialized from a SiLU fit, trained with standard automatic
differentiation, and used as a pole-safe trainable scalar response inside each
RLB group.

Using no local atoms has both a priori and empirical motivation.  A priori, the
global-rational activation has a smaller and cleaner optimizer surface: numerator
and denominator parameters only, no atom coefficients, no atom statistics, and no
empty atom parameter group.  Empirically, our ablations use the same
global-rational activation for both MatrixPolicy and non-MatrixPolicy RLB
controls, so the main comparison is not confounded by a MatrixPolicy-only local
atom path.

\subsection{Positive Gauge Lemma}
\label{app:gauge-proof}

Consider one group and set $\epsilon_{\rm rms}=0$.  For
$r(z)=\sqrt{m^{-1}\lVert z\rVert_2^2}$, any $a>0$, and any nonzero group
with $r(z)>0$,
\begin{align}
    r(az)=a r(z),\qquad u(az)=\frac{az}{r(az)}=\frac{z}{r(z)}=u(z).
\end{align}
Therefore
\begin{align}
    h(az)=r(az)R(u(az))=a r(z)R(u(z))=a h(z).
\end{align}
If the corresponding output columns are scaled by $a^{-1}$, their contribution to
$B_lh_l$ is unchanged.  Applying the argument independently to all groups proves
\eqref{eq:gauge-invariance}.

With the stabilizing floor, the normalized coordinate after scaling becomes
\begin{align}
    u_{\epsilon}(az)=\frac{az}{\sqrt{a^2m^{-1}\lVert z\rVert_2^2+
    \epsilon_{\rm rms}}}=\kappa(a,z)u_{\epsilon}(z),
\end{align}
where
\begin{align}
    \kappa(a,z)=\frac{a\sqrt{m^{-1}\lVert z\rVert_2^2+
    \epsilon_{\rm rms}}}{\sqrt{a^2m^{-1}\lVert z\rVert_2^2+
    \epsilon_{\rm rms}}}.
\end{align}
When $m^{-1}\lVert z\rVert_2^2\gg \epsilon_{\rm rms}$, $\kappa(a,z)\approx 1$;
when a group is near the floor, the normalized input changes and exact invariance
is lost.  This is why gauge rebalance is exact only in the homogeneous
idealization.  With the stabilized RMS floor, only the applied log-scale move is
explicitly bounded by clipping.

\subsection{Why Derivative and Output Gains Are Reasonable Proxies}
\label{app:function-space-scaling}

A perturbation of the output matrix has first-order effect
\begin{align}
    \delta y_g=\delta B_{l,g}h_{l,g}.
\end{align}
MatrixPolicy uses $o_g=\rms(R_g(u_{l,g}))$, the RMS of the scalar rational
output on normalized coordinates, as a cheap output-side proxy.  This abstracts
away the group radius $r_{l,g}$ and is not the full $B$-update Jacobian.  A
perturbation of $A_{l,g}$ first perturbs $z_{l,g}$ and then
passes through the normalized rational branch.  Ignoring the surrounding
Transformer context and keeping only the dominant scalar nonlinearity term gives
a sensitivity proportional to the rational derivative; hence
$d_g=\rms(R'_{l,g}(u_{l,g}))$ is a cheap input-side proxy.  The full Jacobian also
contains the derivative of the RMS normalization and interactions with the rest
of the network, so this is not a Fisher, Hessian, or natural-gradient claim.

The centered inverse-gain rule in \eqref{eq:group-scale} follows from this proxy:
large-gain groups receive smaller raw matrix-gradient scale and small-gain groups
receive larger scale.  Before the final clip,
\begin{align}
    \frac{1}{G}\sum_{g=1}^{G}\log\left(c_g/\geom(c)\right)=0,
\end{align}
so the operation is a redistribution of update budget in log scale.  The final
clip bounds the influence of noisy per-group statistics and can slightly shift
the mean log multiplier.

\subsection{Why Pressure Appears in Both Scaling and Gauge Balance}
\label{app:pressure-rationale}

In the homogeneous gauge direction, the infinitesimal scale transform is
$A_g\mapsto e^sA_g$, $B_g\mapsto e^{-s}B_g$.  If the loss were exactly invariant
and no regularization or optimizer state were present, the directional derivative
would satisfy
\begin{align}
    \langle \nabla_{A_g}\mathcal{L},A_g\rangle_F
    -\langle \nabla_{B_g}\mathcal{L},B_g\rangle_F=0.
\end{align}
MatrixPolicy does not use this inner product directly; instead it uses the more
robust relative-pressure proxy
\begin{align}
    \pi_g=\log q_{\mathrm{in},g}-\log q_{\mathrm{out},g}.
\end{align}
Positive $\pi_g$ means the input matrix is receiving larger relative gradient
pressure than the output matrix.  MatrixPolicy uses this signal to reduce input
matrix scale and increase output matrix scale in the group-gradient multiplier,
and to shift the gauge target toward a representative with less persistent
relative-update imbalance.  This is an a priori heuristic grounded in the RLB
gauge, not an exact quotient-space optimizer.

The gauge target
\begin{align}
    \tau_g=w_\tau\frac{1}{2}(\log d_g-\log o_g)+\beta_p\bar\pi_g
\end{align}
combines the local sensitivity proxy with the clipped on-policy pressure proxy,
where $\bar\pi_g$ is clipped using the gauge-balance threshold
$p_{\max}^{\mathrm{bal}}$.  The applied move is scaled by schedule and activity
and clipped to $[-\ell_{\max},\ell_{\max}]$, so the update is a bounded move
toward $\tau_g$, not exact canonicalization.

\subsection{Why the Matrix-Normalized Branch Is Early}
\label{app:early-matrix-branch}

The early branch in \eqref{eq:matrix-update} is restricted to RLB matrices and to
the beginning of training.  The a priori reason is that the matrices $A_l$ and
$B_l$ define domains and recombinations for the rational groups; early matrix
conditioning and rotations can matter before the rational curves and surrounding
Transformer settle.  The a posteriori reason is that generic Muon controls do not
explain the final MatrixPolicy advantage.  The branch is therefore a short
matrix-family component of MatrixPolicy, after which the update decays to the
role/depth AdamW matrix policy.

\subsection{A Posteriori Design Constraints}
\label{app:posterior}

The empirical design constraints are intentionally narrower than the full design
space.  The main method is the global-rational RLB sublayer in
Section~\ref{sec:method-activation} combined with the MatrixPolicy optimizer in
Section~\ref{sec:method-optimizer}.  Local rational atoms are an ablation of the
activation family, not part of the main method.  Likewise, the empirical claim is
not that the activation alone explains the result: matched RLB controls with the
same activation but different optimizers are required to isolate the optimizer
contribution.

This also fixes the accounting boundary for experiments.  Failed or unstable
optimizer pairings should be reported under the same stopping rules as stable
runs, and runtime comparisons should use clean training time measured by the
training process.  Non-training wall-clock delay and discarded interrupted
attempts are systems artifacts rather than properties of an optimizer or
activation.

\section{MatrixPolicy Hyperparameter Details}
\label{app:details}

For $L>1$, normalized depth is $d_l=(l-1)/(L-1)$.  MatrixPolicy uses
\begin{align}
    \rho_{\mathrm{in}}(l)&=\clip(1-0.50(d_l-0.5),0.55,1.40),\\
    \rho_{\mathrm{out}}(l)&=\clip(1+1.00(d_l-0.5),0.55,1.40),\\
    a_{\mathrm{role}}(l,r)&=\max(0.10,1+1.20(\rho_r(l)-1)).
\end{align}
The AdamW matrix multiplier is
\begin{align}
    a_{l,r}=\clip(3.0a_{\mathrm{role}}(l,r),0.40,4.0).
\end{align}
Let $\xi_t=t/T$ and let $\sigma_{a,b}(\xi)$ be a smoothstep gate from $0$ to $1$
over $[a,b]$.  The early matrix-normalized branch uses
\begin{align}
    \mu_{l,r,t}=\clip\Big(
      0.75\,\sigma_{0.02,0.12}(\xi_t)
      \big[1-\sigma_{0.20,0.36}(\xi_t)\big]
      \rho_r(l)\,s_{\mathrm{stat}}(l,r,t),0,0.75\Big),
\end{align}
where $s_{\mathrm{stat}}(l,r,t)$ is the bounded pressure/activity penalty
\begin{align}
    s_{\mathrm{stat}}(l,r,t)&=\clip\{\exp[-0.30P_l(t)-0.65A_l(t)],0.10,1.15\},\\
    P_l(t)&=G^{-1}\sum_{g=1}^{G}
      \left|\clip(\pi_g,-1.50,1.50)\right|,\\
    A_l(t)&=G^{-1}\sum_{g=1}^{G}
      \relu\left(\frac{\alpha_g-0.05}{0.45}\right).
\end{align}
In the main configuration, $\mu_{l,r,t}=0$ after the decay window.

The gauge rebalance runs every five optimizer steps.  Its schedule is
\begin{align}
    s_{l,t}=0.50\,\sigma_{0.03,0.35}(\xi_t)
      \clip(1+0.15(d_l-0.5),0.75,1.25),
\end{align}
with $\ell_{\max}=0.030$.  The pressure contribution in the gauge target uses EMA
decay $0.95$, pressure coefficient $\beta_p=0.25$, and pressure clip
$p_{\max}^{\mathrm{bal}}=1.25$ for the gauge calculation.  Rational activity
scales the applied move with $\beta_a=0.10$ and clamp range
$(a_{\min},a_{\max})=(0.75,1.25)$.

The main MatrixPolicy configuration enables the group-gradient policy with
\begin{align}
    \lambda_g=0.20,
    \qquad \lambda_p=0.10,
    \qquad \lambda_a=0.20,
    \qquad (c_{\min},c_{\max})=(0.75,1.35),
\end{align}
and a smooth activation window from training progress $0.02$ to $0.30$.

The constants are deliberately modest.  The exponent values keep group
redistribution in the small-perturbation regime; the clips prevent a single noisy
group from dominating the matrix update; the smooth windows suppress statistics
from the cold-start phase and remove the matrix-normalized branch before the
long-run optimizer comparison.  In the experiments, these constants are fixed
across datasets and model sizes rather than tuned per run.
