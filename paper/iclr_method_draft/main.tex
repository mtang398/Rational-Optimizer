\begin{abstract}
Transformer nonlinear sublayers contain large input and output matrices around a
coordinatewise activation, yet standard optimizers usually update these matrices
without using their different functional roles.  We study Rational Latent Basis
(RLB), a grouped rational activation sublayer that exposes this structure, and
MatrixPolicy, an optimizer that uses the exposed matrix roles and rational-curve
statistics during language-model pretraining.  The main RLB variant uses one
global P5/Q4 rational curve per group, initialized from SiLU and trained with no
active local atoms.  MatrixPolicy combines three role-aware operations: a centered
group-gradient policy, a depth-dependent matrix update with a short early Muon
branch, and a bounded positive rescaling of each input/output matrix pair.  On the completed 100M-token and 300M-token suites across five corpora for a
fixed 12-layer, width-768 model, MatrixPolicy reaches lower final validation
loss than every matched finite, non-diverged optimizer control; controls that
produce non-finite losses are reported as divergent outcomes rather than
finite comparators.  Token-to-target readouts show that the advantage often appears
before the fixed training budget is exhausted.
\end{abstract}

\section{Introduction}
\label{sec:introduction}

Transformer language models rely on nonlinear sublayers that expand the residual
stream, apply a coordinatewise activation, and project back to the model width
\citep{vaswani2017attention}.  Modern activation choices such as GELU, SiLU, and
SwiGLU improve the scalar nonlinearity or gating pattern
\citep{hendrycks2016gelu,ramachandran2017swish,shazeer2020glu}, but the optimizer
usually sees the surrounding matrices as ordinary parameter tensors.  This loses
a useful distinction: the input matrix chooses the coordinates in which the
nonlinearity operates, the activation controls local response and saturation, and
the output matrix recombines the resulting features.

This paper asks whether exposing that structure can make optimization more
effective.  We introduce Rational Latent Basis (RLB), a Transformer nonlinear
sublayer that places trainable grouped rational curves between an input-domain
matrix and an output-recombination matrix.  The rational curves are not used as a
standalone trick; they define a geometry that the optimizer can observe.  Each
group has a normalized coordinate system, a trainable scalar response, derivative
and output-gain statistics, and a limited positive rescaling relation between the
two adjacent matrices.

MatrixPolicy is the optimizer built for this parameterization.  It uses live
relative-pressure statistics to compare the input and output matrix roles, uses
rational derivative/output gains to scale group updates, applies a short early
Muon branch to shape the latent directions, and keeps the two matrix
representatives balanced by a bounded positive rescaling.  The resulting
method is intentionally conservative: rational coefficients and all non-RLB
backbone parameters remain on AdamW, while MatrixPolicy acts only on the RLB
input and output matrices.

The completed evidence in this draft covers language-model runs on five corpora
at 100M and 300M training-token budgets for a fixed 12-layer, width-768 model.  These runs compare
MatrixPolicy against matched global-rational RLB controls using AdamW, Lion,
Muon, SOAP-style, CAME-style, ScheduleFree-style, and ADeMaMix-style optimizers,
as well as SiLU controls under the same protocol.  Non-finite or early-stopped
ADeMaMix-style RLB rows are reported as divergent outcomes rather than
finite-loss competitors.  The current results show a consistent final-loss gap in favor of
MatrixPolicy among finite controls and a token-to-target advantage at several
validation-loss thresholds.  Larger scaling experiments will be needed before
claiming behavior beyond this regime.

\section{Related Work}
\label{sec:related}

\paragraph{Transformer nonlinear sublayers.}
The Transformer positionwise nonlinear sublayer was introduced alongside
self-attention \citep{vaswani2017attention}.  Subsequent activation
work showed that smooth and gated nonlinearities can improve optimization and
quality, including GELU \citep{hendrycks2016gelu}, Swish/SiLU
\citep{ramachandran2017swish}, and GLU variants such as SwiGLU
\citep{shazeer2020glu}.  RLB follows this line in replacing a fixed scalar
activation, but differs by making the activation trainable and grouped while
keeping a single input projection and output projection around it.  The goal is to change the function class while exposing matrix roles that the
optimizer can use.

\paragraph{Pretraining optimizers.}
Adam and AdamW remain standard choices for Transformer pretraining
\citep{kingma2015iclr-adam,loshchilov2019decoupled}.  Recent work explores
alternative update rules, parameter factorizations, and curvature or
matrix-aware preconditioners for language models, including Lion
\citep{chen2023lion}, Muon \citep{liu2025muon}, Sophia
\citep{liu2024sophia}, GaLore
\citep{zhao2024galore}, SOAP \citep{vyas2025soap}, Adam-mini
\citep{zhang2025adammini}, ADeMaMix \citep{pagliardini2025ademamix}, CAME
\citep{luo2023came}, cautious optimizers \citep{liang2026cautious}, and recent
pretraining-optimizer surveys \citep{wen2026fantastic}.  MatrixPolicy is closest
in spirit to matrix-aware optimization, but it does not apply one generic matrix
rule to every two-dimensional tensor.  It uses the local RLB structure to decide
which matrices receive role-specific scaling, which branch is active early, and
which group statistics control the update.

\paragraph{Pretraining corpora.}
The experiments use web-scale or web-derived corpora that are common in language
model pretraining studies, including DCLM/DataComp-LM \citep{li2024datacomp},
FineWeb and FineWeb-Edu \citep{penedo2024fineweb}, Dolma
\citep{soldaini2024dolma}, and C4 from the T5 work \citep{raffel2020t5}.  We use
these corpora to test whether the optimizer effect is tied to one data source or
persists across several text distributions.

\section{Method}
\label{sec:method}

RLB and MatrixPolicy are designed as a coupled activation--optimizer pair.  RLB
separates a nonlinear sublayer into an input-domain matrix, grouped rational
curves, and an output-recombination matrix.  MatrixPolicy uses this separation to
assign different update rules to the two matrices around each rational curve,
while the remaining model parameters and the rational coefficients are updated by
AdamW \citep{kingma2015iclr-adam,loshchilov2019decoupled}.  The method does not
claim that a trainable rational curve alone is sufficient; the experiments use
matched RLB controls with the same global-rational activation and different
optimizers to isolate the optimizer effect.

\subsection{Global-Rational RLB}
\label{sec:method-rlb}

For Transformer layer $l\in\{1,\ldots,L\}$, let
$x_l\in\mathbb{R}^{d}$ denote the input to the nonlinear sublayer.  RLB first
projects this input to a latent width $H=Gm$ and partitions the latent vector
into $G$ groups of width $m$:
\begin{align}
    z_l=A_lx_l,
    \qquad
    z_l=\operatorname{concat}_{g=1}^{G}z_{l,g},
    \qquad
    z_{l,g}\in\mathbb{R}^{m},
    \label{eq:rlb-projection}
\end{align}
where $A_l\in\mathbb{R}^{H\times d}$ is the input-domain matrix.  Each group is
normalized by its root-mean-square radius,
\begin{align}
    r_{l,g}
    =
    \sqrt{m^{-1}\lVert z_{l,g}\rVert_2^2+\epsilon_{\rm rms}},
    \qquad
    u_{l,g}=z_{l,g}/r_{l,g},
    \label{eq:rlb-normalization}
\end{align}
with numerical floor $\epsilon_{\rm rms}>0$.  A scalar rational curve is applied
coordinatewise in the normalized coordinates and then multiplied by the same
radius:
\begin{align}
    h_{l,g}=r_{l,g}R_{l,g}(u_{l,g}),
    \qquad
    h_l=\operatorname{concat}_{g=1}^{G}h_{l,g},
    \qquad
    y_l=B_lh_l,
    \label{eq:rlb-output}
\end{align}
where $B_l\in\mathbb{R}^{d\times H}$ is the output-recombination matrix.

The curve $R_{l,g}$ is a trainable global rational function,
\begin{align}
    R_{l,g}(u)=\frac{P_{l,g}(u)}{Q_{l,g}(u)},
    \qquad
    P_{l,g}(u)=\sum_{i=0}^{5}a_{l,g,i}u^i,
    \label{eq:global-rational-p}
\end{align}
with denominator
\begin{align}
    Q_{l,g}(u)
    =
    1+|b_{l,g,1}|\,|u|+|b_{l,g,2}|\,u^2
     +|b_{l,g,3}|\,|u|^3+|b_{l,g,4}|\,u^4 .
    \label{eq:global-rational-q}
\end{align}
The numerator and denominator coefficients are initialized by fitting SiLU on a
fixed probe interval and are trained thereafter.  The denominator form keeps the
real response pole-free because all nonconstant terms are nonnegative on the
real line, while still allowing the learned curve to change slope, curvature,
and saturation across layers and groups.  In the main variant there are no active local
Cauchy atoms, no trainable atom centers, and no atom coefficient parameters; the
nonlinear response is the grouped P5/Q4 curve itself.

The normalization in \eqref{eq:rlb-normalization} gives the optimizer two views
of each group.  The normalized coordinate $u_{l,g}$ determines where the rational
curve is evaluated, while the radius $r_{l,g}$ carries group scale back to the
residual stream.  In the idealized case $\epsilon_{\rm rms}=0$ with nonzero group
radii, this construction admits the positive rescaling
\begin{align}
    f_l(x;A_l,B_l,R_l)
    =
    f_l(x;D_l(a)A_l,B_lD_l(a)^{-1},R_l),
    \label{eq:positive-rescale}
\end{align}
where $R_l=\{R_{l,g}\}_{g=1}^{G}$ and
$D_l(a)=\diag(a_1I_m,\ldots,a_GI_m)$ for
$a\in\mathbb{R}_{>0}^{G}$.  The RMS floor makes this identity approximate near
degenerate groups, so MatrixPolicy uses it only as the mathematical basis for a
small bounded rescaling of the surrounding matrices.

\subsection{MatrixPolicy Signals}
\label{sec:method-signals}

MatrixPolicy treats $A_l$ and $B_l$ as different matrix roles around the same
rational curve.  It therefore tracks role-specific pressure and curve-gain
statistics for each layer and group.  For any tensor $V$, define the floored RMS
$\rms_{\epsilon}(V)=\sqrt{\operatorname{mean}(V^2)+\epsilon}$.  All log-domain
ratios below use a small positive floor before taking logarithms.  Let
$A_{l,g}\in\mathbb{R}^{m\times d}$ be the row block of $A_l$, and let
$B_{l,g}\in\mathbb{R}^{d\times m}$ be the column block of $B_l$.  The relative
matrix-gradient pressures are
\begin{align}
    p^{\rm in}_{l,g}
    =
    \frac{\rms_{\epsilon_p}(\nabla A_{l,g})}
    {\max\{\rms_{\epsilon_p}(A_{l,g}),\epsilon_p\}},
    \qquad
    p^{\rm out}_{l,g}
    =
    \frac{\rms_{\epsilon_p}(\nabla B_{l,g})}
    {\max\{\rms_{\epsilon_p}(B_{l,g}),\epsilon_p\}} .
    \label{eq:matrix-pressure}
\end{align}
The rational-activity statistic for the global-rational curve is
\begin{align}
    p^{R}_{l,g}
    =
    \left[
    \frac{1}{2}
    \left(
    \operatorname{mean}((\nabla a_{l,g,\cdot})^2)
    +
    \operatorname{mean}((\nabla b_{l,g,\cdot})^2)
    \right)
    +\epsilon_p
    \right]^{1/2}.
    \label{eq:rational-activity-raw}
\end{align}
MatrixPolicy maintains exponential moving averages
$q^{\rm in}_{l,g}$, $q^{\rm out}_{l,g}$, and $q^R_{l,g}$ of these quantities with
decay $0.95$, and forms
\begin{align}
    \pi_{l,g}
    =
    \log q^{\rm in}_{l,g}-\log q^{\rm out}_{l,g},
    \qquad
    \alpha_{l,g}
    =
    \log q^{R}_{l,g}
    -\frac{1}{2}\left(\log q^{\rm in}_{l,g}+\log q^{\rm out}_{l,g}\right).
    \label{eq:pressure-activity}
\end{align}
Here $\pi_{l,g}$ measures relative update pressure between the input and output
matrices, while $\alpha_{l,g}$ measures whether the rational coefficients are
receiving unusually large gradients relative to the adjacent matrices.

The activation also provides curve-gain signals.  From a recent sample of
normalized coordinates $u_{l,g}$ cached by the RLB forward path, MatrixPolicy
uses
\begin{align}
    d^{\rm live}_{l,g}=\rms(R'_{l,g}(u_{l,g})),
    \qquad
    o^{\rm live}_{l,g}=\rms(R_{l,g}(u_{l,g})).
    \label{eq:live-gains}
\end{align}
These statistics are not full block Jacobians.  They are cheap proxies:
derivative gain reflects the sensitivity of the input-domain role, and output
gain reflects the scale seen by the recombination role.

\subsection{MatrixPolicy Update}
\label{sec:method-update}

Let $t$ be the optimizer step, $T$ the planned number of training steps, and
$\xi_t=t/T$.  A smooth gate
\begin{align}
    \phi_t=\smooth(0.02,0.30,\xi_t)
    \label{eq:group-phase}
\end{align}
turns on the group-gradient policy.  For positive group values $v_j$, write
$\geom_j v_j=\exp(G^{-1}\sum_{j=1}^{G}\log v_j)$.  The multiplier for group
$g$ and role $r\in\{\mathrm{in},\mathrm{out}\}$ is
\begin{align}
    c_{l,g,r}
    =
    c^{\rm gain}_{l,g,r}
    c^{\rm pressure}_{l,g,r}
    c^{\rm activity}_{l,g}.
    \label{eq:group-multiplier}
\end{align}
For the input role, the gain term uses $d^{\rm live}_{l,g}$; for the output role,
it uses $o^{\rm live}_{l,g}$:
\begin{align}
    c^{\rm gain}_{l,g,\mathrm{in}}
    =
    \left(\frac{\geom_j d^{\rm live}_{l,j}}{d^{\rm live}_{l,g}}\right)^{0.20\phi_t},
    \qquad
    c^{\rm gain}_{l,g,\mathrm{out}}
    =
    \left(\frac{\geom_j o^{\rm live}_{l,j}}{o^{\rm live}_{l,g}}\right)^{0.20\phi_t}.
    \label{eq:gain-policy}
\end{align}
With $\tilde{\pi}_{l,g}=\clip(\pi_{l,g},-1.50,1.50)$, pressure shifts update
budget from the higher-pressure role toward the lower-pressure role:
\begin{align}
    c^{\rm pressure}_{l,g,\mathrm{in}}
    =
    \exp(-0.10\phi_t\tilde{\pi}_{l,g}),
    \qquad
    c^{\rm pressure}_{l,g,\mathrm{out}}
    =
    \exp(+0.10\phi_t\tilde{\pi}_{l,g}).
    \label{eq:pressure-policy}
\end{align}
Rational activity damps both matrix roles when the curve coefficients are moving
more strongly than the adjacent matrices:
\begin{align}
    c^{\rm activity}_{l,g}
    =
    \exp\left[
    -0.20\phi_t
    \relu\left(\frac{\alpha_{l,g}-0.05}{0.45}\right)
    \right].
    \label{eq:activity-policy}
\end{align}
The final multiplier is recentered and clipped,
\begin{align}
    c_{l,g,r}\leftarrow
    \frac{c_{l,g,r}}{\geom_j c_{l,j,r}},
    \qquad
    c_{l,g,r}\leftarrow\clip(c_{l,g,r},0.75,1.35),
    \label{eq:group-center-clip}
\end{align}
so the policy redistributes update scale across groups without changing the mean
log learning-rate multiplier.  All completed MatrixPolicy rows use this fixed
group-policy configuration across datasets and seeds.

After group-gradient scaling, the RLB matrices are updated by a role/depth AdamW
branch and a short early Muon branch.  Define
$\delta_l=(l-1)/(L-1)$ for $L>1$ and $\delta_l=1/2$ otherwise.  The role factors
are
\begin{align}
    \rho_{\mathrm{in}}(l)
    =
    \clip(1-0.50(\delta_l-0.5),0.55,1.40),
    \qquad
    \rho_{\mathrm{out}}(l)
    =
    \clip(1+1.00(\delta_l-0.5),0.55,1.40),
    \label{eq:role-factors}
\end{align}
and the AdamW matrix multiplier for role $r$ is
\begin{align}
    s^{\rm Adam}_{l,r}
    =
    \clip\left(
    3.0\max\{0.10,1+1.20(\rho_r(l)-1)\},
    0.40,4.0
    \right).
    \label{eq:adam-role-scale}
\end{align}
The Muon branch is concentrated early in training and is reduced when pressure
imbalance or rational activity is high.  Define
\begin{align}
    \Psi_{l,t}
    =
    \frac{1}{G}\sum_{g=1}^{G}
    \left|\clip(\pi_{l,g},-1.50,1.50)\right|,
    \qquad
    \Omega_{l,t}
    =
    \frac{1}{G}\sum_{g=1}^{G}
    \relu\left(\frac{\alpha_{l,g}-0.05}{0.45}\right),
    \label{eq:pressure-activity-aggregates}
\end{align}
\begin{align}
    \psi_{l,t}
    =
    \clip\left(\exp[-0.30\Psi_{l,t}-0.65\Omega_{l,t}],0.10,1.15\right).
    \label{eq:stat-penalty}
\end{align}
The branch fraction is
\begin{align}
    \mu_{l,r,t}
    =
    \clip\left(
    0.75\,
    \smooth(0.02,0.12,\xi_t)
    [1-\smooth(0.20,0.36,\xi_t)]
    \rho_r(l)\psi_{l,t},
    0,0.75
    \right).
    \label{eq:muon-fraction}
\end{align}
For $M_{l,\mathrm{in}}=A_l$ and $M_{l,\mathrm{out}}=B_l$, MatrixPolicy composes
a stateful AdamW matrix update with the Muon branch:
\begin{equation}
\begin{gathered}
    \widetilde M_{l,r}^{\,t+1}
    =
    \operatorname{AdamW}_{\eta_t s^{\rm Adam}_{l,r}(1-\mu_{l,r,t})}
    (M_{l,r}^{t};\nabla M_{l,r}^{t}),\\
    M_{l,r}^{t+1}
    =
    \operatorname{Muon}_{\eta_t\mu_{l,r,t}}
    (\widetilde M_{l,r}^{\,t+1};\nabla M_{l,r}^{t}),
\end{gathered}
    \label{eq:matrix-child-step}
\end{equation}
where $\eta_t$ is the base learning rate and $\operatorname{Muon}$ denotes the
\texttt{torch.optim.Muon} update on two-dimensional RLB matrix parameters: momentum
$0.95$, five Newton--Schulz orthogonalization steps, and the match-RMS learning
rate adjustment of the Muon optimizer \citep{liu2025muon}.  In the
implementation, the AdamW child optimizer is stepped first with learning-rate
factor $s^{\rm Adam}_{l,r}(1-\mu_{l,r,t})$, and the Muon child optimizer is
then stepped with learning-rate factor $\mu_{l,r,t}$.  When all Muon fractions
have decayed to zero, this child step is inactive.

The last MatrixPolicy operation is a bounded positive rescaling of the two matrix
blocks around each rational curve.  It is evaluated every five optimizer steps;
on other steps this operation is skipped.  On a fixed probe grid, define
\begin{align}
    d^{\rm probe}_{l,g}=\rms(R'_{l,g}(u)),
    \qquad
    o^{\rm probe}_{l,g}=\rms(R_{l,g}(u)),
    \label{eq:probe-gains}
\end{align}
and the current matrix log ratio
\begin{align}
    \gamma_{l,g}=\log\rms(A_{l,g})-\log\rms(B_{l,g}).
    \label{eq:current-ratio}
\end{align}
The target ratio combines a curve-gain term with a bounded pressure term,
\begin{align}
    \tau_{l,g}
    =
    \frac{1}{2}
    \left(
    \log d^{\rm probe}_{l,g}
    -
    \log o^{\rm probe}_{l,g}
    \right)
    +0.25\,\bar{\pi}_{l,g},
    \qquad
    \bar{\pi}_{l,g}=\clip(\pi_{l,g},-1.25,1.25).
    \label{eq:rescale-target}
\end{align}
Rational activity modulates the rescaling strength through
\begin{align}
    a^{\rm rs}_{l,g}
    =
    \exp\left(
    \clip(0.10\,\bar{\alpha}_{l,g},\log 0.75,\log 1.25)
    \right),
    \qquad
    \bar{\alpha}_{l,g}=\clip(\alpha_{l,g},-1.25,1.25).
    \label{eq:rescale-activity}
\end{align}
With schedule
\begin{align}
    s_{l,t}
    =
    0.50\,\smooth(0.03,0.35,\xi_t)
    \clip(1+0.15(\delta_l-0.5),0.75,1.25),
    \label{eq:rescale-schedule}
\end{align}
On active rescaling steps, the log move is
\begin{align}
    \ell_{l,g,t}
    =
    \clip\left(
    \frac{1}{2}[\tau_{l,g}-\gamma_{l,g}]s_{l,t}a^{\rm rs}_{l,g},
    -0.030,0.030
    \right).
    \label{eq:rescale-log-step}
\end{align}
On active rescaling steps, the matrix blocks are updated as
\begin{align}
    A_{l,g}\leftarrow e^{\ell_{l,g,t}}A_{l,g},
    \qquad
    B_{l,g}\leftarrow e^{-\ell_{l,g,t}}B_{l,g}.
    \label{eq:rescale-update}
\end{align}
This operation follows the positive rescaling structure in
\eqref{eq:positive-rescale}, but it is deliberately clipped because the RMS floor
and optimizer state make the implemented update only approximately
representation-preserving.

\section{Experiments}
\label{sec:experiments}

\paragraph{Setup.}
The completed runs use a 12-layer, width-768 causal Transformer, denoted M0 in
the result artifacts, with sequence length 256 and 32768 global tokens per
optimizer step.  E1 trains for 3050 steps
(about 100M tokens), and E2 trains for 9150 steps (about 300M tokens).  Each
cell uses three seeds on DCLM, FineWeb-Edu, FineWeb, Dolma-sample, and C4.
MatrixPolicy is compared against matched RLB controls using AdamW, Lion, Muon,
SOAP-style, CAME-style, ScheduleFree-style, and ADeMaMix-style optimizers, and
against SiLU controls under the same model and token budgets.  Non-finite or
early-stopped ADeMaMix-style RLB rows are reported as divergent outcomes, not
as finite final-loss comparators.

\paragraph{Final validation loss.}
Table~\ref{tab:e1-e2-final} summarizes the completed M0 results.  In E1,
MatrixPolicy has the lowest mean final validation loss on all five datasets; the
best finite non-MatrixPolicy method is RLB+Lion in each cell.  In E2,
MatrixPolicy is again the lowest-loss finite method on all five datasets; the
best finite non-MatrixPolicy method is RLB+Lion except on FineWeb-Edu, where
RLB+Muon is the strongest aggregate comparator.  The E2 gaps are smaller than in
E1, but they persist after three times as many tokens.

with fewer tokens in every listed dataset.

\paragraph{Interpretation.}
These results support two narrow conclusions.  First, the global-rational
activation is not by itself the whole effect: RLB+AdamW is close to SiLU+AdamW,
and the strongest finite non-MatrixPolicy RLB optimizer is usually RLB+Lion or
RLB+Muon.
Second, the role-aware optimizer consistently improves the RLB sublayer under the
completed M0 protocol.  The evidence does not yet establish scaling behavior
beyond 300M tokens or larger model sizes; those larger runs are the next
experimental stage.

\section{Algebra of the Global-Rational RLB Sublayer}
\label{app:rlb-algebra}

\subsection{Pole-free rational response and coefficient derivatives}
\label{app:rational-derivatives}

For one layer and group, write
\begin{align}
    P(u)=\sum_{i=0}^{5}a_i u^i,
    \qquad
    Q(u)=1+\sum_{j=1}^{4}|b_j|\phi_j(u),
    \qquad
    \phi(u)=(|u|,u^2,|u|^3,u^4).
\end{align}
Since $\phi_j(u)\ge 0$ for all real $u$, $Q(u)\ge 1$ and $R(u)=P(u)/Q(u)$ has
no real pole.  Away from the nondifferentiable points of the absolute-value
terms, the coordinate derivative is
\begin{align}
    R'(u)
    =
    \frac{P'(u)Q(u)-P(u)Q'(u)}{Q(u)^2},
    \label{eq:appendix-r-prime}
\end{align}
where
\begin{align}
    P'(u)=\sum_{i=1}^{5} i a_i u^{i-1},\qquad
    Q'(u)=|b_1|\sign(u)+2|b_2|u+3|b_3|u|u|+4|b_4|u^3.
\end{align}
The coefficient features are similarly explicit:
\begin{align}
    \frac{\partial R(u)}{\partial a_i}=\frac{u^i}{Q(u)},
    \qquad
    \frac{\partial R(u)}{\partial b_j}
    =
    -\frac{P(u)}{Q(u)^2}\sign(b_j)\phi_j(u),
    \label{eq:appendix-coeff-features}
\end{align}
with the usual subgradient convention at zero.  Thus the numerator updates change
the response through normalized polynomial features, while denominator updates
change the response through the same curve multiplied by pole-safe denominator
features.  This is the mathematical reason the global curve can expose output
and derivative gains without introducing separate local-atom parameters.

\subsection{Jacobian of RMS-normalized rational groups}
\label{app:rlb-jacobian}

For a group vector $z\in\mathbb{R}^{m}$, define
\begin{align}
    r(z)=\sqrt{m^{-1}\lVert z\rVert_2^2+\epsilon_{\rm rms}},
    \qquad
    u(z)=z/r(z),
    \qquad
    h(z)=r(z)R(u(z)),
\end{align}
where $R$ is applied coordinatewise.  The radius derivative is
\begin{align}
    \mathrm{d}r
    =
    \frac{z^\top \mathrm{d}z}{m r}
    =
    \frac{u^\top\mathrm{d}z}{m},
\end{align}
and the normalized-coordinate derivative is
\begin{align}
    \mathrm{d}u
    =
    \frac{1}{r}\left(I-\frac{uu^\top}{m}\right)\mathrm{d}z.
    \label{eq:appendix-du}
\end{align}
Therefore the group Jacobian is
\begin{align}
    J_h(z)
    :=
    \frac{\partial h}{\partial z}
    =
    R(u)\frac{u^\top}{m}
    +
    \diag(R'(u))\left(I-\frac{uu^\top}{m}\right).
    \label{eq:appendix-group-jacobian}
\end{align}
Equation~\eqref{eq:appendix-group-jacobian} explains why MatrixPolicy separates
output gain and derivative gain.  The vector $R(u)$ controls the direct feature
scale seen by $B_l$, while $R'(u)$ appears in the tangent component of the input
Jacobian seen by $A_l$.  The RMS-normalization term subtracts the radial
component $uu^\top/m$, so the derivative gain is only a proxy for the full group
Jacobian, not the full Jacobian itself.

\subsection{Positive rescaling and the RMS-floor error}
\label{app:positive-rescale}

Set $\epsilon_{\rm rms}=0$ and take $a>0$.  Then
\begin{align}
    r(az)=a r(z),
    \qquad
    u(az)=u(z),
    \qquad
    h(az)=a h(z).
\end{align}
Scaling $A_{l,g}$ by $a$ and the matching columns of $B_{l,g}$ by $a^{-1}$
therefore leaves the group contribution unchanged.  Applying this independently
to all groups gives \eqref{eq:positive-rescale}.

With $\epsilon_{\rm rms}>0$, define $r_\epsilon$ and $u_\epsilon$ by
\eqref{eq:rlb-normalization}.  For $\rho^2=m^{-1}\lVert z\rVert_2^2$,
\begin{align}
    u_\epsilon(az)
    =
    \kappa(a,z)u_\epsilon(z),
    \qquad
    \kappa(a,z)
    =
    \frac{a\sqrt{\rho^2+\epsilon_{\rm rms}}}
    {\sqrt{a^2\rho^2+\epsilon_{\rm rms}}}.
    \label{eq:appendix-kappa}
\end{align}
Let $L_R$ be a Lipschitz constant of the coordinatewise curve on the segment
between $u_\epsilon(z)$ and $\kappa(a,z)u_\epsilon(z)$.  After compensating the
output matrix by $a^{-1}$, the group-feature error obeys
\begin{align}
    \left\|a^{-1}h_\epsilon(az)-h_\epsilon(z)\right\|_2
    &\le
    \left|\frac{r_\epsilon(az)}{a}-r_\epsilon(z)\right|
    \left\|R(u_\epsilon(z))\right\|_2 \\
    &\quad+
    \frac{r_\epsilon(az)}{a}
    L_R |\kappa(a,z)-1|\left\|u_\epsilon(z)\right\|_2 .
    \label{eq:appendix-floor-bound}
\end{align}
Both terms vanish when $\epsilon_{\rm rms}=0$.  For
$\rho^2\gg \epsilon_{\rm rms}$, $\kappa(a,z)\approx 1$ and the bound is small;
near the floor, the approximation can be poor.  This is why the rescaling step in
\eqref{eq:rescale-log-step} is bounded rather than treated as an exact
function-preserving operation.

\section{Mathematical Rationale for MatrixPolicy}
\label{app:matrixpolicy-math}

\subsection{Role-specific gradients around an RLB group}
\label{app:role-gradients}

For one training example, let $\bar y_l=\nabla_{y_l}\mathcal{L}$ be the upstream
gradient, and let $J_{l,g}=\partial h_{l,g}/\partial z_{l,g}$ be the group
Jacobian in \eqref{eq:appendix-group-jacobian}.  The two matrix gradients have
different forms:
\begin{align}
    \nabla_{B_{l,g}}\mathcal{L}
    =
    \bar y_l h_{l,g}^\top,
    \qquad
    \nabla_{A_{l,g}}\mathcal{L}
    =
    \left(J_{l,g}^\top B_{l,g}^\top\bar y_l\right)x_l^\top.
    \label{eq:appendix-matrix-gradients}
\end{align}
The output matrix sees the realized feature vector $h_{l,g}$ directly.  The
input matrix sees the upstream gradient filtered through $B_{l,g}$ and the
rational group Jacobian.  This is the a priori reason MatrixPolicy uses
$o^{\rm live}_{l,g}=\rms(R(u_{l,g}))$ for the output role and
$d^{\rm live}_{l,g}=\rms(R'(u_{l,g}))$ for the input role.

\subsection{Relative pressure as a log-scale proxy}
\label{app:pressure-math}

The exact derivative along the homogeneous rescaling direction would be
\begin{align}
    \Delta_g
    =
    \left\langle\nabla_{A_{l,g}}\mathcal{L},A_{l,g}\right\rangle_F
    -
    \left\langle\nabla_{B_{l,g}}\mathcal{L},B_{l,g}\right\rangle_F.
    \label{eq:appendix-signed-pressure}
\end{align}
MatrixPolicy does not use this signed quantity directly.  Instead, it uses RMS
relative pressures because they bound the magnitude of a log-RMS change under a
small gradient step.  If $W^+=W-\eta G$ and $\eta$ is small, then
\begin{align}
    \log \rms(W^+)-\log\rms(W)
    =
    -\eta\frac{\langle G,W\rangle_F}{\lVert W\rVert_F^2}+O(\eta^2),
\end{align}
and Cauchy--Schwarz gives
\begin{align}
    \left|\frac{\langle G,W\rangle_F}{\lVert W\rVert_F^2}\right|
    \le
    \frac{\lVert G\rVert_F}{\lVert W\rVert_F}
    =
    \frac{\rms(G)}{\rms(W)} .
    \label{eq:appendix-pressure-bound}
\end{align}
Thus $p^{\rm in}_{l,g}$ and $p^{\rm out}_{l,g}$ are not natural-gradient terms;
they are scale-normalized proxies for how aggressively each matrix role is being
moved.  The log difference $\pi_{l,g}$ in \eqref{eq:pressure-activity} compares
these proxies in a way that is invariant to common multiplicative changes of the
loss scale.

\subsection{Centered group policy preserves the mean log step}
\label{app:centered-policy}

Before clipping, the group policy is recentered by
\begin{align}
    \widehat c_{l,g,r}
    =
    \frac{c_{l,g,r}}{\geom_j c_{l,j,r}}.
\end{align}
Therefore
\begin{align}
    \frac{1}{G}\sum_{g=1}^{G}\log \widehat c_{l,g,r}
    =
    \frac{1}{G}\sum_{g=1}^{G}\log c_{l,g,r}
    -
    \log\left(\geom_j c_{l,j,r}\right)
    =0.
    \label{eq:appendix-centered-policy}
\end{align}
This is why the group policy is a redistribution rule rather than a hidden global
learning-rate schedule.  Clipping can slightly perturb the exact zero-sum log
property, but it prevents a noisy group statistic from dominating the matrix
update.

\subsection{Bounded rescaling is a contraction toward a target ratio}
\label{app:rescale-contraction}

Let
\begin{align}
    \gamma_{l,g}=\log\rms(A_{l,g})-\log\rms(B_{l,g}).
\end{align}
On an active positive-rescaling step,
$A_{l,g}\leftarrow e^{\ell_{l,g,t}}A_{l,g}$ and
$B_{l,g}\leftarrow e^{-\ell_{l,g,t}}B_{l,g}$, so the log ratio changes as
\begin{align}
    \gamma_{l,g}^{+}
    =
    \gamma_{l,g}+2\ell_{l,g,t}.
    \label{eq:appendix-gamma-update}
\end{align}
Ignoring clipping for the moment and writing
$\lambda_{l,g,t}=s_{l,t}a^{\rm rs}_{l,g}$, the update in
\eqref{eq:rescale-log-step} gives
\begin{align}
    \gamma_{l,g}^{+}
    =
    (1-\lambda_{l,g,t})\gamma_{l,g}
    +
    \lambda_{l,g,t}\tau_{l,g}.
    \label{eq:appendix-rescale-contraction}
\end{align}
Thus each active rescaling step moves the matrix representative toward the
target ratio without changing the represented homogeneous block map.  In the
implemented setting this operation runs every five optimizer steps,
$\lambda_{l,g,t}$ is small, and the log move is clipped by $0.030$, so it acts as
a gradual balancing term rather than a large functional update.

\subsection{Why the Muon branch is early}
\label{app:early-muon}

The branch fraction in \eqref{eq:muon-fraction} contains the window
\begin{align}
    w(\xi_t)=\smooth(0.02,0.12,\xi_t)
    \left[1-\smooth(0.20,0.36,\xi_t)\right].
\end{align}
It is approximately zero at initialization, rises during the early phase, and
then decays to zero.  This shape matches the role of the RLB matrices.  Early in
training, changing matrix directions changes the normalized coordinates seen by
the rational curves; later, after the curves and surrounding Transformer layers
co-adapt, a persistent Muon branch would add an additional optimizer mechanism
where the simpler role/depth AdamW branch is sufficient.  The activity
penalty $\psi_{l,t}$ further reduces the branch when the rational coefficients
are already moving strongly, coupling the branch to the state of the activation
rather than applying a generic matrix rule everywhere.
