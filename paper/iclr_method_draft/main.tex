\begin{abstract}
Fixed token budgets make Transformer pretraining an arrival-time problem:
beyond endpoint loss, the practical question is how many tokens are needed to
reach a useful validation loss.  Most activation design changes the forward
response of the nonlinear sublayer, from pointwise curves to gated forms, while
the optimizer still sees the surrounding matrices through a generic tensor
interface.  We study a different lever: expose the sublayer's matrix roles to
the optimizer.  Rational Latent Basis (RLB) maps residual states into normalized
groups and learns real-pole-free P5/Q4 rational response curves that provide
response and matrix-pair scale summaries.  MatrixPolicy uses these summaries to
update the RLB input and output matrices by role, while AdamW handles rational
coefficients and all remaining Transformer parameters.  Across five 12-layer,
width-768 language-model pretraining corpora, MatrixPolicy reaches common
validation-loss targets earlier than matched SiLU and RLB controls.  At
100M tokens it saves 19.5--22.8\% target-arrival tokens versus SiLU with AdamW
and 29.2--34.0\% versus SiLU with Muon; at 300M tokens, after endpoint losses
begin to saturate, it still saves 22.3--26.4\% and 6.7--9.8\%, respectively,
with lower measured arrival time in every listed dataset/comparator pair.
These results support designing activations as optimizer interfaces for
token-efficient training.  [todo: Add the larger-scale training result once the next
experiment is complete.]
\end{abstract}

\section{Introduction}
\label{sec:introduction}

A central cost in language-model pretraining is the number of tokens required to
reach a useful validation loss.  The nonlinear sublayer is a natural target for
reducing this cost because it is a structured computation: an input matrix
selects latent coordinates, a response transforms them, and an output matrix
recombines the resulting features.  Much activation design has improved the
forward response.  Pointwise activations such as GELU and SiLU choose fixed
scalar curves, while gated sublayers such as GLU and SwiGLU add multiplicative
structure and became prominent in modern language models
\citep{hendrycks2016gelu,ramachandran2017swish,shazeer2020glu}.  In these
sublayers, the scalar nonlinearity is embedded between learned projections,
gates, and output recombination, so adjacent matrices can absorb scale and remix
feature directions.  Isolated curve changes are therefore a limited lever.  The
optimizer, however, still updates the surrounding matrices through a generic
parameter-gradient interface.

This leaves a different lever: change what the optimizer can see about the
nonlinear sublayer.  The input matrix controls which latent directions enter each
response group, the rational response shapes the transformed values, and the
output matrix recombines those values into the residual stream.  Treating these
matrices as generic tensors hides this role asymmetry and the reciprocal scale
balance between them.  We take this route with Rational Latent Basis (RLB), a
grouped rational sublayer that reports normalized group coordinates, trainable
rational response curves, derivative/output response scales, and a positive
matrix-pair scale relation.  The evaluated RLB variant is global-rational: it
uses one trainable real-pole-free P5/Q4 response per group and projects the
transformed groups back to the model width.

MatrixPolicy is the role-aware update rule paired with RLB.  For the RLB input
and output matrices, it uses the exposed response and scale summaries to perform
centered group-gradient redistribution, a transient gated Muon substep, and
bounded matrix-pair rescaling.  Rational coefficients, attention weights,
embeddings, and all remaining Transformer parameters use AdamW in the reported
configuration.  This separation keeps the optimizer change concentrated on the
two matrices whose roles are made explicit by the sublayer.

We evaluate the method on a fixed 12-layer, width-768 causal Transformer across
DCLM, FineWeb-Edu, FineWeb, Dolma-sample, and C4.  The 100M-token budget
captures early optimization behavior, where MatrixPolicy reaches shared
validation-loss targets substantially earlier than AdamW and Muon comparators on
matched SiLU and RLB controls.  The 300M-token budget tests the same architecture
after longer training, where endpoint gaps narrow but the target-arrival
advantage remains visible in both tokens and measured time.  [todo: Add
the larger-scale experiment result here once the next run is complete.]

The contributions are:
\begin{itemize}
    \item a global-rational RLB sublayer that exposes normalized groups,
    rational response summaries, and matrix-pair scale information to the
    optimizer;
    \item MatrixPolicy, a role-aware update rule for the RLB input and output
    matrices that combines group-gradient redistribution, a gated matrix
    substep, and bounded pair rescaling while AdamW handles the remaining
    parameters;
    \item matched evidence across five pretraining corpora showing faster
    target arrival in tokens and measured time against AdamW and Muon
    controls, with longer-budget runs measuring the saturation regime.
\end{itemize}

\section{Related Work}
\label{sec:related}

Transformer nonlinear sublayers are often identified by their scalar response,
from GELU and Swish/SiLU to gated variants such as GLU and SwiGLU
\citep{hendrycks2016gelu,ramachandran2017swish,shazeer2020glu}.  RLB follows the
same architectural location but changes the interface exposed to optimization:
instead of replacing only a fixed scalar curve, it exposes grouped coordinates,
trainable rational responses, and the adjacent matrix roles used by MatrixPolicy.

Rational activations are motivated by the ability of low-degree rational
functions to represent sharp transitions, saturation, and curved response shapes
with few parameters.  Recent approximation-theoretic work argues that trainable
low-degree rational activations can have expressivity advantages over common
fixed activations \citep{tang2026rationalexpressivity}.  We use that result as
motivation for the activation family, not as a proof of MatrixPolicy.  The
empirical comparison separates the global-rational RLB sublayer from the
role-aware optimizer by including RLB controls with AdamW, Muon, Lion, SOAP,
CAME, and ScheduleFree-style optimizers.

Adam and AdamW remain standard Transformer pretraining optimizers
\citep{kingma2015iclr-adam,loshchilov2019decoupled}.  Other work changes the
first-order rule while keeping a generic tensor interface, including Lion and
cautious optimizers \citep{chen2023lion,liang2026cautious}, or uses matrix
structure and low-rank information, including Muon, Sophia, GaLore, SOAP, and
Adam-mini \citep{liu2025muon,liu2024sophia,zhao2024galore,vyas2025soap,zhang2025adammini}.
CAME and schedule-free training modify optimizer state or schedules
\citep{luo2023came,defazio2024road}.  MatrixPolicy is closest in spirit to
matrix-aware optimization, but it does not infer role from the parameter tensor
alone: it receives activation-specific response gains, group-pressure signals,
and pair-balance summaries from RLB.  In the reported configuration,
role-specific rules apply only to the RLB input and output matrices; rational
coefficients and non-RLB-matrix Transformer parameters use AdamW.  Broader
optimizer coverage is available in recent surveys \citep{wen2026fantastic}.

\section{Method}
\label{sec:method}

RLB and MatrixPolicy are designed as a single interface.  RLB defines the
nonlinear sublayer and the detached summaries it exposes; MatrixPolicy consumes
those summaries to update the two adjacent matrices.  Rational coefficients and
ordinary Transformer parameters remain on the AdamW path in the reported
configuration.

Throughout the method we use
\begin{align}
    \clip(x,a,b)&=\min\{\max\{x,a\},b\}, \\
    \smooth(a,b,x)&=3\omega^2-2\omega^3,
    \qquad
    \omega=\clip\left(\frac{x-a}{b-a},0,1\right).
\end{align}

\subsection{Rational Latent Basis}
\label{sec:method-rlb}

For layer $l\in\{1,\ldots,L\}$, let $x_l\in\mathbb{R}^{d}$ be the input to the
nonlinear sublayer.  RLB projects $x_l$ to a latent width $H=Gm$, partitions the
latent coordinates into $G$ groups, normalizes each group by its RMS radius, and
applies one trainable group-global rational response:
\begin{align}
    z_l&=A_lx_l,
    \qquad
    z_l=\operatorname{concat}_{g=1}^{G}z_{l,g},
    \quad z_{l,g}\in\mathbb{R}^{m},
    \quad A_l\in\mathbb{R}^{H\times d},
    \label{eq:rlb-projection}\\
    r_{l,g}&=\sqrt{m^{-1}\lVert z_{l,g}\rVert_2^2+\epsilon_{\rm rms}},
    \qquad
    u_{l,g}=z_{l,g}/r_{l,g},
    \label{eq:rlb-normalization}\\
    P_{l,g}(u)&=\sum_{i=0}^{5}a_{l,g,i}u^i,
    \label{eq:global-rational-p}\\
    Q_{l,g}(u)&=
    1+|b_{l,g,1}|\,|u|+|b_{l,g,2}|\,u^2
     +|b_{l,g,3}|\,|u|^3+|b_{l,g,4}|\,u^4,
    \label{eq:global-rational-q}\\
    R_{l,g}(u)&=P_{l,g}(u)/Q_{l,g}(u),
    \qquad
    h_{l,g}=r_{l,g}R_{l,g}(u_{l,g}),
    \notag\\
    y_l&=B_l\operatorname{concat}_{g=1}^{G}h_{l,g},
    \qquad
    B_l\in\mathbb{R}^{d\times H}.
    \label{eq:rlb-output}
\end{align}
Here $\epsilon_{\rm rms}>0$ is the stabilizing squared-RMS floor; the rescaling
identity below explicitly sets this floor to zero.  The scalar functions
$P_{l,g}$, $Q_{l,g}$, and $R_{l,g}$ are applied coordinatewise to vector inputs.
The denominator satisfies $Q_{l,g}(u)\ge1$ for real $u$, so the implemented curve
has no real pole.  The response is piecewise rational because of the
absolute-value terms; derivative statistics use the autodiff derivative of this
implemented expression, with $\sign(0)=0$, and equations involving $R'_{l,g}$ are
interpreted almost everywhere.  Numerator and denominator coefficients are
initialized by a SiLU fit on $[-5,5]$ and are then trained by AdamW.  The reported
model uses only these group-global P5/Q4 rational responses.

The design separates where the response is evaluated from how much group scale
is returned to the residual stream.  The normalized coordinate $u_{l,g}$ indexes
the rational curve, while $r_{l,g}$ carries the latent group scale.  For fixed
curves $R_l=\{R_{l,g}\}_{g=1}^{G}$, write the block map
\begin{align}
    f_l(x;A_l,B_l,R_l)
    =
    B_l\operatorname{concat}_{g=1}^{G}
    r_{l,g}R_{l,g}(u_{l,g}),
    \label{eq:rlb-block-map}
\end{align}
with $z_l=A_lx$ and $r_{l,g},u_{l,g}$ defined as above.  If
$\epsilon_{\rm rms}=0$ and every group radius is nonzero, then for any
$\lambda\in\mathbb{R}_{>0}^{G}$ and
$D_l(\lambda)=\diag(\lambda_1I_m,\ldots,\lambda_GI_m)$,
\begin{align}
    f_l(x;A_l,B_l,R_l)
    =
    f_l(x;D_l(\lambda)A_l,B_lD_l(\lambda)^{-1},R_l).
    \label{eq:positive-rescale}
\end{align}
This positive matrix-pair rescaling is exact only in the unfloored idealization.
With the stabilizing RMS floor and optimizer state, MatrixPolicy treats it as a
bounded balancing direction rather than an exact invariance of the implemented
training dynamics.

\subsection{MatrixPolicy}
\label{sec:method-update}

MatrixPolicy acts only on the RLB matrix pair $(A_l,B_l)$.  It has three design
operations.  First, it redistributes update scale across rational groups using
live response gains and relative matrix-gradient pressure.  Second, it adds a
transient matrix-aware substep during early training, when endpoint saturation has
not yet compressed method differences.  Third, it performs bounded reciprocal
rescaling of each input/output matrix pair along the positive balance coordinate
exposed by RLB.  At step $t$, these operations read gradients and cached RLB
response summaries from the current minibatch, rescale matrix gradients by group
and role, apply the AdamW/Muon matrix branch, and finally perform the scheduled
positive matrix-pair balancing move.  Unless stated otherwise, gradient-derived
statistics in this subsection are computed after backpropagation and before any
parameter update.  The final pair-balance operation is applied after the
AdamW/Muon matrix branch and computes its current matrix ratio at that point.
For any tensor $V$, define
\begin{align}
    \rms(V)=\sqrt{\operatorname{mean}(V^2)},
    \qquad
    \rms_{\epsilon}(V)=\sqrt{\operatorname{mean}(V^2)+\epsilon}.
    \label{eq:rms-definition}
\end{align}
The constants $\epsilon_p>0$ and $\epsilon_g>0$ denote fixed additive floors in
squared-RMS units.  The same $\epsilon_p$ is reused as the implementation floor
for matrix-ratio logs in \eqref{eq:current-ratio}.  The resulting pressure and
activity scores are bounded update-control signals.  Let
$A_{l,g}\in\mathbb{R}^{m\times d}$ be the row block of $A_l$, and let
$B_{l,g}\in\mathbb{R}^{d\times m}$ be the column block of $B_l$.  The relative
matrix-gradient scales are
\begin{align}
    p^{\rm in}_{l,g}
    =
    \frac{\rms_{\epsilon_p}(\nabla A_{l,g})}
    {\rms_{\epsilon_p}(A_{l,g})},
    \qquad
    p^{\rm out}_{l,g}
    =
    \frac{\rms_{\epsilon_p}(\nabla B_{l,g})}
    {\rms_{\epsilon_p}(B_{l,g})} .
    \label{eq:matrix-pressure}
\end{align}
The coefficient-gradient energy scale for the global response is
\begin{align}
    p^{R}_{l,g}
    =
    \left[
    \frac{1}{2}
    \left(
    \operatorname{mean}((\nabla a_{l,g,\cdot})^2)
    +
    \operatorname{mean}((\nabla b_{l,g,\cdot})^2)
    \right)
    +\epsilon_p
    \right]^{1/2}.
    \label{eq:rational-activity-raw}
\end{align}
The same numerical floor is used in $p^R_{l,g}$, although this quantity is raw
coefficient-gradient energy rather than a relative matrix pressure.
MatrixPolicy maintains exponential moving averages
$q^{\rm in}_{l,g}$, $q^{\rm out}_{l,g}$, and $q^R_{l,g}$ of these quantities with
decay $0.95$, and forms
\begin{align}
    \pi_{l,g}
    =
    \log q^{\rm in}_{l,g}-\log q^{\rm out}_{l,g},
    \qquad
    \alpha_{l,g}
    =
    \log q^{R}_{l,g}
    -\frac{1}{2}\left(\log q^{\rm in}_{l,g}+\log q^{\rm out}_{l,g}\right).
    \label{eq:pressure-activity}
\end{align}
Here each matrix pressure is an unsigned RMS relative-gradient scale.
Consequently $\pi_{l,g}$ is a signed log imbalance between two unsigned
magnitudes: its sign records which role currently has the larger RMS-relative
scale.  MatrixPolicy uses this imbalance only as a bounded control signal for
redistribution and pair balancing.  The score $\alpha_{l,g}$ compares
coefficient-gradient activity with adjacent matrix pressure and is used only
inside bounded redistribution and gating rules.

The activation also provides batch-estimated curve gains.  From a recent sample
of normalized coordinates $u_{l,g}$ cached by the RLB forward path, MatrixPolicy
uses floored summaries
\begin{align}
    \hat d^{\rm live}_{l,g}
    =
    \sqrt{\operatorname{mean}\!\left(R'_{l,g}(u_{l,g})^2\right)+\epsilon_g},
    \qquad
    \hat o^{\rm live}_{l,g}
    =
    \sqrt{\operatorname{mean}\!\left(R_{l,g}(u_{l,g})^2\right)+\epsilon_g}.
    \label{eq:live-gains}
\end{align}
In \eqref{eq:live-gains}, the mean is over all cached scalar normalized
coordinates for group $(l,g)$ across batch, sequence positions, and the $m$
group coordinates.  The derivative gain is a proxy for the input-domain role.
The output gain is a curve-response proxy for the recombination role; it does
not include the group radius $r_{l,g}$ and therefore is not the full feature
scale seen by $B_l$.
Both gains are cheap role summaries rather than full block-Jacobian
preconditioners.

Let $t$ be the optimizer step, $T$ the planned number of training steps, and
$\xi_t=t/T$.  A smooth gate
\begin{align}
    \phi_t=\smooth(0.02,0.30,\xi_t)
    \label{eq:group-phase}
\end{align}
turns on the group-gradient policy.  For positive group values $v_j$, define
$\geom_{j=1}^{G}(v_j)=\exp\!\left(G^{-1}\sum_{j=1}^{G}\log v_j\right)$.
The multiplier for group $g$ and role $\sigma\in\{\mathrm{in},\mathrm{out}\}$ is
\begin{align}
    c_{l,g,\sigma}
    =
    c^{\rm gain}_{l,g,\sigma}
    c^{\rm pressure}_{l,g,\sigma}
    c^{\rm activity}_{l,g}.
    \label{eq:group-multiplier}
\end{align}
For the input role, the gain term uses $\hat d^{\rm live}_{l,g}$; for the output
role, it uses $\hat o^{\rm live}_{l,g}$:
\begin{align}
    c^{\rm gain}_{l,g,\mathrm{in}}
    =
    \left(\frac{\geom_{j=1}^{G} \hat d^{\rm live}_{l,j}}{\hat d^{\rm live}_{l,g}}\right)^{0.20\phi_t},
    \qquad
    c^{\rm gain}_{l,g,\mathrm{out}}
    =
    \left(\frac{\geom_{j=1}^{G} \hat o^{\rm live}_{l,j}}{\hat o^{\rm live}_{l,g}}\right)^{0.20\phi_t}.
    \label{eq:gain-policy}
\end{align}
With $\tilde{\pi}_{l,g}=\clip(\pi_{l,g},-1.50,1.50)$, the relative-gradient term
sets role-dependent group multipliers before the later role-wise recentering:
\begin{align}
    c^{\rm pressure}_{l,g,\mathrm{in}}
    =
    \exp(-0.10\phi_t\tilde{\pi}_{l,g}),
    \qquad
    c^{\rm pressure}_{l,g,\mathrm{out}}
    =
    \exp(+0.10\phi_t\tilde{\pi}_{l,g}).
    \label{eq:pressure-policy}
\end{align}
Coefficient-gradient activity downweights groups whose rational coefficients are
moving more strongly than the adjacent matrices before role-wise recentering:
\begin{align}
    c^{\rm activity}_{l,g}
    =
    \exp\left[
    -0.20\phi_t
    \relu\left(\frac{\alpha_{l,g}-0.05}{0.45}\right)
    \right].
    \label{eq:activity-policy}
\end{align}
The final multiplier is recentered and clipped,
\begin{align}
    c_{l,g,\sigma}\leftarrow
    \frac{c_{l,g,\sigma}}{\geom_{j=1}^{G} c_{l,j,\sigma}},
    \qquad
    c_{l,g,\sigma}\leftarrow\clip(c_{l,g,\sigma},0.75,1.35),
    \label{eq:group-center-clip}
\end{align}
so the policy redistributes update scale across groups, separately for each
matrix role, without changing the role-wise mean log multiplier before
clipping.

The scaled matrix gradients are
\begin{align}
    \widetilde\nabla A_{l,g}=c_{l,g,\mathrm{in}}\nabla A_{l,g},
    \qquad
    \widetilde\nabla B_{l,g}=c_{l,g,\mathrm{out}}\nabla B_{l,g}.
    \label{eq:scaled-gradients}
\end{align}
Let $\widetilde\nabla M_{l,\mathrm{in}}$ be the row-block concatenation of
$\{\widetilde\nabla A_{l,g}\}_{g=1}^{G}$, and let
$\widetilde\nabla M_{l,\mathrm{out}}$ be the column-block concatenation of
$\{\widetilde\nabla B_{l,g}\}_{g=1}^{G}$.
After this scaling, the RLB matrices are updated by a role/depth AdamW branch and
a transient Muon branch.  Define $\delta_l=(l-1)/(L-1)$ for $L>1$ and
$\delta_l=1/2$ otherwise.  The role factors are
\begin{align}
    \varrho_{\mathrm{in}}(l)
    =
    \clip(1-0.50(\delta_l-0.5),0.55,1.40),
    \qquad
    \varrho_{\mathrm{out}}(l)
    =
    \clip(1+1.00(\delta_l-0.5),0.55,1.40),
    \label{eq:role-factors}
\end{align}
and the AdamW matrix multiplier for role $\sigma$ is
\begin{align}
    s^{\rm Adam}_{l,\sigma}
    =
    \clip\left(
    3.0\max\{0.10,1+1.20(\varrho_\sigma(l)-1)\},
    0.40,4.0
    \right).
    \label{eq:adam-role-scale}
\end{align}
The Muon branch is concentrated early in training and is reduced when relative
scale imbalance or coefficient-gradient scale is high.  Define
\begin{align}
    \Psi_{l,t}
    =
    \clip\left(\frac{1}{G}\sum_{g=1}^{G}|\pi_{l,g}|,0,1.50\right),
    \qquad
    \Omega_{l,t}
    =
    \relu\left(\frac{G^{-1}\sum_{g=1}^{G}\alpha_{l,g}-0.05}{0.45}\right),
    \label{eq:pressure-activity-aggregates}
\end{align}
\begin{align}
    \psi_{l,t}
    =
    \clip\left(\exp[-0.30\Psi_{l,t}-0.65\Omega_{l,t}],0.10,1.15\right).
    \label{eq:stat-penalty}
\end{align}
The branch gate is
\begin{align}
    \mu_{l,\sigma,t}
    =
    \clip\left(
    0.75\,
    \smooth(0.02,0.12,\xi_t)
    [1-\smooth(0.20,0.36,\xi_t)]
    \varrho_\sigma(l)\psi_{l,t},
    0,0.75
    \right).
    \label{eq:muon-fraction}
\end{align}
For $M_{l,\mathrm{in}}=A_l$ and $M_{l,\mathrm{out}}=B_l$, let $\eta_t$ be the
base learning rate.  MatrixPolicy applies an AdamW matrix step followed by any
active Muon substep.  The gate $\mu_{l,\sigma,t}$ scales the two learning rates;
it is not a convex mixing coefficient for a single update direction:
\begin{equation}
\begin{gathered}
    \widetilde M_{l,\sigma}^{\,t+1}
    =
    \operatorname{AdamW}_{\eta_t s^{\rm Adam}_{l,\sigma}(1-\mu_{l,\sigma,t})}
    (M_{l,\sigma}^{t};\widetilde\nabla M_{l,\sigma}^{t}),\\
    M_{l,\sigma}^{t+1}
    =
    \operatorname{Muon}_{\eta_t\mu_{l,\sigma,t}}
    (\widetilde M_{l,\sigma}^{\,t+1};\widetilde\nabla M_{l,\sigma}^{t}),
\end{gathered}
    \label{eq:matrix-branch-step}
\end{equation}
The update in \eqref{eq:matrix-branch-step} is operational notation: AdamW and
Muon carry separate optimizer states, their configured weight-decay and momentum
terms are handled by the respective optimizer implementations, and both substeps
use the gradient from training step $t$.  Here $\operatorname{Muon}$ denotes the
\texttt{torch.optim.Muon} update on two-dimensional RLB matrix parameters:
momentum $0.95$, five Newton--Schulz orthogonalization steps, and the match-RMS
learning-rate adjustment of the Muon optimizer \citep{liu2025muon}.  When all
Muon fractions have decayed to zero, this branch is inactive.

The last operation is a bounded positive rescaling of the two matrix blocks
around each rational curve.  It is evaluated after the AdamW/Muon matrix branch
every five optimizer steps; on other steps it is skipped.  Let
$\mathcal{U}=\{u_k\}_{k=1}^{129}$ be a uniform probe grid over $[-5,5]$, and
define
$\rms_{\mathcal{U}}(\varphi)=\sqrt{|\mathcal{U}|^{-1}\sum_{u_k\in\mathcal{U}}\varphi(u_k)^2}$.
The fixed-grid probe gains are diagnostics of the curve shape, not estimates of
the current feature distribution.  They are read inside the post-branch balancing
operation when the probe metric is refreshed.  The live gains in
\eqref{eq:live-gains} provide the batch-distribution summaries for group-gradient
redistribution.  The probe gains are
\begin{align}
    \hat d^{\rm probe}_{l,g}
    =
    \sqrt{|\mathcal U|^{-1}\sum_{u_k\in\mathcal U}R'_{l,g}(u_k)^2+\epsilon_g},
    \qquad
    \hat o^{\rm probe}_{l,g}
    =
    \sqrt{|\mathcal U|^{-1}\sum_{u_k\in\mathcal U}R_{l,g}(u_k)^2+\epsilon_g},
    \label{eq:probe-gains}
\end{align}
and the current matrix log ratio is computed from the post-branch matrix blocks
with floored matrix RMS values,
\begin{align}
    \gamma_{l,g}=\log\rms_{\epsilon_p}(A_{l,g})-\log\rms_{\epsilon_p}(B_{l,g}).
    \label{eq:current-ratio}
\end{align}
Because the floor is inside both logarithms, $\gamma_{l,g}$ is a stable
implementation proxy for a matrix-RMS ratio.  The target ratio combines
curve-gain and relative-gradient terms,
\begin{align}
    \tau_{l,g}
    =
    \frac{1}{2}
    \left(
    \log \hat d^{\rm probe}_{l,g}
    -
    \log \hat o^{\rm probe}_{l,g}
    \right)
    +0.25\,\bar{\pi}_{l,g},
    \qquad
    \bar{\pi}_{l,g}=\clip(\pi_{l,g},-1.25,1.25).
    \label{eq:rescale-target}
\end{align}
The first term balances fixed-grid derivative and response gains in log space,
with the factor $1/2$ mapping the gain contrast to the matrix-pair log-ratio
coordinate; the second term adds a smaller pressure bias from the clipped
RMS-imbalance proxy.  Coefficient-gradient scale modulates the rescaling strength
through
\begin{align}
    \chi^{\rm rs}_{l,g}
    =
    \exp(0.10\,\bar{\alpha}_{l,g}),
    \qquad
    \bar{\alpha}_{l,g}=\clip(\alpha_{l,g},-1.25,1.25).
    \label{eq:rescale-activity}
\end{align}
The positive sign is intentional: high group coefficient activity damps the
group-gradient path, while high layer-average coefficient activity damps the Muon
branch, but the bounded balancing step moves slightly more quickly toward the
representative ratio; the later log-step clip limits this effect.
With schedule
\begin{align}
    s_{l,t}
    =
    0.50\,\smooth(0.03,0.35,\xi_t)
    \clip(1+0.15(\delta_l-0.5),0.75,1.25),
    \label{eq:rescale-schedule}
\end{align}
the active-step log move is
\begin{align}
    \ell_{l,g,t}
    =
    \clip\left(
    \frac{1}{2}[\tau_{l,g}-\gamma_{l,g}]s_{l,t}\chi^{\rm rs}_{l,g},
    -0.030,0.030
    \right).
    \label{eq:rescale-log-step}
\end{align}
The matrix blocks are then updated as
\begin{align}
    A_{l,g}\leftarrow e^{\ell_{l,g,t}}A_{l,g},
    \qquad
    B_{l,g}\leftarrow e^{-\ell_{l,g,t}}B_{l,g}.
    \label{eq:rescale-update}
\end{align}
The implementation applies the corresponding group scale to optimizer-state
buffers as well, using squared scales for square-average state entries.

\section{Conclusion}
\label{sec:conclusion}

Global-rational RLB turns the nonlinear Transformer sublayer into an
optimizer-visible interface: it exposes grouped normalized coordinates, trainable
global rational responses, and an idealized positive matrix-pair relation used as
a bounded balancing coordinate.  MatrixPolicy uses that interface to update the
RLB input and output matrices with role-aware statistics, while rational
coefficients and non-RLB-matrix parameters use AdamW.  The completed 100M-token and 300M-token runs show a consistent target-arrival pattern:
MatrixPolicy reaches common validation losses with fewer tokens and lower measured
target-arrival time than the listed SiLU and global-rational controls.  Larger-scale
training and component ablations remain explicit TODO subsections inside the

\section{Rational Latent Basis Calculus}
\label{app:rlb-calculus}

\paragraph{Real-pole-free group-global response.}
\label{app:rational-derivatives}

For one layer and group, write
\begin{align}
    \phi_1(u)=|u|,
    \quad
    \phi_2(u)=u^2,
    \quad
    \phi_3(u)=|u|^3,
    \quad
    \phi_4(u)=u^4,
    \notag\\
    P(u)=\sum_{i=0}^{5}a_i u^i,
    \qquad
    Q(u)=1+\sum_{j=1}^{4}|b_j|\phi_j(u).
\end{align}
Since $\phi_j(u)\ge 0$ for all real $u$, $Q(u)\ge 1$ and $R(u)=P(u)/Q(u)$ has
no real pole.  Away from $u=0$ for input derivatives,
\begin{align}
    R'(u)
    =
    \frac{P'(u)Q(u)-P(u)Q'(u)}{Q(u)^2},
    \label{eq:appendix-r-prime}
\end{align}
where
\begin{align}
    P'(u)=\sum_{i=1}^{5} i a_i u^{i-1},
    \qquad
    Q'(u)=|b_1|\sign(u)+2|b_2|u+3|b_3|u|u|+4|b_4|u^3.
\end{align}
The implementation uses the autodiff convention $\sign(0)=0$ for derivative-gain
statistics.  The coefficient features are explicit:
\begin{align}
    \frac{\partial R(u)}{\partial a_i}=\frac{u^i}{Q(u)},
    \qquad
    \frac{\partial R(u)}{\partial b_j}
    =
    -\frac{P(u)}{Q(u)^2}\sign(b_j)\phi_j(u),
    \label{eq:appendix-coeff-features}
\end{align}
with the usual autodiff subgradient convention at $b_j=0$.  These derivatives make output-factor
and derivative gains directly observable from the layer/group global curve,
without introducing local-atom parameters.

\paragraph{Normalized-group Jacobian and gain summaries.}
\label{app:rlb-jacobian}

For a group vector $z\in\mathbb{R}^{m}$, define
\begin{align}
    r(z)=\sqrt{m^{-1}\lVert z\rVert_2^2+\epsilon_{\rm rms}},
    \qquad
    u(z)=z/r(z),
    \qquad
    h(z)=r(z)R(u(z)),
\end{align}
where $R$ is applied coordinatewise.  The radius derivative is
\begin{align}
    \mathrm{d}r
    =
    \frac{z^\top \mathrm{d}z}{m r}
    =
    \frac{u^\top\mathrm{d}z}{m},
\end{align}
and the normalized-coordinate derivative is
\begin{align}
    \mathrm{d}u
    =
    \frac{1}{r}\left(I-\frac{uu^\top}{m}\right)\mathrm{d}z.
    \label{eq:appendix-du}
\end{align}
Therefore the group Jacobian is
\begin{align}
    J_h(z)
    :=
    \frac{\partial h}{\partial z}
    =
    R(u)\frac{u^\top}{m}
    +
    \diag(R'(u))\left(I-\frac{uu^\top}{m}\right).
    \label{eq:appendix-group-jacobian}
\end{align}
This decomposition motivates separate output-gain and derivative-gain summaries.
The vector $R(u)$ controls the curve-response factor inside the realized feature
$h=rR(u)$, while $R'(u)$ appears in the tangent component of the input Jacobian
seen by $A_l$.  The response and derivative RMS summaries used by MatrixPolicy
are not full feature-scale or input-Jacobian measurements: the full feature also
depends on $r$, and the full input gradient also depends on the radial
$R(u)u^\top/m$ term and on $B_{l,g}$.

\paragraph{Positive matrix-pair rescaling with an RMS floor.}
\label{app:positive-rescale}

Set $\epsilon_{\rm rms}=0$ and take $z\ne0$ and $\lambda>0$.  Then
\begin{align}
    r(\lambda z)=\lambda r(z),
    \qquad
    u(\lambda z)=u(z),
    \qquad
    h(\lambda z)=\lambda h(z).
\end{align}
Scaling $A_{l,g}$ by $\lambda$ and the matching column block $B_{l,g}$ by
$\lambda^{-1}$ therefore leaves the group contribution unchanged.  Applying
this independently to all groups gives \eqref{eq:positive-rescale}.

With $\epsilon_{\rm rms}>0$, define the floored maps
\begin{align}
    r_\epsilon(z)=\sqrt{m^{-1}\lVert z\rVert_2^2+\epsilon_{\rm rms}},
    \qquad
    u_\epsilon(z)=z/r_\epsilon(z),
    \qquad
    h_\epsilon(z)=r_\epsilon(z)R(u_\epsilon(z)).
\end{align}
For $\rho^2=m^{-1}\lVert z\rVert_2^2$,
\begin{align}
    u_\epsilon(\lambda z)
    =
    \kappa(\lambda,z)u_\epsilon(z),
    \qquad
    \kappa(\lambda,z)
    =
    \frac{\lambda\sqrt{\rho^2+\epsilon_{\rm rms}}}
    {\sqrt{\lambda^2\rho^2+\epsilon_{\rm rms}}}.
    \label{eq:appendix-kappa}
\end{align}
Let $L_R$ be a Lipschitz constant of the scalar curve over an interval containing
all coordinates of $u_\epsilon(z)$ and
$\kappa(\lambda,z)u_\epsilon(z)$.  After compensating the output matrix by
$\lambda^{-1}$, the group-feature error obeys
\begin{align}
    \left\|\lambda^{-1}h_\epsilon(\lambda z)-h_\epsilon(z)\right\|_2
    &\le
    \left|\frac{r_\epsilon(\lambda z)}{\lambda}-r_\epsilon(z)\right|
    \left\|R(u_\epsilon(z))\right\|_2 \\
    &\quad+
    \frac{r_\epsilon(\lambda z)}{\lambda}
    L_R |\kappa(\lambda,z)-1|\left\|u_\epsilon(z)\right\|_2 .
    \label{eq:appendix-floor-bound}
\end{align}
Both terms vanish when $\epsilon_{\rm rms}=0$.  When
$\rho^2\gg \epsilon_{\rm rms}$ and the global response and derivative are bounded on
the interval above, the bound is small; near the floor, the approximation can be poor.  This is the reason
positive matrix-pair balancing is treated as a bounded log-coordinate move rather
than an unrestricted change of representative.



\section{MatrixPolicy Update Geometry}
\label{app:matrixpolicy-step}

\paragraph{Optimizer step order.}
\label{app:optimizer-step-order}

At training step $t$, backpropagation produces gradients with respect to the
pre-update parameters.  MatrixPolicy computes the pressure and activity
statistics from these gradients and from $A_l^t$, $B_l^t$, and the rational
coefficients before any parameter is changed.  With EMA decay $\beta=0.95$, the
matrix and coefficient statistics have the form
\begin{align}
    q^{\rm in,t}_{l,g}
    &=
    \beta q^{\rm in,t-1}_{l,g}+(1-\beta)p^{\rm in,t}_{l,g}, \\
    q^{\rm out,t}_{l,g}
    &=
    \beta q^{\rm out,t-1}_{l,g}+(1-\beta)p^{\rm out,t}_{l,g}, \\
    q^{R,t}_{l,g}
    &=
    \beta q^{R,t-1}_{l,g}+(1-\beta)p^{R,t}_{l,g}.
\end{align}
The live curve gains are read from the RLB forward cache that produced the same
loss and enter the group-gradient multipliers in
\eqref{eq:group-multiplier}.  The Muon fraction in
\eqref{eq:muon-fraction} and the balancing quantities in
\eqref{eq:rescale-target}--\eqref{eq:rescale-activity} use pre-update
pressure/activity EMAs collected by the optimizer wrapper.  Non-matrix
Transformer parameters and rational coefficients then follow the AdamW path.
The RLB matrix blocks use the scaled gradients in \eqref{eq:scaled-gradients}
for the AdamW and Muon matrix branches in \eqref{eq:matrix-branch-step}.  On
scheduled rescaling steps, the bounded positive matrix-pair move in
\eqref{eq:rescale-update} is applied after the matrix branch, and the
corresponding optimizer-state buffers are scaled covariantly.  Thus MatrixPolicy
changes only the representatives of RLB input/output matrix pairs; it does not
introduce a separate optimizer path for rational coefficients or for non-RLB
tensors.

MatrixPolicy is built from the quantities that the RLB parameterization exposes
without adding a new optimization objective.  The normalized group map separates
curve response from tangent sensitivity; the positive rescaling direction creates
a near-invariant coordinate for the input/output matrix pair away from the RMS
floor; and the relative-gradient summaries provide a cheap estimate of which role
is changing faster.  These three signals determine where MatrixPolicy redistributes
group update scale, how strongly it moves the two matrix representatives toward a
balanced log ratio, and when it applies the transient matrix-direction branch.
\label{app:matrixpolicy-geometry}

\paragraph{Role-specific gradients and gain selection.}
\label{app:role-gradients}

For one training example, let $\bar y_l=\nabla_{y_l}\mathcal{L}$ be the upstream
gradient, and let $J_{l,g}=\partial h_{l,g}/\partial z_{l,g}$ be the group
Jacobian in \eqref{eq:appendix-group-jacobian}.  The adjacent matrix gradients
factor as
\begin{align}
    \nabla_{B_{l,g}}\mathcal{L}
    &=
    \bar y_l h_{l,g}^\top, \\
    \nabla_{A_{l,g}}\mathcal{L}
    &=
    \left(J_{l,g}^\top B_{l,g}^\top\bar y_l\right)x_l^\top .
    \label{eq:appendix-matrix-gradients}
\end{align}
The output matrix is coupled directly to the realized feature $h_{l,g}$, whereas
the input matrix is coupled to the tangent and radial components of the RLB
Jacobian before the upstream gradient reaches $x_l$.  This asymmetry motivates
separate gain summaries: response RMS summaries act as output-role proxies, and
derivative RMS summaries act as input-role proxies.  These summaries are partial
by construction.  The full output feature also contains $r_{l,g}$, and the full
input gradient also depends on $B_{l,g}$ and on the radial term $R(u)u^\top/m$
in \eqref{eq:appendix-group-jacobian}.  MatrixPolicy therefore uses gains as
bounded role signals for the adjacent matrix updates.

\paragraph{Scale-normalized pressure and centered redistribution.}
\label{app:pressure-redistribution}

In the idealized unfloored rescaling direction, an infinitesimal increase of the
input representative and reciprocal decrease of the output representative has the
loss derivative
\begin{align}
    \Delta_g
    =
    \left\langle\nabla_{A_{l,g}}\mathcal{L},A_{l,g}\right\rangle_F
    -
    \left\langle\nabla_{B_{l,g}}\mathcal{L},B_{l,g}\right\rangle_F .
    \label{eq:appendix-signed-pressure}
\end{align}
MatrixPolicy does not estimate $\Delta_g$ directly.  Instead it uses RMS relative
gradient scales because they are cheap and stable.  For nonzero unfloored $W$,
if $W^+=W-\eta \mathcal{G}$ and $\eta$ is small, then
\begin{align}
    \log \rms(W^+)-\log\rms(W)
    =
    -\eta\frac{\langle \mathcal{G},W\rangle_F}{\lVert W\rVert_F^2}+O(\eta^2),
\end{align}
and Cauchy--Schwarz implies
\begin{align}
    \left|\frac{\langle \mathcal{G},W\rangle_F}{\lVert W\rVert_F^2}\right|
    \le
    \frac{\lVert \mathcal{G}\rVert_F}{\lVert W\rVert_F}
    =
    \frac{\rms(\mathcal{G})}{\rms(W)} .
    \label{eq:appendix-pressure-bound}
\end{align}
The implemented quantities $p^{\rm in}$ and $p^{\rm out}$ are floored versions
of the upper-bound scale on the right-hand side.  They are unsigned magnitudes.
Thus $\pi_{l,g}=\log q^{\rm in}_{l,g}-\log q^{\rm out}_{l,g}$ is an
RMS-imbalance proxy: its sign identifies which role currently has the larger
relative update scale, and its clipped magnitude supplies the pressure term used
by \eqref{eq:pressure-policy} and \eqref{eq:rescale-target}.

The redistribution step is centered separately for each role.  Before clipping,
\begin{align}
    \widehat c_{l,g,\sigma}
    =
    \frac{c_{l,g,\sigma}}{\geom_{j=1}^{G} c_{l,j,\sigma}},
    \qquad
    \frac{1}{G}\sum_{g=1}^{G}\log \widehat c_{l,g,\sigma}=0 .
    \label{eq:appendix-centered-policy}
\end{align}
The policy therefore redistributes update scale across groups while preserving
the role-wise mean log multiplier before clipping.  The clip in
\eqref{eq:group-center-clip} deliberately trades exact centering for robustness
to noisy group statistics.

\paragraph{Bounded matrix-pair balancing and transient direction updates.}
\label{app:balancing-transient}

For the unfloored nonzero-matrix calculation, write
\begin{align}
    \gamma_{l,g}=\log\rms(A_{l,g})-\log\rms(B_{l,g}).
\end{align}
An active rescaling step applies
$A_{l,g}\leftarrow e^{\ell_{l,g,t}}A_{l,g}$ and
$B_{l,g}\leftarrow e^{-\ell_{l,g,t}}B_{l,g}$, hence
\begin{align}
    \gamma_{l,g}^{+}=\gamma_{l,g}+2\ell_{l,g,t}.
    \label{eq:appendix-gamma-update}
\end{align}
If clipping is ignored and
$\lambda_{l,g,t}=s_{l,t}\chi^{\rm rs}_{l,g}$ uses the schedule and activity
factor from \eqref{eq:rescale-activity}--\eqref{eq:rescale-schedule}, then
\eqref{eq:rescale-log-step} gives
\begin{align}
    \gamma_{l,g}^{+}
    =
    (1-\lambda_{l,g,t})\gamma_{l,g}
    +
    \lambda_{l,g,t}\tau_{l,g}.
    \label{eq:appendix-rescale-contraction}
\end{align}
This is an exact contraction only in the nonzero-matrix, unfloored-RMS,
$\epsilon_{\rm rms}=0$, unclipped idealization.  The implementation uses the
floored proxy in \eqref{eq:current-ratio}; near the floor, the log-ratio
interpretation and the contraction model are approximate.

The target
\begin{align}
    \tau_{l,g}
    =
    \frac{1}{2}
    \left(
    \log \hat d^{\rm probe}_{l,g}
    -
    \log \hat o^{\rm probe}_{l,g}
    \right)
    +0.25\,\bar{\pi}_{l,g},
    \qquad
    \bar{\pi}_{l,g}=\clip(\pi_{l,g},-1.25,1.25)
\end{align}
uses fixed-grid probe gains because pair rescaling is meant to balance the
representative around the curve shape rather than chase minibatch feature noise.
The derivative/response contrast supplies the log-space gain-balancing target,
the factor $1/2$ maps that contrast to the matrix-pair ratio coordinate in
\eqref{eq:appendix-gamma-update}, and the smaller pressure term biases the target
toward the role with the larger relative update scale.

The time window inside the Muon fraction in \eqref{eq:muon-fraction} is
\begin{align}
    w(\xi_t)=\smooth(0.02,0.12,\xi_t)
    \left[1-\smooth(0.20,0.36,\xi_t)\right].
\end{align}
Together with the role factor $\varrho_\sigma(l)$, penalty $\psi_{l,t}$, and
clipping in the full $\mu_{l,\sigma,t}$ formula, this window confines the
matrix-direction update to the phase in which changes to latent directions most
directly affect the coordinates seen by the rational curves.  The penalty
$\psi_{l,t}$ reduces this branch when RMS imbalance or coefficient-gradient
activity is high.  MatrixPolicy therefore uses Muon as a bounded,
state-dependent matrix-direction substep rather than as a persistent generic
optimizer for all tensors.
