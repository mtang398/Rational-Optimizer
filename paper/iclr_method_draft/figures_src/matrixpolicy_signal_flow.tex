% Step 1 design document.
% Domain / format / density: ICLR method figure, TikZ standalone, medium
% density. The figure preserves the original purpose: show the MatrixPolicy
% route for the RLB matrix pair while separating it from the AdamW-only bypass.
% Five-second message: detached measurements are read-only signals; each one has
% a visible use site in MatrixPolicy, while rational coefficient tensors are not
% MatrixPolicy update targets.
% Layout: top source-summary cards, middle read-set pills aligned above their
% consumer operations, bottom AdamW-only bypass. The dashed horizontal boundary
% means stop-gradient. Repeated variable names in read-set pills do the routing
% work, so the figure avoids spaghetti arrows.
