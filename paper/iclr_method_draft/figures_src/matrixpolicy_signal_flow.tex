% Step 1 design document
% Field: optimizer step schematic for transformer rational activation. Format: TikZ standalone, paper method schematic.
% Five-second message: MatrixPolicy has one left-to-right RLB matrix update lane; rational coefficients and all ordinary Transformer parameters stay in a separate AdamW-only lane.
% Layout: left detached statistics cache, then one straight purple matrix pipeline. Bottom lane is a grey AdamW-only bypass; the red exclusion note is a callout, not another update step.
% Modules: statistics cache, MatrixPolicy controller, group gates, scaled matrix gradients, AdamW matrix branch, transient Muon branch, pair rescale, updated A_l/B_l, AdamW-only parameters, AdamW-only update, updated non-matrix parameters.
% Visual emphasis: purple = MatrixPolicy-updated RLB matrices; grey = AdamW-only parameters. The observation from rational coefficients is statistics-only and never a purple update arrow.
