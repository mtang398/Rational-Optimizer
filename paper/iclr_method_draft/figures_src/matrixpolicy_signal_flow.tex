% Step 1 design document.
% Domain: ICLR method figure for an optimizer/activation interface in language
% model training. Format: TikZ standalone, because formulas and the paper font
% must remain vector and LaTeX-native. Complexity: medium system overview.
% Layout: 16.4 cm by 7.15 cm, preserving the original three-lane purpose:
% detached summary bus above, MatrixPolicy route for A_l and B_l in the middle,
% and AdamW-only bypass below. The top bus is extended with compact source
% capsules above the four summary families, so readers can see where each
% detached statistic comes from before it enters the MatrixPolicy route.
% Modules: forward/probe gain source, A/B gradient source, rational-coefficient
% gradient source, pair-state source, four detached-summary families, group
% gradient gates, AdamW/Muon matrix branch, post-step pair rescale, updated
% matrix pair, bypass lane. Core = the MatrixPolicy route and stop-gradient
% boundary. Lines: solid purple arrows for matrix updates, dashed gray arrows
% for detached reads, muted gray arrows for the bypass. Space planning keeps the
% dashed read rail above action boxes, with use-site labels placed in whitespace.
\documentclass[tikz,border=5pt]{standalone}
\usepackage{tikz}
\usepackage{amsmath,amssymb}
\usepackage[T1]{fontenc}
\usepackage{helvet}
