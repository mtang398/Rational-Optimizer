% Step 1 design document
% Field: transformer optimization / rational activations. Format: TikZ standalone method overview.
% Complexity: medium method overview. Five-second message: global-rational RLB is a matrix-curve-matrix
% sublayer whose detached statistics are read by MatrixPolicy; MatrixPolicy writes only to A_l and B_l.
% Layout: top band is the left-to-right forward pass from x_l through A_l, global-rational RLB,
% B_l, and y_l. Middle band is a detached stop-gradient statistics panel separated from the forward
% path by white space. Bottom band is MatrixPolicy with two purple write rails routed outside the
% statistics panel. The rational coefficients stay inside the RLB hero box and are labeled
% AdamW-trained / observed-only; no local atoms or per-atom targets appear.
% Modules: x_l, A_l, coordinate grouping, global-rational RLB with P5/Q4 curve and theta_R,
% h_l, B_l, y_l, four detached summary cards, MatrixPolicy, two write-only action rails.
% Connection plan: solid black arrows for forward flow; dashed gray arrows for stop-gradient
% observations into the statistics panel; purple orthogonal rails for MatrixPolicy writes to A_l/B_l.
% Prevention notes: no arrows from MatrixPolicy to theta_R or the rational curve; no curved write
% paths crossing statistics; all labels are inside boxes or on empty rail segments.
