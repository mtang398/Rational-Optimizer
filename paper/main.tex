\section{Method}
\label{sec:method}

A learned activation changes both the features a network represents and how
parameter updates affect those features. We use this connection to design
\grain{} and \tiller{} together. \grain{} learns a rational response within
each feature group. \tiller{} uses the resulting response geometry to
construct update directions, then coordinates these directions through their
joint effect on the loss. This separates two decisions: which direction to
take within each group, and how to combine directions across the network.

\subsection{GRAIN: learning the response within each group}

Consider a feed-forward block with input $x\in\mathbb R^d$. Partition its
intermediate features into $G$ groups of width $w$, with incoming matrices
$A_g\in\mathbb R^{w\times d}$ and outgoing matrices
$B_g\in\mathbb R^{d\times w}$. The block computes
\begin{equation}
 y=\sum_{g=1}^G B_g h_g,\qquad
 h_g=\rho_g\phi_g(u_g),\qquad
 u_g=\frac{A_gx}{\rho_g},\quad
 \rho_g=\sqrt{\|A_gx\|_2^2/w+\epsilon_{\rm act}}.
 \label{eq:overview-grain}
\end{equation}
Each $\phi_g$ is a learned rational function, applied elementwise:
\begin{equation}
 \phi_g(u)=
 \frac{\sum_{j=0}^{5}a_{gj}u^j}
 {1+\sum_{j=1}^{4}|b_{gj}|\,|u|^j}.
 \label{eq:overview-rational}
\end{equation}
Rational functions offer a trainable response shape
\citep{molina2020pade,boulle2020rational}; the denominator above stays positive.
Internal RMS normalization \citep{zhang2019rmsnorm} lets the function act on
relative feature magnitudes, while multiplication by $\rho_g$ restores the
group scale. Groups start from a common SiLU fit and learn separate
responses. With intermediate width $Gw=3H/2$, the two projections use the
same number of dense weights as a SwiGLU block of width $H$
\citep{shazeer2020glu}.

This parameterization also exposes the response of a group to an update.
Writing $J_g=\partial h_g/\partial(A_gx)$, differentiation gives
\begin{equation}
 J_g=\operatorname{Diag}(\phi'_g(u_g))
 +\frac{1}{w}
 \bigl[\phi_g(u_g)-u_g\odot\phi'_g(u_g)\bigr]u_g^\top.
 \label{eq:overview-jacobian}
\end{equation}
The first term describes the elementwise response; the second captures the
coupling induced by normalization. Both learned features $h_g$ and their
Jacobian $J_g$ inform the optimizer below. Appendix~\ref{app:grain-calculus}
derives this identity and specifies initialization.

\subsection{TILLER: adapting directions to the learned response}

For $L$ feed-forward layers, index the $C=LG$ layer--group pairs by
$i=(\ell,g)$. Write $g_i$ for a block's current clipped loss gradient.
For each of its two matrix roles,
start with a Muon direction $p_i$ and a direction $a_i$ obtained from
factorized second moments
\citep{jordan2024muon,liu2025muon,shazeer2018adafactor}.
Their orthogonal component
$a_i^\perp=a_i-\inner{a_i}{p_i}p_i/\|p_i\|_{\rm F}^2$
provides a way to change the direction while controlling its norm.

To determine the rotation magnitude, \tiller{} measures two
properties of the learned response: participation $\pi_i$, which measures
how broadly its energy is distributed, and congruence $\kappa_i$, which
compares its kernel with that of the initial activation at the same input.
The incoming role uses the Jacobian kernel $J_iJ_i^\top$; the outgoing role
uses the feature kernel $h_ih_i^\top$. These statistics are weighted by
downstream loss sensitivity. Their definitions and bounds appear in
Appendix~\ref{sec:directions}.
With $e_i=\pi_i(1-\kappa_i^2)\in[0,1]$, the candidate direction is
\begin{equation}
 \widetilde q_i=
 \sqrt{1-e_i}\,p_i+
 \sigma_i\sqrt{e_i}\,
 \frac{\|p_i\|_{\rm F}}{\|a_i^\perp\|_{\rm F}}a_i^\perp,
 \qquad
 \sigma_i=\operatorname{sign}\inner{g_i}{a_i^\perp}.
 \label{eq:overview-chord}
\end{equation}
We choose $\sigma_i=1$ when the contraction is zero.
Participation weights the breadth of the response, and $1-\kappa_i^2$
measures its departure from initialization. A broad response with low congruence permits more adaptive rotation,
so each group determines its mixture from its learned activation. Orthogonality gives
$\|\widetilde q_i\|_{\rm F}=\|p_i\|_{\rm F}$: the response changes direction
without changing its magnitude. The selected $q_i$ is this candidate when
both it and the parent have positive gradient contraction; degenerate or
nonfinite candidates retain $p_i$.

\subsection{Coordinating directions through their loss responses}

Directions in separate parameter blocks can affect the same loss
simultaneously. \tiller{} measures this relationship in a shared set of
activation probes. For probe $k$ and group $i$, let $\xi_{k\ell}$ be the
downstream loss cotangent. A paired direction $(q_i^A,q_i^B)$ contributes
\begin{equation}
 S_{ki}=
 \inner{\xi_{k\ell}}
 {B_iJ_{ki}q_i^Ax_{k\ell}+q_i^Bh_{ki}}.
 \label{eq:overview-score}
\end{equation}
Thus each column describes a group direction, and each row compares all
groups at the same probe. For coefficients $c$, $Sc$ is their combined
linearized response. The cross terms in $\|Sc\|_2^2$ distinguish directions
whose effects reinforce one another from those whose effects offset.

\tiller{} maintains a discounted history of these score rows using a Robust
Frequent-Directions sketch
\citep{ghashami2016frequent,luo2019robust}. It retains dominant combinations
of loss responses and assigns an isotropic remainder to the discarded
spectrum. Between probe refreshes, the current minibatch contractions
$s_i=\inner{g_i^A}{q_i^A}+\inner{g_i^B}{q_i^B}$
supply fresh directional information. This combines the current descent
signal with recent information about how directions act together.
Appendices~\ref{sec:loss-measurements} and~\ref{sec:ledger} give the updates.

Let $G_t$ denote the second-moment metric of loss responses used for the current step and $r_t$
the measured interaction with decoupled weight decay. With scheduled learning
rate $\eta$, \tiller{} chooses
signed coefficients through the model
\begin{equation}
 \min_c\;
 -\eta s_t^\top c+
 \frac{\eta^2}{2}\bigl(c^\top G_tc+2r_t^\top c\bigr),
 \qquad
 \sum_i\omega_ic_i^2=\sum_i\omega_i,
 \quad
 \omega_i=\|q_i^A\|_{\rm F}^2+\|q_i^B\|_{\rm F}^2.
 \label{eq:overview-coordinate-model}
\end{equation}
The linear term rewards descent on the current batch. The response metric measures squared linearized loss responses across probes;
the constraint fixes
their total update energy. Coefficients can amplify, attenuate, or reverse
individual groups. This makes coordination a choice of how to allocate a
shared update norm according to loss information.

A projected solver proposes coefficients; the proposal is accepted when it
improves this model, meets the norm constraint, and passes the layerwise
descent checks in Appendix~\ref{sec:transaction}. Otherwise $c_i=1$.
With weight decay $\lambda_{\rm wd}$, each paired matrix updates as
$A_i\leftarrow(1-\eta\lambda_{\rm wd})A_i-\eta c_iq_i^A$ and analogously
for $B_i$. Attention uses a response-guided rotation based on the
same layer's group statistics; rational coefficients and the remaining
parameters use AdamW \citep{loshchilov2019decoupled}. The full update is in
Appendix~\ref{app:algorithm}.

\section{GRAIN parameterization}
\label{sec:grain}

Let $H_r=Gw$ be the expanded width. For an input
$x\in\R^d$, one block is
\begin{equation}
  z=Ax,\qquad h=\Phi(z),\qquad y=Bh,
  \label{eq:grain-block}
\end{equation}
where $A\in\R^{H_r\times d}$ and $B\in\R^{d\times H_r}$. Partition $z$ into
$G$ contiguous groups $z_g\in\R^w$. At layer $\ell$, write
$A_{\ell g}\in\R^{w\times d}$ for the corresponding row block of $A_\ell$
and $B_{\ell g}\in\R^{d\times w}$ for the corresponding column block of
$B_\ell$. Then
\begin{equation}
  z_{\ell g}=A_{\ell g}x_\ell,\qquad
  y_\ell=\sum_{g=1}^G B_{\ell g}\Phi_g(z_{\ell g}).
  \label{eq:grain-group-block}
\end{equation}
For each group, define
\begin{equation}
  \rho_g=\sqrt{w^{-1}\|z_g\|_2^{2}+\epsilon_{\rm act}},
  \qquad
  u_g=z_g/\rho_g,
  \qquad
  \epsilon_{\rm act}=10^{-6}.
  \label{eq:grain-normalize}
\end{equation}
Each group has a learned rational response with a degree-five numerator and
degree-four denominator,
\begin{align}
  P_g(u)&=\sum_{k=0}^{5}a_{gk}u^k,\\
  Q_g(u)&=1+\sum_{k=1}^{4}|b_{gk}|\,|u|^k,\\
  \Phi_g(z_g)&=\rho_g\,\phi_g(u_g),
  \qquad \phi_g(u)=P_g(u)/Q_g(u),
  \label{eq:grain-rational}
\end{align}
where all functions and powers act elementwise. This combines learned rational activations
\citep{molina2020pade,boulle2020rational} with an internal RMS coordinate
system \citep{zhang2019rmsnorm}. Because $Q_g(u)\geq1$, the response is
finite for every real input.

For a SwiGLU intermediate width $H$, we set $H_r=3H/2$. The two dense
matrices in equation~\ref{eq:grain-block} then contain
$2dH_r=3dH$ weights, equal to the dense projection count of the three SwiGLU
matrices. The activation adds $10G$ rational coefficients per block. This
parameterization preserves the projection budget. The learned response
supplies the Jacobian and feature statistics used below.

The normalized map has a diagonal-plus-rank-one Jacobian wherever the
rational response is differentiable. Write
$f_g=\phi_g(u_g)$, $d_g=\phi'_g(u_g)$, and
$r_g=f_g-u_g\odot d_g$, all in $\R^w$. Direct differentiation gives
\begin{equation}
  J_g \equiv \frac{\partial\Phi_g}{\partial z_g}
  =\operatorname{Diag}(d_g)+\frac{1}{w}r_gu_g^\top,
  \qquad
  J_g^\top v=d_g\odot v+u_g\,\operatorname{mean}(r_g\odot v).
  \label{eq:grain-jacobian}
\end{equation}
Thus a group response and its pullback reduce to a diagonal operation and one
rank-one correction. This structure lets us evaluate loss derivatives of
matrix directions directly in activation space.

\subsection{Jacobian derivation and initialization}
\label{app:grain-calculus}

\begin{proposition}[Pole freedom and Jacobian structure]
For every finite group input, $Q_g(u)\geq1$. Wherever the absolute-value
terms are differentiable, the Jacobian of equations~\ref{eq:grain-normalize}
and~\ref{eq:grain-rational} is equation~\ref{eq:grain-jacobian}. At
$u_j=0$, where the response need not be classically differentiable, we use
the automatic-differentiation selection $\operatorname{sign}(0)=0$; throughout
the paper, $J_g$ denotes this selected derivative at such coordinates.
\end{proposition}

\begin{proof}
Every term $|b_{gk}|\,|u|^k$ is nonnegative, hence $Q_g(u)\geq1$. Suppress
the group index and write
$\rho=(w^{-1}z^\top z+\epsilon_{\rm act})^{1/2}$ and $u=z/\rho$. Then
\begin{equation}
  \nabla_z\rho=u/w,
  \qquad
  \frac{\partial u}{\partial z}
  =\rho^{-1}\left(I-uu^\top/w\right).
  \label{eq:grain-normalization-derivative}
\end{equation}
Applying the product and chain rules to $\Phi(z)=\rho\phi(u)$ gives
\begin{align}
  J
  &=\phi(u)u^\top/w+\operatorname{Diag}(\phi'(u))
    \left(I-uu^\top/w\right)\\
  &=\operatorname{Diag}(d)
    +\left(\phi(u)-u\odot d\right)u^\top/w.
\end{align}
Transposition and multiplication by $v$ yield the pullback in
equation~\ref{eq:grain-jacobian}.
\end{proof}

All groups begin from the same SiLU fit. In ascending powers, the coefficients
are
\begin{align}
  (a^{\rm init}_0,\ldots,a^{\rm init}_5)
  ={}&(2.4915714620520875\!\times\!10^{-5},\
  0.5000668663485823,\ 0.2499441908995771,\nonumber\\
  &0.0526200910151016,\ 0.005525765640115002,\
  0.00024199321178747251),\\
  (b^{\rm init}_1,\ldots,b^{\rm init}_4)
  ={}&(0.00022554017910995938,\ 0.10511420350691994,\nonumber\\
  &2.8656992394109812\!\times\!10^{-5},\
  0.0004816962110562025).
\end{align}
The ten coefficients subsequently learn independently in every group.

\section{Response-aware structured directions}
\label{sec:directions}

\paragraph{Parent and adaptive directions.}
Let $g_t$ denote the parameter gradient after microbatch accumulation,
distributed averaging, and global-norm clipping.
For each pair of group blocks $i=(\ell,g)$ and role
$r\in\{A,B\}$, \tiller{} starts from a Nesterov--Muon direction $p_i^r$:
with $\beta_1=0.95$, it forms
\begin{equation}
  v_{t,i}^r=\beta_1v_{t-1,i}^r+(1-\beta_1)g_{t,i}^r,
  \qquad
  m_{t,i}^r=\beta_1v_{t,i}^r+(1-\beta_1)g_{t,i}^r,
  \label{eq:nesterov-momentum}
\end{equation}
followed by a five-step Newton--Schulz polar map
applied independently to each group block and Muon's role-dependent RMS
adjustment \citep{jordan2024muon,bernstein2024old,liu2025muon}. The groupwise
map has nominal rank $G\min\{w,d\}$, whereas the corresponding full matrix has
rank at most $\min\{H_r,d\}$. We therefore apply the calibration
\begin{equation}
  \chi_{\rm grp}
  =\sqrt{\frac{\min\{H_r,d\}}{G\min\{w,d\}}},
  \label{eq:group-polar-calibration}
\end{equation}
which calibrates the nominal Frobenius scale to that of a full-matrix polar direction.
Writing $\mathcal P_5$ for this blockwise polar map, Muon's adjustment is
$\mu_{\rm mlp}=0.2\sqrt{\max\{H_r,d\}}$ for either GRAIN matrix role. The
parent group direction is
$p_{t,i}^r=\mu_{\rm mlp}\chi_{\rm grp}\mathcal P_5(m_{t,i}^r)$.
In parallel, \tiller{} maintains
factorized row and column second moments, in the spirit of memory-efficient
factored adaptation \citep{shazeer2018adafactor}. For a grouped matrix with
gradient $g_i$ and Nesterov momentum $m_i$, suppressing role and time indices,
\begin{align}
  R_t&=\beta_2 R_{t-1}+(1-\beta_2)\operatorname{rowsum}(g_i^2),\\
  C_t&=\beta_2 C_{t-1}+(1-\beta_2)\operatorname{colsum}(g_i^2),\\
  V_{t,jk}&=\frac{R_{t,j}C_{t,k}}
  {\max\{\sum_sR_{t,s},\delta_{\rm fp}\}}\frac{1}{1-\beta_2^t},
  \qquad
  a_i=\mu_{\rm mlp}\frac{m_i}{\sqrt{V_t}+\epsilon_{\rm opt}}.
  \label{eq:factored-direction}
\end{align}
We set $\beta_2=0.95$ and $\epsilon_{\rm opt}=10^{-8}$. The same $\beta_2$
sets the time scale of the loss ledger in Section~\ref{sec:ledger}, aligning
the adaptive-direction and response histories. The zero-total convention for
the factorized estimate is given in Appendix~\ref{app:algorithm}.

\paragraph{A response-derived mixing fraction.}
Two bounded summaries determine how much of the adaptive direction enters
the update. At a response refresh, let $n\in\{1,\ldots,K\}$ index the sampled
positions and let $\xi_{n\ell}\in\R^d$ be the downstream cotangent at the
output of block $\ell$. Define
\begin{align}
  \operatorname{pr}_A(J_{in})
  &=\frac{[\operatorname{tr}(J_{in}J_{in}^{\top})]^2}
  {w\|J_{in}J_{in}^{\top}\|_{\rm F}^2},&
  \Gamma^A_{in}&=J_{in}J_{in}^{\top},\\
  \operatorname{pr}_B(h_{in})
  &=\frac{\|h_{in}\|_2^4}{w\|h_{in}\|_4^4},&
  \Gamma^B_{in}&=h_{in}h_{in}^{\top}.
  \label{eq:response-summary-components}
\end{align}
For the same normalized input, $\Gamma^{r,0}_{in}$ denotes the kernel
obtained from the initial rational response. Let
\begin{equation}
  \alpha^A_{in}=\|J_{in}^{\top}B_i^{\top}\xi_{n\ell}\|_2^2/w,
  \qquad
  \alpha^B_{in}=\|\xi_{n\ell}\|_2^2/d
  \label{eq:response-sensitivity}
\end{equation}
measure downstream loss sensitivity. Participation and congruence are
\begin{align}
  \pi_i^A
  &=\frac{\sum_n\alpha^A_{in}\operatorname{pr}_A(J_{in})}
  {\sum_n\alpha^A_{in}},&
  \pi_i^B
  &=\frac{\sum_n\alpha^B_{in}\operatorname{pr}_B(h_{in})}
  {\sum_n\alpha^B_{in}},
  \label{eq:participation-main}\\
  \kappa_i^r
  &=\frac{\sum_n\alpha^r_{in}
  \inner{\Gamma^r_{in}}{\Gamma^{r,0}_{in}}}
  {\sqrt{\left(\sum_n\alpha^r_{in}\frob{\Gamma^r_{in}}^2\right)
  \left(\sum_n\alpha^r_{in}\frob{\Gamma^{r,0}_{in}}^2\right)}}.
  \label{eq:congruence-main}
\end{align}
The two participation statistics answer role-specific versions of the same
question: how broadly is the live response distributed?  For the incoming
role, $\operatorname{pr}_A$ is the normalized inverse participation ratio of
the squared singular values of $J_{in}$; it equals $1/w$ for a rank-one
Jacobian and reaches one when all $w$ singular values have equal magnitude.
For the outgoing role, $\operatorname{pr}_B$ is the normalized inverse
participation ratio of the coordinate energies $h_{in,j}^2$; it equals $1/w$
when all feature energy lies in one coordinate and reaches one when that
energy is uniform. Congruence is the cosine between the live and initial
kernels in a loss-weighted direct-sum space, so
$1-(\kappa_i^r)^2$ is the squared sine of their kernel angle. Their product
therefore opens the adaptive tangent when the response is both broadly
supported and different from its initialization. Zero-response conventions and bounds are given in
Appendix~\ref{app:response-proof}; whenever a comparison is undefined, we set
its departure energy to zero. We allocate
\begin{equation}
  e_i^r=\pi_i^r\bigl(1-(\kappa_i^r)^2\bigr)
  \label{eq:departure-energy}
\end{equation}
of the direction energy to an adaptive tangent.

\paragraph{A norm-preserving chord.}
Suppressing the role index, define
\begin{equation}
  a_i^\perp
  =
  \begin{cases}
  a_i-\dfrac{\inner{a_i}{p_i}}{\frob{p_i}^2}p_i,
  &\frob{p_i}>0,\\
  0,&\frob{p_i}=0,
  \end{cases}
  \qquad
  \sigma_i=
  \begin{cases}
    1,&\inner{g_i}{a_i^\perp}\geq0,\\
    -1,&\inner{g_i}{a_i^\perp}<0.
  \end{cases}
  \label{eq:tangent-orientation}
\end{equation}
When $\|p_i\|_{\rm F}>0$ and $\|a_i^\perp\|_{\rm F}>0$, form the candidate
\begin{equation}
  \widetilde q_i=\sqrt{1-e_i}\,p_i+
  \sigma_i\sqrt{e_i}\frac{\frob{p_i}}{\frob{a_i^\perp}}a_i^\perp.
  \label{eq:tangent-chord}
\end{equation}
The selected direction is
\begin{equation}
  q_i=
  \begin{cases}
    \widetilde q_i,
    &\|p_i\|_{\rm F}\|a_i^\perp\|_{\rm F}>0,\
    \inner{g_i}{p_i}>0,\ \inner{g_i}{\widetilde q_i}>0,
    \text{ and the candidate is finite},\\
    p_i,&\text{otherwise}.
  \end{cases}
  \label{eq:chord-selection}
\end{equation}
Participation measures response spread; congruence measures learned change.
A broad response with low congruence receives a larger adaptive norm fraction.
The gradient determines the orientation of the resulting tangent.

\subsection{Bounds and norm preservation}
\label{app:response-proof}

At probe position $n$, the initialization kernels
$\Gamma^{A,0}_{in}$ and $\Gamma^{B,0}_{in}$ evaluate the frozen initial
rational coefficients at the current normalized input $u_{in}$. The input
projection and the downstream cotangent remain at their current values.
Products between the live and initial Jacobian kernels are evaluated directly
from equation~\ref{eq:grain-jacobian}.

For a nonzero Jacobian with singular values
$\{\sigma_j\}_{j=1}^w$,
\begin{equation}
  \operatorname{pr}_A(J)
  =\frac{(\sum_j\sigma_j^2)^2}{w\sum_j\sigma_j^4},
  \qquad
  \operatorname{pr}_B(h)=\frac{\|h\|_2^4}{w\|h\|_4^4}.
  \label{eq:participation-expanded}
\end{equation}
We take $\operatorname{pr}_A(0)=\operatorname{pr}_B(0)=0$. If either role has
zero total sensitivity, we set both participation values to one. If either
kernel-alignment denominator vanishes, we set both congruence values to one.
In either case equation~\ref{eq:departure-energy} gives $e_i^r=0$ whenever
the corresponding response comparison is undefined.

\begin{lemma}[Response-summary bounds]
For every $J\neq0$ and $h\neq0$,
$\operatorname{pr}_A(J),\operatorname{pr}_B(h)\in[1/w,1]$. Whenever the
denominator in equation~\ref{eq:congruence-main} is positive,
$\kappa_i^r\in[0,1]$.
\end{lemma}

\begin{proof}
For nonnegative $v_j$, Cauchy--Schwarz gives
$(\sum_jv_j)^2\leq w\sum_jv_j^2$, while
$(\sum_jv_j)^2\geq\sum_jv_j^2$. Apply this first to
$v_j=\sigma_j^2$ and then to $v_j=h_j^2$. For congruence, concatenate the
weighted kernels as direct-sum matrices
$\bigoplus_n\sqrt{\alpha^r_{in}}\Gamma^r_{in}$ and
$\bigoplus_n\sqrt{\alpha^r_{in}}\Gamma^{r,0}_{in}$.
Frobenius Cauchy--Schwarz gives the upper bound. The numerator is
nonnegative because
$\inner{JJ^\top}{J^0J^{0\top}}=\|J^\top J^0\|_{\rm F}^2$ and
$\inner{hh^\top}{h^0h^{0\top}}=(h^\top h^0)^2$.
\end{proof}

\begin{proposition}[Norm preservation]
Assume $e\in[0,1]$, $p\neq0$, and $a^\perp\neq0$. The candidate in
equation~\ref{eq:tangent-chord} satisfies
$\frob{\widetilde q}=\frob{p}$, and the selected direction in
equation~\ref{eq:chord-selection} satisfies $\frob{q}=\frob{p}$.
\end{proposition}

\begin{proof}
By construction, $\inner{p}{a^\perp}=0$. Since $e\in[0,1]$,
\begin{equation}
  \frob{\widetilde q}^2=(1-e)\frob{p}^2+
  e\,\frob{p}^2=\frob{p}^2.
\end{equation}
The fallback branch in equation~\ref{eq:chord-selection} is $q=p$.
\end{proof}

\section{Loss-coordinate measurements}
\label{sec:loss-measurements}

On optimizer step 1 and every eight steps thereafter, \tiller{}
deterministically selects a probe set $\mathcal P_t$ of $K=32$ example--token
positions. The same positions index every coordinate at that refresh, so each
row is a joint measurement across the network. For probe
$k\in\mathcal P_t$ and coordinate $i=(\ell,g)$, let
$x_{k,\ell}$ be the block input, $z_{k,i}=A_ix_{k,\ell}$,
$h_{k,i}=\Phi_i(z_{k,i})$. Let $\xi_{k,\ell}$ be the corresponding output
cotangent of the summed microbatch loss at that activation position, scaled
by the clipping factor applied to the parameter gradient. Along the paired direction
$(q_i^A,q_i^B)$,
\begin{equation}
  \delta z_{k,i}=q_i^Ax_{k,\ell},\qquad
  \delta h_{k,i}=J_{k,i}\delta z_{k,i},\qquad
  \delta y_{k,i}=B_i\delta h_{k,i}+q_i^Bh_{k,i}.
  \label{eq:directional-path}
\end{equation}
Pairing $\delta y_{k,i}$ with the downstream loss derivative gives
\begin{equation}
  S_{t,k,i}
  =\inner{q_i^A x_{k,\ell}}{J_{k,i}^\top B_i^\top \xi_{k,\ell}}
  +\inner{q_i^B h_{k,i}}{\xi_{k,\ell}}.
  \label{eq:functional-score}
\end{equation}
At differentiability points, equation~\ref{eq:functional-score} is the
clipped activation-position contribution to the loss derivative. Averaging
over all activation positions recovers the clipped mean-reduced minibatch
derivative; sampled rows
retain contributions at the probe positions. The exact
minibatch contraction is computed below from the parameter gradient. At zero
coordinates, the score uses the derivative convention in
Appendix~\ref{app:grain-calculus}. The pullback in
equation~\ref{eq:grain-jacobian} evaluates its incoming term using groupwise
contractions. Applying the same calculation to the decoupled decay direction
and summing over coordinates gives a decay-action vector
$a_t^{\rm dec}\in\R^K$.

Between functional refreshes, the two matrix roles provide the current
minibatch directional derivatives
\begin{equation}
  s_{t,i}=\inner{g^A_{t,i}}{q^A_{t,i}}+
  \inner{g^B_{t,i}}{q^B_{t,i}}.
  \label{eq:current-score}
\end{equation}
Let $\nu=\|S_{\rm ref}\|_{\rm F}/\sqrt K$ be the RMS row norm of the latest
functional measurement. Set
\begin{equation}
  \gamma_t=
  \begin{cases}
    \nu/\|s_t\|_2,&\|s_t\|_2>0,\\
    0,&\|s_t\|_2=0,
  \end{cases}
  \qquad
  S_t=\boldsymbol1_K(\gamma_t s_t)^\top,\qquad
  a_t^{\rm dec}=\boldsymbol1_K\gamma_t d_t^{\rm dec},
  \label{eq:trace-matched-rows}
\end{equation}
where $d_t^{\rm dec}$ is the current minibatch derivative along the complete
GRAIN decay direction. This construction exactly preserves the trace of the
latest functional geometry because
$\|S_t\|_{\rm F}^2=K\gamma_t^2\|s_t\|_2^2=
\|S_{\rm ref}\|_{\rm F}^2$ whenever $s_t\neq0$. Hence every step contributes
the current first-order direction, while functional refreshes periodically
restore probe-level cross-coordinate variation.

For coefficients $c\in\R^C$, the probe vector induced jointly by the
structured direction and decoupled decay is $S_tc+a_t^{\rm dec}$. Its squared
response expands as
\begin{equation}
  \frac1K\|S_tc+a_t^{\rm dec}\|_2^2
  =\frac1K\|S_tc\|_2^2
  +\frac{2}{K}c^\top S_t^\top a_t^{\rm dec}
  +\frac1K\|a_t^{\rm dec}\|_2^2.
  \label{eq:functional-response-energy}
\end{equation}
The last term is constant in $c$. The first two terms expose which
coordinates repeatedly affect the same loss probes and whether their joint
effect reinforces the fixed decay direction. They define a
functional-response covariance surrogate rather than a Hessian model of the
loss.

\subsection{Directional score derivation}
\label{app:ledger-identities}

At one activation position, consider a local intervention with
$A_i(\alpha)=A_i+\alpha q_i^A$ and
$B_i(\alpha)=B_i+\alpha q_i^B$. At points where the rational response is
differentiable, hold the other positions in this block fixed and differentiate the group contribution
$B_i(\alpha)\Phi_i(A_i(\alpha)x)$ at $\alpha=0$ gives
\begin{align}
  \left.\frac{d}{d\alpha}
  B_i(\alpha)\Phi_i(A_i(\alpha)x)\right|_{\alpha=0}
  &=q_i^Bh_i+B_iJ_iq_i^Ax,\\
  \left.\frac{d\mathcal L}{d\alpha}\right|_{\alpha=0}
  &=\inner{\xi}{q_i^Bh_i+B_iJ_iq_i^Ax}.
\end{align}
Here $\mathcal L$ is the summed microbatch loss multiplied by the realized
clipping factor, held fixed during the local differentiation.
At a zero coordinate of the normalized response, the right-hand sides define
the automatic-differentiation-selected linearization from
Appendix~\ref{app:grain-calculus}, rather than a classical two-sided
derivative.
Moving the linear maps across the inner product yields
equation~\ref{eq:functional-score}. Thus one row of $S$ records the loss-sensitive
contributions of every layer--group direction at the same sampled position;
its rowwise outer product couples coordinates whose contributions vary together.

The captured cotangent is put on the summed-loss scale explicitly. If a
microbatch contains $R$ activation positions, $M$ microbatches are
accumulated, $\bar\xi_{k\ell}$ is the cotangent captured from the
mean-reduced backward pass, and $\chi_{\rm clip}$ is the realized clipping
factor, then
\begin{equation}
  \xi_{k\ell}=RM\chi_{\rm clip}\,\bar\xi_{k\ell}.
  \label{eq:cotangent-rescaling}
\end{equation}
The indices used to sample $x$, $z$, $h$, and $\bar\xi$ are identical within
each probe row.


When $s_t\neq0$, the repeated surrogate has the same trace
$\operatorname{tr}(S_t^\top S_t/K)=\nu^2$ as the latest functional score factor.
It has rank at most one (rank one when $\nu>0$) and is aligned with the
current coordinate-score vector; the next functional refresh replaces that
directional approximation with probe-level cross-coordinate structure.

\section{A Robust Frequent-Directions loss ledger}
\label{sec:ledger}

The ledger tracks the two coefficient-dependent terms in
equation~\ref{eq:functional-response-energy}. The score rows define a
quadratic geometry over the $C=LG$ coordinates.
\tiller{} represents this geometry by a low-rank factor and an isotropic
remainder. It initializes $\mathcal B_1=S_1$ and $\tau_1=0$. From the second
step onward, it retains $\mathcal B_{t-1}$ with at most $r=64$ rows and forms
\begin{equation}
  \mathcal A_t=
  \begin{bmatrix}
    \sqrt{\beta_2}\mathcal B_{t-1}\\
    \sqrt{1-\beta_2}S_t
  \end{bmatrix}.
  \label{eq:rfd-stack}
\end{equation}
Following Frequent Directions and its robust isotropic completion
\citep{ghashami2016frequent,luo2019robust}, \tiller{} diagonalizes the row
Gram matrix $\mathcal A_t\mathcal A_t^\top$. If $\Delta_t$ is the largest discarded
eigenvalue, it shrinks every retained eigenvalue by $\Delta_t$ and adds
$\Delta_t/(2K)$ to an isotropic tail. The persistent metric is
\begin{equation}
  \widehat G_t=\frac1K \mathcal B_t^\top \mathcal B_t+\tau_tI,
  \qquad
  \tau_t=\beta_2\tau_{t-1}+\frac{\Delta_t}{2K}.
  \label{eq:rfd-metric}
\end{equation}
The midpoint tail assigns half of the unrepresented eigenvalue interval to every
direction. It therefore halves the worst-direction error of either endpoint
completion, yielding the bound $\Delta_t/(2K)$ in
Appendix~\ref{app:rfd-proof}. The score--decay cross term is
\begin{equation}
  r_t=\beta_2r_{t-1}+
  (1-\beta_2)S_t^\top a_t^{\rm dec}/K.
  \label{eq:decay-cross}
\end{equation}
The current transaction uses the uncompressed factor $\mathcal A_t$ and
diagonal completion
$\delta_t=\beta_2\tau_{t-1}\boldsymbol1$;
$(\mathcal B_t,\tau_t,r_t)$ is carried to the next step. At initialization,
$\mathcal A_1=S_1$, $\delta_1=0$, and
$r_1=S_1^\top a_1^{\rm dec}/K$.

\subsection{Spectral approximation}
\label{app:rfd-proof}

\begin{proposition}[Positive semidefiniteness and spectral error]
Let $K>0$, $0\leq\beta_2\leq1$, $\tau_{t-1}\geq0$, and
$\mathcal A=U\operatorname{Diag}(\sigma)V^\top$, with singular values in
nonincreasing order. If
$\operatorname{rank}(\mathcal A)>r$, set $\Delta=\sigma_{r+1}^2$ and define
\begin{equation}
  \mathcal B=\operatorname{Diag}\!\left(
  \sqrt{(\sigma_1^2-\Delta)_+},\ldots,
  \sqrt{(\sigma_r^2-\Delta)_+}\right)V_{1:r}^\top .
  \label{eq:rfd-reconstruction}
\end{equation}
If $\operatorname{rank}(\mathcal A)\leq r$, set $\Delta=0$ and choose any
factor with at most $r$ rows satisfying
$\mathcal B^\top\mathcal B=\mathcal A^\top\mathcal A$. Let
\begin{equation}
  G=\mathcal A^\top\mathcal A/K+\beta_2\tau_{t-1}I
\end{equation}
be the pre-compression metric, and form
$\widehat G=\mathcal B^\top\mathcal B/K+
(\beta_2\tau_{t-1}+\Delta/(2K))I$. Then
\begin{equation}
  \widehat G\succeq0,
  \qquad
  \|\widehat G-G\|_2\leq\frac{\Delta}{2K}.
  \label{eq:rfd-error}
\end{equation}
\end{proposition}

\begin{proof}
When $\operatorname{rank}(\mathcal A)\leq r$, the two metrics are identical
and the claim follows with $\Delta=0$. Otherwise, the retained eigenvalues
after shrinkage are nonnegative, and
$\tau_t=\beta_2\tau_{t-1}+\Delta/(2K)\geq0$, proving positive
semidefiniteness. On a retained right-singular direction, the represented
eigenvalue differs from the live eigenvalue by $-\Delta/(2K)$. On a
discarded direction with live eigenvalue $\lambda\in[0,\Delta]$, the error is
$(\Delta/2-\lambda)/K$. On a null direction it is $\Delta/(2K)$. The largest
absolute eigenvalue error is therefore at most $\Delta/(2K)$.
\end{proof}

The scalar $\Delta/(2K)$ is the midpoint of the unrepresented interval
$[0,\Delta/K]$ and minimizes the worst absolute scalar-completion error over
that interval. The one-step result also yields a discounted history bound.
Let
\begin{equation}
  G_t^\star=\beta_2G_{t-1}^\star+
  (1-\beta_2)S_t^\top S_t/K,\qquad
  G_1^\star=S_1^\top S_1/K
\end{equation}
be the uncompressed exponentially weighted metric. If
$E_t=\widehat G_t-G_t^\star$, then
\begin{equation}
  \|E_t\|_2
  \leq\sum_{j=2}^{t}\beta_2^{\,t-j}\frac{\Delta_j}{2K}.
  \label{eq:rfd-history-error}
\end{equation}
Indeed, the compression error at step $t$ is a perturbation $D_t$ with
$\|D_t\|_2\leq\Delta_t/(2K)$, so
$E_t=\beta_2E_{t-1}+D_t$ and $E_1=0$.

\section{Signed equal-budget transaction}
\label{sec:transaction}

Let $c\in\R^C$ scale the paired directions and define
$\omega_i=\frob{q_i^A}^2+\frob{q_i^B}^2$. Assume $\omega_i>0$ for every coordinate. The uncoordinated parent update is
$c=\boldsymbol 1$, whose squared norm is
$\mathcal E_0=\sum_i\omega_i$. Indeed, the parameter blocks associated with
different coordinates are disjoint, so the structured update
$\Delta\theta(c)=-\eta\{c_iq_i^A,c_iq_i^B\}_{i=1}^C$ satisfies
$\|\Delta\theta(c)\|_2^2=\eta^2\sum_i\omega_ic_i^2$.
With current directional derivatives $s_t$,
pre-compression factor $\mathcal A_t$, diagonal completion $\delta_t$,
score--decay cross term $r_t$, and scheduled step size $\eta$, \tiller{}
forms the response penalty
\begin{equation}
  \mathcal R_t(c)=\frac1K\|\mathcal A_tc\|_2^2+
  \delta_t^\top(c\odot c)+2r_t^\top c
  \label{eq:ledger-response-penalty}
\end{equation}
and searches in a Krylov subspace for a projected positive-multiplier
stationary candidate of the equal-budget model
\begin{align}
  \min_c\quad
  F_t(c)&=-\eta s_t^\top c+\frac{\eta^2}{2}\mathcal R_t(c),
  \label{eq:transaction-objective}\\
  \text{s.t.}\quad&\sum_i\omega_ic_i^2=\mathcal E_0.
  \label{eq:transaction-budget}
\end{align}
The linear term rewards immediate descent. The quadratic term penalizes
directions that the loss ledger predicts to interact strongly, including the
effect of decoupled decay. The constraint gives the coordinated GRAIN
direction the same aggregate squared norm as the parent before applying their
common decay term.
Because $c$ is signed, a transaction may amplify, attenuate, or reverse
individual coordinates.

After whitening $y=W^{1/2}c$, where $W=\operatorname{Diag}(\omega)$, the
stationarity equation is
\begin{equation}
  (M_t+\lambda I)y=b_t,
  \quad
  M_t=W^{-1/2}\left(\mathcal A_t^\top\mathcal A_t/K+
  \operatorname{Diag}(\delta_t)\right)W^{-1/2},
  \quad
  b_t=W^{-1/2}(s_t/\eta-r_t).
  \label{eq:transaction-kkt}
\end{equation}
The proposal is retained when it satisfies the budget, lowers
$F_t$ relative to $c=\boldsymbol1$, and preserves positive layerwise
gradient and momentum contractions
\begin{equation}
  \sum_g c_{\ell g}\inner{g_{\ell g}^r}{q_{\ell g}^r}>0,
  \qquad
  \sum_g c_{\ell g}\inner{m_{\ell g}^r}{q_{\ell g}^r}>0
  \quad (r\in\{A,B\}).
  \label{eq:transaction-contractions}
\end{equation}
Both contractions must also be positive for the parent $c=\boldsymbol1$.

\subsection{Projected solution}
\label{app:transaction-proof}

For $\eta>0$, $\omega_i>0$, and $\delta_t\geq0$, let
$W=\operatorname{Diag}(\omega)$ and set $y=W^{1/2}c$. Substituting
$c=W^{-1/2}y$ into equations~\ref{eq:transaction-objective} and
\ref{eq:transaction-budget}, then dividing by $\eta^2$, gives the equivalent
problem
\begin{equation}
  \min_{\|y\|_2^2=\mathcal E_0}\
  \frac12y^\top M_ty-b_t^\top y,
  \label{eq:whitened-transaction}
\end{equation}
with $M_t$ and $b_t$ from equation~\ref{eq:transaction-kkt}. Its Lagrangian
\begin{equation}
  \mathcal J(y,\lambda)=\tfrac12y^\top M_ty-b_t^\top y
  +\tfrac{\lambda}{2}(\|y\|_2^2-\mathcal E_0)
\end{equation}
has stationarity equation $(M_t+\lambda I)y=b_t$.

For $b_t\neq0$, matrix products are evaluated as
$M_tv=W^{-1/2}\mathcal A_t^\top(\mathcal A_tW^{-1/2}v)/K+
(\delta_t\oslash\omega)\odot v$.
A fully reorthogonalized Lanczos \citep{lanczos1950iteration}
recurrence starts from $b_t/\|b_t\|_2$ and constructs an orthonormal basis
$Q_k$, with $k\leq32$.
Without breakdown, this basis spans
$\mathcal K_k(M_t,b_t)=
\operatorname{span}\{b_t,M_tb_t,\ldots,M_t^{k-1}b_t\}$.
If a numerical breakdown threshold is reached early, a deterministic cosine
vector is reorthogonalized against the existing basis to start the next block,
and the coupling between the two blocks is set to zero. The recurrence is
accepted only after its final orthogonality check. Let $\bar T_k$ denote the symmetric block-tridiagonal
matrix accumulated by this recurrence; without a threshold restart,
$\bar T_k=Q_k^\top M_tQ_k$. If
$\bar T_k=U\operatorname{Diag}(\bar\theta)U^\top$, define the numerical
positive-semidefinite surrogate
$T_k^+=U\operatorname{Diag}(\theta)U^\top$ with
$\theta_j=\max\{\bar\theta_j,0\}$. The solver uses
\begin{equation}
  (T_k^++\lambda I)z=Q_k^\top b_t,
  \qquad \|z\|_2^2=\mathcal E_0.
  \label{eq:projected-secular}
\end{equation}
With $\gamma=U^\top Q_k^\top b_t$, the norm constraint becomes
\begin{equation}
  \psi(\lambda)=\sum_j\frac{\gamma_j^2}{(\theta_j+\lambda)^2}
  =\mathcal E_0.
  \label{eq:secular-equation}
\end{equation}
On the regular branch $\lambda>0$, $\psi$ is continuous and strictly
decreasing because $\gamma\neq0$ and $\theta_j\geq0$.
Let
\begin{equation}
  \lambda_{\rm lo}=\epsilon_{\rm mach}C,\qquad
  \lambda_{\rm hi}=
  \frac{\|b_t\|_2}{\sqrt{\mathcal E_0}}
  +\lambda_{\max}(T_k^+)+\lambda_{\rm lo}.
\end{equation}
Because $\|\gamma\|_2=\|b_t\|_2$ and every $\theta_j\geq0$,
$\psi(\lambda_{\rm hi})\leq\|b_t\|_2^2/\lambda_{\rm hi}^2
\leq\mathcal E_0$. When
$\psi(\lambda_{\rm lo})\geq\mathcal E_0$, a unique root in the positive
bracket is approximated by 64 bisection steps. Otherwise no multiplier in the
implemented interval $[\lambda_{\rm lo},\infty)$ attains the budget. The parent coefficients are retained in this case.

The projected coefficient vector is evaluated in double precision using the
unprojected low-rank-plus-diagonal objective. A finite proposal is retained
when
\begin{equation}
  \frac{|c^\top Wc-\mathcal E_0|}{\max\{\mathcal E_0,1\}}\leq10^{-8},
  \qquad F_t(c)<F_t(\boldsymbol1),
\end{equation}
and both its and the parent's aggregate current-gradient and Nesterov
contractions are positive for both matrix roles in each layer.

\section{Completing the Transformer update}
\label{sec:distributed}

For attention, the group statistics are summarized at each layer as
\begin{equation}
  \pi_\ell^{\rm att}=
  \sqrt{\left(G^{-1}\sum_g\pi_{\ell g}^A\right)
              \left(G^{-1}\sum_g\pi_{\ell g}^B\right)},
  \qquad
  \kappa_\ell^{\rm att}=\sqrt{\kappa_\ell^A\kappa_\ell^B},
  \label{eq:attention-response}
\end{equation}
where each $\kappa_\ell^r$ is formed by summing the numerator and two
denominator terms of equation~\ref{eq:congruence-main} over groups before
normalization. With
\begin{equation}
  e_\ell^{\rm att}
  =\sqrt{\bar\pi_\ell^A\bar\pi_\ell^B}
   \left(1-\kappa_\ell^A\kappa_\ell^B\right),
  \qquad
  \bar\pi_\ell^r=G^{-1}\sum_g\pi_{\ell g}^r,
  \label{eq:attention-departure}
\end{equation}
the participation factor requires broad support on both matrix roles, while
the departure factor opens when either role has moved away from its initial
response. These layerwise statistics gate the same norm-preserving chord for
the QKV and output matrices. Attention heads are partitioned into blocks of four for the
polar map; the stacked QKV direction is scaled by $1/\sqrt3$ to match its
three constituent projections. The adaptive tangent is factorized at matrix
level. Attention does not enter the $LG$ coefficient transaction. Learned
rational coefficients, embeddings, normalization parameters, and remaining
tensors use AdamW \citep{loshchilov2019decoupled}.


\subsection{Complete update}
\label{app:algorithm}

For completeness, the five-step polar map starts from the input matrix
normalized by its Frobenius norm (lower bounded by $10^{-7}$), transposing
tall matrices before the iteration. Each step is
\begin{equation}
  X_{j+1}=aX_j+b(X_jX_j^\top)X_j+c(X_jX_j^\top)^2X_j,
  \qquad
  (a,b,c)=(3.4445,-4.775,2.0315),
  \label{eq:newton-schulz-map}
\end{equation}
after which the original orientation is restored.

The update below is defined for $C\geq2$ on the transaction domain
$\omega_i>0$ for every coordinate and $b_t\neq0$.
The state at step $t$ comprises Nesterov momentum, factorized second moments,
the most recent response summaries, the score factor $\mathcal B_{t-1}$, its isotropic
tail $\tau_{t-1}$, and the score--decay cross term. One update proceeds as
follows.
The factorized moments use float32 accumulators and
$\delta_{\rm fp}=\operatorname{finfo}(\texttt{float32}).\operatorname{tiny}$;
when the row-moment total is zero, the estimate in
equation~\ref{eq:factored-direction} is $V_t=0$.
\begin{enumerate}
  \item Update momentum and construct the five-step Newton--Schulz Muon
  parent directions for the paired GRAIN matrices and the attention matrices.
  \item Update the factorized second moments. On a functional refresh, compute
  participation and congruence; between refreshes, reuse their latest values.
  Form the response-gated tangent chords.
  \item At step 1 and every eight steps thereafter, evaluate the $32$ rows in
  equation~\ref{eq:functional-score} and the corresponding decay action.
  At other steps, form the trace-matched rows from the current batch-gradient
  scores.
  \item Update the rank-$64$ Robust Frequent-Directions factor, isotropic
  tail, and score--decay cross term.
  \item Construct the at-most 32-dimensional Lanczos basis, attempt the
  positive regular branch of
  equation~\ref{eq:secular-equation}, and evaluate the proposed transaction.
  \item Scale both GRAIN matrix directions in coordinate $(\ell,g)$ by
  $c_{\ell g}$, then apply decoupled decay to the existing parameters and add
  the scheduled directional update.
  Apply the response-informed chord to the attention matrices.
  \item Update the rational coefficients and remaining parameter classes with
  AdamW.
\end{enumerate}

The attention polar map groups 16 heads in blocks of four. GRAIN uses group
width $w=256$. Undefined response comparisons set $e=0$, degenerate tangents
select the Muon parent, and unbracketed positive-multiplier branches or
rejected proposals retain $c=\boldsymbol1$.
